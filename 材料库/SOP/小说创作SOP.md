# SOP · 小说创作阶段(流水线第 ② 步)

> 用 **A1 → A2 → A3 → A4** 四个 agent,把"一个题材想法"变成"可改编漫剧的小说成稿"。

---

## 阶段定位

| 项 | 内容 |
|---|---|
| 流水线位置 | ② 小说创作 |
| 涉及 agent | A1(大纲) / A2(正文) / A3(精化) / A4(审查) |
| 时间预算 | **4-12 小时**(新手 / 老手差异大) |
| 产物存放 | `我的作品/<编号>_<项目名>/01_小说.md` |
| 下一阶段对接 | A6 剧本生成(A5 三视图已移至分镜审查之后) |

---

## 0 · 前置准备(0.5 小时)

### 0.1 查材料库现有资产

打开三个目录,看有什么能复用:

- `材料库/人物/` —— 是否有可复用角色?(陆战神 / 苏婉清 ...)
- `材料库/场景/` —— 是否有可复用场景?(战神别墅 / 天玄宗 ...)
- `材料库/参考作品/` —— 你赛道的拆解笔记里,有哪些"可复用清单"?

把"打算复用 + 打算借鉴"的资产列出来,A3 阶段会用到。

### 0.2 准备 6 个必填字段

A1 启动需要这 6 个字段——**写不出来 = 还没想清楚,不开跑**:

| 字段 | 例 | 备注 |
|---|---|---|
| 题材 | 战神归来 | 必须明确赛道 |
| 平台 | 抖音 | 影响合规审标准 |
| 集数 | 10 | 5-30 集常见 |
| 每集时长 | 180s | 60 / 180 / 300s |
| Logline 草案 | 废婿三年归,扫平当年踩过他的人 | ≤ 50 字 |
| 主题 | 真正的强者不需要他人证明 | ≤ 15 字 |

**Logline 写不出来 → 看 `学习笔记/创作思维.md` A.1 节公式 → 写 10 个备选挑 1 个。**

### 0.3 新建作品目录

```
我的作品/00X_<项目名>/
  00_企划.md         ← 填基本信息(模板见 我的作品/README.md)
  01_小说.md         ← 最终终稿(完成本 SOP 后放这里)
  ...
```

填好 `00_企划.md`。

---

## 1 · A1 大纲(1-2 小时)

### 1.1 配置

- DeepSeek 智能体:创建 "漫剧-A1-小说大纲-V1.0",系统提示词槽位粘 `材料库/agent/A1_小说大纲.md` 全文
- Claude Project:Custom instructions 粘同上
- 普通对话:开新对话,先粘 agent md,回复"已就绪"后发输入

### 1.2 喂输入

按 A1 的"输入约定"格式发出:

```
{题材}: 战神归来
{平台}: 抖音
{集数}: 10
{每集时长}: 180s
{Logline 草案}: 废婿三年归,扫平当年踩过他的人
{主题}: 真正的强者不需要他人证明
```

### 1.3 接收输出

A1 会输出:
- Logline 终稿(润色后,15-30 字)
- 主题精炼
- 受众画像
- **整剧铺垫与回收清单**(≥ 5 条)
- 整剧爽点分布概览
- N 集节拍表(每集 8 节拍)
- **原创风险报告**(6 维度)

### 1.4 卡口检查 ⭐

打开输出,**逐项自检,不通过的就让 A1 重写**:

- [ ] Logline 是否让你"读完就想看"?不行 → 重写
- [ ] 节拍表的"钩子(0-3s)"是否够狠?(每集 3 秒内能否抓住人)
- [ ] 铺垫回收清单 ≥ 5 条?每条都标了回收集?
- [ ] 原创风险报告是否全"低"?
  - 有"高"风险 → **用 A1 给的备选替换名**
  - 有"中"风险 → 自己判断要不要改

### 1.5 存档

存到:`我的作品/00X_<项目名>/01a_大纲.md`

> ⚠️ **如果对 A1 输出不满意,改 agent md 重跑——不要在对话里反复"再来一次"**。Agent 越用越好,迭代写在 md 里才能积累。

---

## 2 · A2 正文(2-4 小时)

### 2.1 配置

**新对话窗口 / 新 Project**,不要复用 A1 的窗口——避免上下文污染。

system prompt:`材料库/agent/A2_小说正文.md`

### 2.2 喂输入

把 `01a_大纲.md` 的**全文**粘贴给 A2。

### 2.3 接收输出

A2 会按节拍标签 `### [节拍 X · ...]` 分段输出全部 N 集正文,末尾附"写作自检"段。

### 2.4 卡口检查 ⭐⭐(最关键)

- [ ] 字数总计是否符合预期?(每集 4000-8000 字)
- [ ] 节拍标签是否全保留?(`grep "### \[节拍"` 应为 N × 8 行)
- [ ] **盖名测试**:拿出第 1 集,把所有角色名盖住,**能否分辨对白是谁说的**?
- [ ] **钩子测试**:翻每集结尾,是否有"想看下一集"的力度?
- [ ] **心理外化测试**:任翻 5 段心理戏,看有几段是"她非常愤怒"式直接告知?(应 ≤ 30%)

不通过 → 在 A2 对话里**精确指出哪集哪段哪条规则违反**,要求重写**那一段**——不要让 A2 全文重来(浪费 token 还掉质量)。

### 2.5 存档

存到:`我的作品/00X_<项目名>/01b_正文初稿.md`

---

## 3 · A3 精化(1-2 小时)

### 3.1 配置

新对话窗口。system prompt:`材料库/agent/A3_小说精化.md`

### 3.2 喂输入

两段:

1. `01b_正文初稿.md` 全文
2. 0.1 步整理的"材料库可复用资产清单",格式:
   ```
   已有角色:陆战神(出处:001) / 苏婉清(出处:002)
   已有场景:战神别墅_客厅
   ```
   如果没有可复用资产,写"无,全部新建"。

### 3.3 接收输出

- **4 张资产卡**(角色 / 场景 / 道具 / 武器法宝)
- **精化版全文**(变更点标 `<!-- 精化:[原因] -->`)
- **精化决策记录**
- **资产沉淀建议**

### 3.4 卡口检查

- [ ] 资产卡每个角色的外观要点 **5 项齐全**(人种 + 年龄 + 发型 + 关键面部 + 标志着装)?
- [ ] 每个场景关键元素 **≥ 3 个**且都是视觉可见物?
- [ ] 复用资产是否明确标了"复用"?
- [ ] 节拍位置零改动?(可用 `diff 01b 01c` 比对)
- [ ] 武器/法宝卡:若小说没出现就该空着(不强行编)

### 3.5 ⭐ 立即沉淀新资产到材料库

对**新建**的角色 / 场景,**当场就做**(记忆最新,补得最准):

- 新角色 → 复制资产卡到 `材料库/人物/<角色名>.md`,按 `材料库/人物/README.md` 模板补全(音色档案 / 服装变体 / 翻车点等)
- 新场景 → 复制场景卡到 `材料库/场景/<场景名>.md`,按 `材料库/场景/README.md` 模板补全

⚠️ **不要拖到作品完工再做**。

### 3.6 存档

存到:`我的作品/00X_<项目名>/01c_精化版.md`

---

## 4 · A4 审查(0.5-1 小时)

### 4.1 配置

新对话窗口。system prompt:`材料库/agent/A4_内容审查.md`

### 4.2 喂输入

```
{平台}: 抖音
{题材}: 战神归来
{精化小说}: <01c_精化版.md 全文>
```

### 4.3 接收输出

4 个子报告:
1. **合规层**:血腥 / 色情 / 政治 / 敏感
2. **改编可拍性层**:钩子 / 爽点 / 节拍 / 铺垫 / 对白 / 切换 / 集末钩子 / 题材爆点
3. **修订优先级矩阵**:P0 / P1 / P2 数量
4. **给作者的总结建议**(3-5 句,聚焦最重要的修订)

### 4.4 卡口决策

- **P0 必改**:全改,不改不发布
- **P1 建议改**:挑"提升明显的"改,其他放着
- **P2 可选**:能放就放

### 4.5 应用建议 + 输出完整版(关键闭环 ⭐)

A4 只审不写,**应用 P0/P1 建议是你的工作**。按修订量级选路径:

| 修订量级 | 操作方式 | 产出 |
|---|---|---|
| **小范围**(单段 / 单句修改,合规软化、对白微调) | **你自己手改** `01c_精化版.md` | 改完直接覆盖 |
| **中范围**(单集 1-2 段重写,如整段心理外化) | 回到 **A2 对话**(同一窗口最好,保留上下文),精确指出改哪集哪段,要求重写;然后回到 **A3 对话**重新精化变更段落 | 更新 `01c_精化版.md` |
| **大范围**(整集节奏 / 角色重构 / 反转重写) | 改 A1 大纲(`01a_大纲.md`)→ 回 A2 重跑变更集 → 回 A3 重新精化 | 更新 `01a / 01b / 01c` |
| **修订量 > 30%** | 强烈建议把改后正文**重新喂回 A4 再审一遍**(避免修订引入新问题) | 二次审查报告 → 覆盖 `01d_审查报告.md` |

### 4.6 输出终稿

应用完所有 P0(必改)+ 决定采纳的 P1 后:

- **审查报告** → `我的作品/00X_<项目名>/01d_审查报告.md`
- **最终小说**(应用建议后的完整版) → `我的作品/00X_<项目名>/01_小说.md`(终稿,可进下一阶段 A6 剧本生成)
- 在终稿头部加一段元数据:`<!-- 应用 A4 建议:P0 全改(N 项) / P1 改 M 项 / P2 全保留 -->`

## 常见卡点 + 应对

| 卡点 | 应对 |
|---|---|
| Logline 写不出来 | 看创作思维 A.1 公式,写 10 个备选再挑 1 个 |
| A1 节拍表写得太"四平八稳"没爆点 | 让 A1 把"中点反转"和"至暗时刻"重写,提高反转幅度 |
| A1 原创风险全"高" | 题材太红海,要么换"反差点"要么换冷门设定 |
| A2 写到一半节拍跑了 | 改 A2 system prompt 强化"节拍位置硬约束",新对话重跑 |
| A2 对白都像同一个人说的 | 在用户消息里追加:"用创作思维 A.8 节差异化策略重写第 N 集" |
| A3 资产卡太抽象不能生图 | 改 A3 prompt 加"必须可生图"硬约束(已含) |
| A4 报告太软不给具体改写 | 改 A4 prompt 加"必有具体改写文本"约束(已含) |
| 总耗时 > 12 小时 | 多半是反复改 logline / 大纲 → 这就是为啥 A1 卡口要严 |
