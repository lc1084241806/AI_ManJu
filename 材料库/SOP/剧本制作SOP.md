# SOP · 剧本制作阶段(流水线第 ④ 步)

> 用 **A6 → A7 → A8** 三个 agent,把"小说终稿"变成"可直接进入分镜的剧本成稿"。

|---|---|

## 0 · 前置准备(0.25 小时)

### 0.2 确认 5 个字段

| 字段 | 用在哪 |
|---|---|
| 题材 | A6 类型特化模块选择(玄幻 / 战神 / 言情 / 悬疑 / 恐怖 / 重生 / 现代) |

| 每集时长 | A6 字数 / 时长换算依据 |
| 平台 | A8 题材爆点审 |
| 小说总字数 | 估算剧本字数预期(≈ 1.5-2 倍) |

### 0.3 与 A5 三视图的关系

**A5 三视图(出图 prompt)和 A6 剧本生成可以并行**:
- 如已建 A5:开两个对话同时跑(并行省一半时间)
- 如未建 A5:**先跑 A6**,A5 留到出图阶段再跑也没问题——剧本不依赖 A5 输出

## 1 · A6 剧本生成(2-4 小时)

### 1.1 配置

DeepSeek 智能体 / Claude Project / 新对话,system prompt 用 `材料库/agent/A6_剧本生成.md` 全文。

### 1.2 喂输入

```
{小说终稿}: <01_小说.md 全文 + A3 资产卡>
{题材}: 战神归来
{集数}: 10
{平台}: 抖音
{每集时长}: 180s
```

### 1.3 接收输出

A6 会按"剧本格式标准"输出:
- 每集开头有 logline + 节拍位置标注
- 每集 N 场,场号 `N-1` ~ `N-X`
- 每场标:章节 / 序号 / 场景画面 / 人物 / 道具(关键/常规) / 对应小说节拍 / 预估时长
- 剧本正文用 △ 动作 + 角色对白 + (音效) + 转场标记
- **按题材自动注入特化标记**(玄幻的特效 / 战神的旁人反应 / 古风的服饰特写 / 悬疑的线索 ...)

### 1.4 卡口检查 ⭐⭐⭐

这是剧本阶段最关键的卡口。逐项自检:

- [ ] **集集对应**:小说第 N 集 → 剧本第 N 集场号 `N-1` ~ `N-X`?
- [ ] **对白原句保留**:任抽 5 句小说关键对白,对比剧本是否一字不差?
- [ ] **心理外化测试**:翻 5 段心理戏,看是否都转成动作 / 表情 / 环境音?(超过 50 字的内心独白 = 违规)
- [ ] **道具分级标注**:每场道具都标了"(关键)" / "(常规,特写×N)"?
- [ ] **类型特化标记**:按 {题材} 注入了对应模块的标记?
- [ ] **中文标点**:全文无英文标点("." → "。", "," → ",", '"' → """")
- [ ] **时长合理**:每场 1-3 分钟?总时长 ≈ {每集时长}?
- [ ] **镜头连接性完整**:动作有起承转合?(转身 → 走向 → 抬手 → 看向 这种连续不能缺中间)
- [ ] **节拍位置标注完整**:每集开头都标了 8 节拍对应的场号?

不通过 → 在 A6 对话里**精确指出哪集哪场哪条规则违反**,要求重写**那一场或那一集**——不要让 A6 全文重来。

### 1.5 存档

存到:`我的作品/<项目>/03a_剧本初稿.md`

## 2 · A7 剧本精简(0.5-1.5 小时)

### 2.1 配置

**新对话窗口**,不复用 A6 的——避免上下文污染。
system prompt:`材料库/agent/A7_剧本精简.md`

### 2.2 喂输入

`03a_剧本初稿.md` 全文。

### 2.3 接收输出

- 精简版剧本全文
- 删改说明表(删除统计 + 精彩度保障 + 字数变化)

### 2.4 卡口检查 ⭐⭐

- [ ] **镜头连接性 100% 保留**:对照 A6 原稿抽查 10 个动作,精简后是否完整?
- [ ] **对白实质不变**:抽查 5 句关键对白,精简后是否一字不差?
- [ ] **铺垫 / 伏笔 100% 保留**:对照 A1 大纲铺垫清单逐条核对
- [ ] **类型特化标记 100% 保留**:玄幻的特效 / 战神的旁人反应等不能丢
- [ ] **8 节拍位置 100% 保留**:每集开头的节拍标注不能丢
- [ ] **精简率 15-30%**:过低 = 没精简,过高 = 可能伤剧情
- [ ] **冲突戏全保留**:对峙 / 反转 / 爽点戏不能压缩

⚠️ **重点检查"镜头连接性"**:这是 A7 最容易出问题的地方。例:

A6 原稿:
```
△他缓缓站起。
△他走向妻妹。
△他抬手。
```
✅ A7 合理精简:`△他缓缓站起,走向妻妹,缓缓抬手。`(三动作合并,但起承转合保留)
❌ A7 错误精简:`△他抬手。`(从坐姿突然到抬手前,**后续分镜会跳帧**)

### 2.5 存档

存到:`我的作品/<项目>/03b_剧本精简.md`
删改说明存:`我的作品/<项目>/03b_删改说明.md`

## 3 · A8 连贯审查(0.5-1 小时)

### 3.1 配置

新对话窗口。system prompt:`材料库/agent/A8_剧本连贯审查.md`

### 3.2 喂输入

两段:
- `01_小说.md` 全文
- `03b_剧本精简.md` 全文
- (建议同时给 `01a_大纲.md` 用于铺垫清单审查)

### 3.3 接收输出

6 个子报告:
1. **集集对应审**(逐集节拍齐全度)
2. **关键信息保留审**(对白 / 铺垫 / 道具)
3. **场与场连贯审**(5 维:时间线 / 空间 / 道具流转 / 人物动机 / 配角)
4. **整体节奏审**(集钩子 / 爽点 / 题材爆点)
5. **修订优先级矩阵**(P0 / P1 / P2)
6. **给作者的总结建议**(≤ 200 字)

### 3.4 卡口决策

- **P0 必改**:全改,不改不发布(集集对应错误 / 关键对白丢失 / 铺垫断裂 / 时空跳跃)
- **P1 建议改**:挑提升明显的改
- **P2 可选**:能放就放

### 3.5 回头改

针对要改的项:
- **小范围**(单场调整):你自己手改更快
- **大范围**(整集调整):回到 A6 对话(同窗口),精确指出哪集哪场要重写

### 3.6 存档

- 审查报告 → `我的作品/<项目>/03c_审查报告.md`
- **最终剧本** → `我的作品/<项目>/03_剧本.md`(终稿,可进 A9 分镜)

## 常见卡点 + 应对

| 卡点 | 应对 |
|---|---|
| A6 输出对白被改写 | A6 prompt 加重"对白原句保留"约束,新对话重跑那一集 |
| A6 心理戏没外化(出现大段独白) | 用户消息追加:"按 A6 心理活动外化策略重写第 N 集第 X 场" |
| A6 类型特化标记缺失 | 检查输入字段 {题材} 是否填了;改后重跑 |
| A6 使用英文标点 | 直接在对话里说"全文换中文标点重新输出" |
| A7 精简过度删了镜头连接动作 | 让 A7 对照 A6 原稿恢复连续动作,合并而非删除 |
| A7 精简率 < 15% | 让 A7 重新精简,重点压缩龙套和车轱辘话 |
| A8 报告太笼统 | 改 A8 prompt 加重"结构化表格 + 具体改写建议"约束 |
| A8 漏审某集 | 在 A8 对话里直接补:"请补审第 N 集" |
| 总耗时 > 8 小时 | 多半是 A6 一次写整剧后段崩 → 分集喂入,每次只让 A6 处理 1-2 集 |
