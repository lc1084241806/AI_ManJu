# SOP · 分镜制作阶段(流水线第 ⑤ 步)

> 用 **A9 → A9b → A9c** 三个 agent,把"剧本终稿"变成"可直接喂给 A10 故事板的分镜词"。

---

## 阶段定位

| 项 | 内容 |
|---|---|
| 流水线位置 | ⑤ 分镜词制作 |
| 涉及 agent | A9(分镜骨架) / A9b(分镜增强) / A9c(分镜审查) |
| 上游输入 | `我的作品/<项目>/03_剧本.md`(A8 后的终稿) + A3 资产卡 |
| 时间预算 | **4-10 小时** |
| 产物存放 | `我的作品/<项目>/04_分镜.md` |
| 下一阶段对接 | A10 分镜→故事板(关键帧) → A11 图生视频 prompt |

## 0 · 前置准备(0.25 小时)

### 0.1 确认上游产物齐全

需要:
- [ ] `03_剧本.md` 终稿(A8 已审过)
- [ ] A3 输出的资产卡(角色 / 场景 / 道具 / 武器法宝)
- [ ] (建议)A1 大纲(查铺垫清单可能用到)

如缺,**回到剧本制作 SOP 补完**。

### 0.2 确认 3 个字段

| 字段 | 用在哪 |
|---|---|
| 题材 | A9 / A9b / A9c 的类型特化模块选择 |
| 平台 | A9c 合规审针对的平台(默认抖音) |
| 总分镜词预期 | 估算工作量(剧本每集 180s × 集数 = 总秒数;每片段 12-15s 算片段数) |

### 0.3 视频平台策略说明

本 SOP **新策略**:
```
分镜词(A9-c)→ 故事板/关键帧(A10) → 图生视频 prompt(A11) → 即梦 Seedance 2.0
```

**不再走老策略**(分镜词 → 直接文生视频),因为:
- 角色一致性靠图首帧锁更稳
- 故事板可反复调,失败成本低
- A5 三视图可直接喂 A10 做参考

## 1 · A9 分镜骨架(2-4 小时)

### 1.1 配置

DeepSeek 智能体 / Claude Project / 新对话,system prompt 用 `材料库/agent/A9_分镜骨架.md` 全文。

### 1.2 喂输入

```
{剧本终稿}: <03_剧本.md 全文>
{资产卡}: <A3 资产卡全部>
{题材}: 战神归来
```

### 1.3 接收输出

A9 会按"分镜骨架格式"输出:
- 每片段顶部 11 字段(片段编号 / 时长 / 场景 / 时间 / 内外 / 地点 / 人物 / 关键道具 / 负向提示词 / 全局风格 / 转场说明)
- 每镜头基础字段(画面描述 + 音效 + 台词 + 字幕 + 镜头结束状态)
- 占位一致性(道具持有者 / 角色站位 / 特效占位)
- **不含特效具体形状 / 色温 / 景别 / 运镜细节**(留给 A9b)

### 1.4 卡口检查 ⭐⭐⭐

这是分镜阶段最关键的卡口。逐项自检:

- [ ] **片段时长精确**:每片段所有镜头时长之和 = 片段总时长?
- [ ] **片段长度合理**:非末段 12-15s,末段 1-15s?
- [ ] **镜头时长合理**:每镜 1.5-5 秒(极短 1.2 / 极长 6 需理由)?
- [ ] **切割点在自然停顿**:跨片段切割点都在动作停顿处?
- [ ] **跨片段台词拆分**:都在句号 / 问号 / 感叹号后?后续片段标了"接上一片段,语气连续"?
- [ ] **跨片段衔接语**:都用"接上一片段结尾,..."开头?
- [ ] **跨场景转场**:都标了【转场说明】"渐隐渐显 + 转场字幕"?
- [ ] **旁白全部转换**:0 处独立旁白?
- [ ] **内心独白嘴闭**:所有内心独白镜头都标了"嘴巴闭合 / 嘴唇紧抿"?
- [ ] **占位一致性**:道具持有者 / 站位 / 特效落点跨片段复述了?
- [ ] **字幕三类分清**:转场字幕 / 剧情内字幕 / 对话台词字幕不混淆?对话台词字幕**不**在【字幕】字段?
- [ ] **类型特化模块**:按 {题材} 注入了对应模块的占位?
- [ ] **字段无简写**:无"同上""如上"?
- [ ] **未越界**:画面描述中**未**含色温 / 景别 / 运镜细节?(特效占位只标"落点 + 区域 + 大致类型",**不含**具体颜色形状;CG 质感词留给 A10)

不通过 → 在 A9 对话里**精确指出哪片段哪镜头违反**,要求重写**那一片段**——不要让 A9 全文重来。

### 1.5 存档

存到:`我的作品/<项目>/04a_分镜骨架.md`

## 2 · A9b 分镜增强(1-3 小时)

### 2.1 配置

**新对话窗口**,不复用 A9 的——避免上下文污染。
system prompt:`材料库/agent/A9b_分镜增强.md`

### 2.2 喂输入

```
{分镜骨架}: <04a_分镜骨架.md 全文>
{题材}: 战神归来
```

### 2.3 接收输出

- 增强版分镜词(在骨架上加了景别 / 特效 / 色温 / 运镜 / 特写,并重排时长)
- 增强清单(特效新增统计 / 色温分布 / 景别节奏 / 特写记录 / 时间线重排汇总)

### 2.4 卡口检查 ⭐⭐⭐

- [ ] **特效仅加在该加处**:打斗 / 动作 / 神兽 / 大功 / 法宝镜头加了,日常对话 / 走路 / 反应镜头未加?
- [ ] **特效不超 4 属性**:每个特效描述 ≤ 形状 + 颜色 + 材质 + 动态?
- [ ] **运镜白名单**:所有运镜方式都在(静止 / 推 / 摇 / 跟 / 慢动作 / 晃动)内?
- [ ] **运镜含角度**:每镜运镜都有平视 / 仰拍 / 俯拍 / 鸟瞰之一?
- [ ] **色温必标**:每镜都标了色温(色温名 + 数值)?
- [ ] **景别必标**:每镜都标了景别(远 / 全 / 中 / 近 / 特 / 大特)?
- [ ] **景别节奏**:无连续 3 镜以上同景别?
- [ ] **每片段重排说明**:都有【片段重排说明】字段?
- [ ] **总时长不变**:每片段总时长与 A9 骨架完全一致?
- [ ] **镜头时长之和**:精确 = 片段总时长?
- [ ] **未压含台词镜头**:有台词的镜头时长 ≥ 台词朗读时间?
- [ ] **骨架不动**:动作 / 对白 / 占位 / 切割点都没改?
- [ ] **类型特化特效偏好**:按 {题材} 用了对应特效偏好?

⚠️ **重点检查"时间线重排"**:这是 A9b 最容易出问题的地方。例:

A9 骨架:
```
镜头 1:3.5 秒(陆战神出手)
镜头 2:3 秒(对手反应)
镜头 3:7.5 秒(陆战神内心独白)
总:14 秒
```

✅ A9b 合理重排:
```
镜头 1:4 秒(+0.5,加金色拳风特效)
镜头 2:2.5 秒(-0.5,反应镜头无台词可压)
镜头 3:7.5 秒(不变,台词主导)
总:14 秒 ✓
```

❌ A9b 错误重排:
```
镜头 1:5 秒(+1.5)
镜头 2:3 秒(不变)
镜头 3:7 秒(-0.5,但台词需 8 秒)
总:15 秒 ✗(超出原 14 秒)+ 台词被切
```

### 2.5 存档

- 增强分镜 → `我的作品/<项目>/04b_分镜增强.md`
- 增强清单 → `我的作品/<项目>/04b_增强清单.md`

## 3 · A9c 分镜审查(0.5-1.5 小时)

### 3.1 配置

新对话窗口。system prompt:`材料库/agent/A9c_分镜审查.md`

### 3.2 喂输入

```
{增强分镜}: <04b_分镜增强.md 全文>
{题材}: 战神归来
{剧本终稿}: <可选,03_剧本.md 用于对照>
```

### 3.3 接收输出

6 个子报告:
1. **抖音 / 平台合规审**(色情 / 暴力 / 恐怖 / 政治 / 导向 / 未成年 6 类)
2. **即梦 AI 理解性审**(抽象隐喻 / 多主体动作 / 复杂特效 / 白名单外运镜 等 8 类)
3. **台词-时长吻合审**(逐镜核验字数 / 字/秒 / 时长,+ 内心独白 4 项 + 画外音残留扫描)
4. **镜头/片段连贯性审**(同片段内衔接 / 跨片段复述 / 跨场景转场 / 占位一致 / 回忆色调成对)
5. **修订优先级矩阵**(P0 / P1 / P2)
6. **给作者的总结建议**(≤ 200 字)

### 3.4 卡口决策

- **P0 必改**:全改,不改不发布(合规高风险 / 即梦无法生成 / 台词被切断)
- **P1 建议改**:挑提升明显的改
- **P2 可选**:能放就放

### 3.5 回头改

针对要改的项:
- **合规问题**(替换 / 软化措辞):你自己手改更快
- **即梦理解性问题**(改写画面描述):回到 A9b 对话(同窗口),指出哪镜要重写
- **台词-时长问题**(调时长 / 缩台词):回到 A9b 对话调时长;或回到剧本(A6 / A7)调台词

### 3.6 存档

- 审查报告 → `我的作品/<项目>/04c_审查报告.md`
- **最终分镜** → `我的作品/<项目>/04_分镜.md`(终稿,可进 A10 故事板)

注:A9b 输出的"增强清单"嵌在分镜词主体后,通常**与增强分镜同存一文件**(`04b_分镜增强.md`)。
若你希望分两文件存,可手动把增强清单部分粘到 `04b_增强清单.md`(可选)。

## 与新策略的关系(分镜→故事板→视频)

### 老策略 vs 新策略

| 维度 | 老策略 | 新策略(本 SOP 采用) |
|---|---|---|
| 流程 | 分镜词 → 即梦文生视频 | 分镜词 → A10 故事板 → A11 图生视频 prompt → 即梦图生视频 |
| 角色一致性 | 靠文字 prompt 死撑,经常崩 | 故事板锁人脸 / 服装 / 道具 |
| 失败成本 | 视频生成失败要从头跑 | 故事板先出,确认 OK 再图生视频 |
| A5 三视图作用 | 几乎用不上 | 直接喂 A10 做角色 reference |

### 本阶段产物给下游

| 字段 | 给谁 | 怎么用 |
|---|---|---|
| 画面描述(静态) | A10 故事板 prompt | 静态首帧出图 |
| 运镜 + 动作 + 时长 + 台词时间标注 | A11 图生视频 prompt | 从故事板首帧开始的运动描述 |
| 负向提示词 + 全局风格 | A10 + A11 | 风格 / 画质一致性 |
| 特效占位 / 色温 / 景别 | A10(出图)+ A11(运动) | 视觉一致性 |
| 字幕(剧情内 / 转场) | 后期工具 | 视频剪辑后期 |
| 音效 | 后期工具 / 即梦音效 | 视频混音 |

## 常见卡点 + 应对

| 卡点 | 应对 |
|---|---|
| A9 把特效 / 运镜细节也写了 | 在 A9 prompt 加重"不出特效细节"约束,新对话重跑那一片段 |
| A9 切割点在匀速动作中 | 用户消息追加:"P_X 切割点不在自然停顿,请改用'重叠动作补偿'方案" |
| A9 旁白没转内心独白 | 直接在对话里:"P_X-M_Y 的旁白请按规则转为内心独白" |
| A9 内心独白镜头没标嘴闭 | 全文检查,要求 A9 在所有内心独白镜头补"嘴唇紧抿" |
| A9b 加特效太复杂 | 让 A9b 简化:"P_X-M_Y 特效 ≤ 4 属性,请精简" |
| A9b 重排后总时长变了 | 强制让 A9b 重新计算每片段镜头时长之和 = 片段总时长 |
| A9b 压了含台词镜头 | 指出"P_X-M_Y 镜头 X 秒 < 台词 X 字所需 X 秒,请延长或缩台词" |
| A9c 报告太笼统 | 改 A9c prompt 加重"必引原文 + 具体改写文本" |
| A9c 漏审某项 | 在 A9c 对话里直接补:"请补审 P_X 的合规风险" |
| 总耗时 > 10 小时 | 多半是 A9 一次跑整剧后段崩 → 分集喂入,每次只让 A9 处理 1-2 集 |
