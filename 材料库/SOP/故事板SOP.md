# SOP · 故事板制作阶段(流水线第 ⑤ 步)

> 用 **D1 → D2 → D3** 三个 agent,把"分镜终稿"变成"可直接喂给 E1 图生视频的故事板首帧 prompt"。

---

## 阶段定位

| 项 | 内容 |
|---|---|
| 流水线位置 | ⑤ 故事板(含视觉设定集 + 关键帧) |
| 涉及 agent | D1(视觉设定集生成) / D2(视觉设定集审查) / D3(故事板关键帧 prompt,待建) |
| 上游输入 | `我的作品/<项目>/04_分镜.md`(C3 后的终稿) + A3 资产卡 + B1 剧本 + 选题阶段锁定的 `{画风}` |
| 时间预算 | **5-12 小时**(D1 视觉设定集 3-6h + D2 审查 0.5-1.5h + D3 关键帧 prompt 1-3h + 实际出图 N 小时另算) |
| 产物存放 | `我的作品/<项目>/04_视觉设定集/`(D1+D2 产出)+ `05_关键帧/`(D3 产出 + 实际出图) |
| 下一阶段对接 | E1 图生视频 prompt → 即梦/可灵图生视频 |
| 适配出图工具 | 即梦 / MJ / SD / Flux / 可灵图(prompt 通用) |
| 适配视频平台 | 即梦 Seedance 2.0(图生视频走 E1) |

---

## 0 · 前置准备(0.5 小时)

### 0.1 确认上游产物齐全

需要:
- [ ] `04_分镜.md` 终稿(C3 已审过)
- [ ] A3 输出的资产卡(角色 / 场景 / 道具 / 武器法宝 / 动物)
  - 武器法宝卡 §1.4 必须含"子类型(兵器/法宝)"列(A3 V1.4 起)
- [ ] B1 剧本终稿(可选,供 D1 查场次背景)
- [ ] 选题阶段已锁定 `{画风}`,且 `材料库/画风/<画风>.md` 风格包已存在
- [ ] 已确定 `{题材}`(纯古风 / 玄幻 / 仙侠 / 现代 / 科幻)

如缺,**回到上游 SOP 补完**:
- 缺分镜 → 分镜制作 SOP
- 缺资产卡子类型列 → A3 跑一次补"子类型"
- 缺风格包 → 去 `材料库/画风/` 建对应包(参考国漫CG_老师标准.md)

### 0.2 确认 4 个字段

| 字段 | 用在哪 |
|---|---|
| **{画风}** | D1 阶段 A 加载风格包注入渲染描述 |
| **{题材}** | D1 阶段 A 题材分流(决定保留/删除哪些模块) |
| 平台 | D2 审查时关注的合规重点(默认抖音,与 C3 一致) |
| 全角色 × 全服装变化清单 | 从 04_分镜.md 嵌入字段抽出,D1 阶段 B 展开依据 |

### 0.3 创建项目目录结构

```bash
mkdir -p 我的作品/<项目>/04_视觉设定集/{02_人物,03_兵器,04_神兽动物,05_法宝,06_道具,07_场景}
mkdir -p 我的作品/<项目>/05_关键帧
```

> 不必现在就建子目录里的文件,D1 跑批次时会按对应路径写入。

### 0.4 新策略说明

```
分镜词(C3)→ D1 视觉设定集生成(7 批次)→ D2 审查(三轮)→ D3 关键帧 prompt → 实际出图 → E1 图生视频 prompt → 即梦
                                                                                ↑
                                                            (本 SOP 结束于此,出图工具操作另起)
```

**为什么 D2 是必跑而不是可选**:D1 涉及 6 大模块、人物纯净/古风女鞋等数百条约束,LLM 自审是弱模式,必须独立 agent 审查才能稳定输出可用 prompt。这与 C1/C2/C3 三件套同款设计。

## 1 · D1 视觉设定集生成 · 阶段 A 模板定型(0.5 小时)

### 1.1 配置

DeepSeek 智能体 / Claude Project / 新对话,system prompt 用 `材料库/agent/D1_视觉设定集.md` 全文。

### 1.2 喂输入(阶段 A)

```
{阶段}: A
{画风}: <如 国漫CG_老师标准>
{题材}: <如 玄幻>
{风格包}: <把 材料库/画风/<画风>.md 全文粘贴>
```

> **默认行为**:若 `{画风} = 国漫CG_老师标准`,D1 会跳过风格包注入(老师基线即此风格);若是其他画风,D1 会把风格包的渲染描述 / 禁用清单 / 光影材质细则覆盖到基线模板。

### 1.3 接收输出(阶段 A)

D1 输出"定型模板.md":
- 头部标注画风 + 题材 + 已剥离哪些模块
- 6 模块按 §题材分流表 删除不适用项后的全文(画风注入完成的版本)

### 1.4 卡口检查 ⭐⭐

- [ ] 头部已标注画风 + 题材
- [ ] 题材分流表对应"删除"列模块整段移除(如纯古风无神兽/法宝)
- [ ] 适用模块文本逐字与基线一致(无概括/无改写,枚举式禁项完整)
- [ ] 若 ≠ 国漫CG_老师标准,风格包字段已覆盖渲染描述/禁用清单/光影细则

不通过 → 在 D1 对话里指出具体段落违反约束,要求重写**那一模块**。

### 1.5 存档

存到:`我的作品/<项目>/04_视觉设定集/00_定型模板.md`

## 2 · D1 视觉设定集生成 · 阶段 B 七批次(3-5 小时)

### 2.1 配置

**沿用 D1 同一对话窗口**(阶段 A 输出的定型模板已在上下文中,无需重新喂)。

或者新开对话窗口 + 把"定型模板.md"作为输入一起喂入。

### 2.2 七批次执行顺序

**纪律:一次只跑一个批次**,跑完一批等用户喂下一批指令。

#### 批次 0 · 元素清点(必须最先跑)

喂入:
```
{阶段}: B
{批次}: 0_元素清点
{A3 资产卡}: <粘贴 A3 全部 5 张卡>
{C3 分镜词}: <粘贴 04_分镜.md 全文,或重点贴出场角色 + 服装变化字段>
{B1 剧本}: <可选,03_剧本.md 全文>
```

接收输出:
- 元素清点表(C/W/F/P/A/S 编号)
- 服装变化展开清单
- 兵器双状态判定结果
- 神兽/动物子类型与特效分级判定
- 兵器/法宝拆分结果
- 待复用清单(已在材料库/人物/存在的角色)

存档:`04_视觉设定集/01_元素清点表.md`

**卡口** ⭐⭐⭐:
- [ ] 编号无跳号
- [ ] 服装变化清单与 04_分镜.md 一致
- [ ] 武器法宝按 A3 §1.4 子类型字段正确分流
- [ ] 已比对 材料库/人物/ 找出可复用资产

#### 批次 1-6 · 各模块逐批跑

| 批次 | 喂入 | 输出 | 存档 |
|---|---|---|---|
| `1_人物` | `{批次}: 1_人物` + 阶段 A 模板 + 清点表 | 每个 "角色 × 服装变化" 一个文件 | `04_视觉设定集/02_人物/<角色>_<服装>.md` 多文件 |
| `2_兵器` | `{批次}: 2_兵器` + ... | 每个兵器一/二文件(双状态者两个) | `03_兵器/<兵器名>_<状态>.md` |
| `3_神兽动物` | `{批次}: 3_神兽动物` + ... | 每个生物一个文件 | `04_神兽动物/<生物名>.md` |
| `4_法宝` | `{批次}: 4_法宝` + ...(纯古风跳过) | 每个法宝一个文件 | `05_法宝/<法宝名>.md` |
| `5_道具` | `{批次}: 5_道具` + ... | 每个道具一个文件 | `06_道具/<道具名>.md` |
| `6_场景` | `{批次}: 6_场景` + ... | 每个场景一个文件 | `07_场景/<场景名>.md` |

### 2.3 每批次接收后的卡口检查 ⭐⭐⭐

**批次 1 人物**(密度最高,逐角色 × 逐服装查):
- [ ] 每个 "角色 × 服装变化" 都出了独立文件
- [ ] 同角色多套服装的五官/瞳色/年龄/身份/原文体征字段完全一致
- [ ] 人物纯净约束完整保留(三时代悬挂物/背负物枚举不缺)
- [ ] 古风/玄幻男:须发按年龄分级 + 中国传统样式(无西式胡型)
- [ ] 古风/玄幻女:鞋履无任何现代高跟特征(11 项禁止枚举)
- [ ] 古风长衫合拢、内衬裤装存在、鞋口无露袜(非短打/裙开衩)
- [ ] 服装与鞋履洁净度匹配身份等级

**批次 2 兵器**:
- [ ] 有鞘者出 2 个文件(收纳 + 战斗),无鞘者 1 个
- [ ] 古风兵器无自发光(仅玄幻/仙侠允许灵气)
- [ ] 剑穗/飘带末端完整在画面内

**批次 3 神兽动物**:
- [ ] 神兽/妖兽特效分级正确(仙气/魔气/元素)
- [ ] 普通动物零特效(无发光/粒子/光晕)
- [ ] 纯古风题材神兽强制降级为普通动物
- [ ] 尾尖不触画面边缘

**批次 4 法宝**:
- [ ] 纯古风题材完全跳过本批次(并在交付时注明"跳过")
- [ ] 特效分级正确(仙家灵宝/魔道邪宝/元素灵宝/高科技/异能)
- [ ] 普通器物没误用法宝模板

**批次 5 道具**:
- [ ] 现代屏幕息屏无显示内容
- [ ] 默认崭新光滑(除非原文指定做旧)
- [ ] 无主动特效

**批次 6 场景**:⭐⭐⭐ 红线
- [ ] **空无一人**(无人物/类人生物/剪影/背影)
- [ ] **无任何动物**(无飞鸟/走兽/游鱼/昆虫/灵兽)
- [ ] 镜头选择(室外广角大景深;室内中焦浅景深)
- [ ] 纯古风场景无任何发光/粒子/悬浮/灵气元素

任一批次不通过 → 在 D1 对话里指出问题元素,要求**只重写那个元素**(不要全批次重来)。

### 2.4 存档

7 批次跑完后,目录结构应该是:

```
  04_神兽动物/<生物名>.md  ...
  05_法宝/<法宝名>.md  ...
  06_道具/<道具名>.md  ...
  07_场景/<场景名>.md  ...
```

## 3 · D2 视觉设定集审查(0.5-1.5 小时)

### 3.1 配置

**新对话窗口**,不复用 D1 的——避免上下文污染。
system prompt:`材料库/agent/D2_视觉设定集审查.md`

### 3.2 喂输入

```
{A11 全元素 prompt 集}: <把 04_视觉设定集/ 下所有 .md 文件按目录顺序粘贴>
{A11 元素清点表}: <01_元素清点表.md 全文>
{画风}: <如 国漫CG_老师标准>
{题材}: <如 玄幻>
{A3 资产卡}: <可选,用于反向核对>
{小说原文}: <可选,用于核对特殊外貌神态>
```

> 若设定集文件多到塞不下,分两批喂入:第一批 = 批次 0+1(清点表 + 人物),第二批 = 批次 2-6 + 终审清点核对。

### 3.3 接收输出

D2 输出审查报告:
1. **总体评估**(状态 / 三轮问题统计 / 风格包注入正确性)
2. **第一轮 · 人物模块专项审**(6 个子表:通用 / 古风玄幻 / 古风女鞋 / 现代科幻 / 跨服装一致性 / 风格包注入)
3. **第二轮 · 其他 5 模块审**(兵器 / 神兽动物 / 法宝 / 道具 / 场景)
4. **终审 · 元素清点核对**(双向闭环:清点表 → 输出 / A3 → 清点表)
5. **修订优先级矩阵**(P0 / P1 / P2)
6. **总结建议**(≤ 200 字)

### 3.4 卡口决策

- **P0 必改**:全改,不改不进入 D3
  - 人物纯净约束违反 / 古风女鞋现代特征 / 场景出现人或动物 / 纯古风出现神兽法宝 / 兵器双状态判定错 / 终审遗漏
- **P1 建议改**:挑提升明显的改
  - 跨服装一致性偏差 / 风格包注入不完整 / 普通动物加了轻微特效 / A3 漏抽
- **P2 可选**:能放就放

### 3.5 回头改

针对要改的项:
- **D1 输出问题**(具体某元素 prompt 错):回 D1 对话(同窗口),指出"清点编号 C-XX 的人物 prompt 改为 ___",重新生成那一个文件
- **A3 漏抽**(D2 反向核对发现):回 A3 补抽该元素 → 重跑 D1 批次 0 元素清点 → 重出该元素 prompt
- **风格包问题**(D1 阶段 A 注入不全):回 D1 阶段 A 重新加载风格包后,重跑受影响批次

### 3.6 存档

存到:`我的作品/<项目>/04_视觉设定集/99_审查报告.md`

### 6.5 D2 审查报告读法

- **P0 项**:逐条回 D1 重出对应元素;改完所有 P0 后再跑一次 D2(或人工复核 D2 给的建议是否被采纳)
- **P1 项**:能改就改,改不动的标注"接受不改"
- **P2 项**:可忽略

### 6.6 容易踩的坑

| 坑 | 症状 | 解法 |
|---|---|---|
| 一次发了多批次 | D1 把所有内容混在一个回复,模块约束被压缩 | 严格"一批一发",D1 内部已硬约束,但用户也要约束自己 |
| 风格包没喂 | D1 阶段 A 抱怨 {风格包} 缺失,或默认按基线跑 | 必须把风格包整段粘贴,即使是国漫CG 也要喂(让 D1 自己确认是默认风格) |
| A3 子类型字段缺失 | D1 兵器/法宝分流错 | 回 A3 跑一次补"子类型(兵器/法宝)"列 |
| 场景里出现人 | D2 审查时 P0 报错 | 回 D1 重出场景 prompt,强调"空无一人 + 无任何动物" |
| 角色五官在不同服装中不一致 | D2 跨服装一致性审报错 | 回 D1 重出受影响服装,强调"五官/瞳色/年龄字段完全照搬第一套" |
| 古风女鞋出现尖头/高跟 | D2 古风女鞋专项审报错 | 回 D1 重出,强调"汉服传统绣鞋 + 平直圆润鞋头 + 极薄千层底 + 11 项现代特征禁止" |

## 常见卡点 + 应对

| 卡点 | 应对 |
|---|---|
| D1 阶段 A 把基线模板"概括"了 | 在 D1 对话里强制要求"基线模板逐字保留,不得概括",新对话重跑 |
| D1 阶段 B 一次跑了多批次 | 强制"一次只跑一批",当前批次重发,要求只输出指定批次 |
| D1 批次 0 元素清点漏了角色 | 检查 A3 §1.1 角色卡是否完整,若 A3 漏 → 回 A3 补抽;若 D1 漏 → 在对话里追加"还有 XX 角色,请补到清点表" |
| D1 把兵器和法宝混了 | 检查 A3 §1.4 子类型字段;若 A3 缺该列 → 回 A3 跑 V1.4 补字段 |
| D1 给纯古风加了神兽 | 阶段 A 的题材分流没执行干净,回 D1 阶段 A 重新输出定型模板,确认神兽模块已删 |
| D2 审查太笼统 | 改 D2 prompt 加重"必引清点编号 + 三类问题打标 + 具体改写文本" |
| D2 漏了某模块审 | 在 D2 对话里追加"请补审批次 X" |
| D2 报告说"整体没问题" | 违反 D2 硬约束,要求"逐项打标,不允许整体性结论" |
| 反复改但出图还崩 | 画风包可能与出图工具不匹配,回 `材料库/画风/<画风>.md` 补"翻车记录"和"已验证的解法",或换个出图工具试 |
| 总耗时 > 12 小时 | 多半是 D1 阶段 B 一批次跑了所有元素 → 严格拆批,每批次完成立刻存档,避免重跑 |
| 角色一致性出图崩(同角色不同图脸不一样) | D1 prompt 没问题的话,问题在出图工具,要用"角色参考"或 IP-Adapter 锁脸,详见 阶段4_难点突破.md |
