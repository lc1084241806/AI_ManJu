# 画风:写实真人摄影

## 元数据
- 风格名:写实真人摄影
- 来源:用户提供的"现代都市男角色设定板"提示词中抽离的视觉风格层(2026-06-01)
- 适用题材:现代都市 / 商战 / 言情 / 悬疑 等真实世界题材(古风玄幻慎用)
- 适用工具:即梦 / MJ / SD / Flux / 可灵图 通用

- 与 CG 画风的区别:本风格要**真人摄影质感、影视剧实拍感**,明确排斥 CG / 二次元 / 插画 / 卡通
- 版本:V1.0
- 日期:2026-06-01

## 通用渲染描述(写入 D1 每模块提示词正文第一段)

**人物模块第一段**:
超写实真人摄影风格,真实摄影质感,影视剧角色设定图,真实演员质感。皮肤细节真实细腻,毛孔与光泽自然,发丝清晰,五官真实立体,人物比例自然。电影感光影,自然光影过渡,灰黑色调,简约都市感。严禁 CG 塑料感、卡通、二次元、插画风。

**道具/服饰模块第一段**:
产品摄影风格,真实摄影质感,面料纹理清楚,材质真实(布料/皮革/金属/针织),局部特写高清。自然光下材质高光与粗糙度真实,无卡通高光、无塑料感。

**场景模块第一段**:
真实世界摄影照片风格,使用真实相机参数与物理光照,真实材质质感,真实比例与透视。严禁动漫、二次元、插画、卡通、CG 动画感,无描边、无平涂、无塑料质感。

## 各模块光影/材质细则

### 人物模块
- 光影:电影感自然光,浅景深背景,光影统一柔和
- 皮肤:真实细腻,毛孔光泽自然,严禁磨皮死白与塑料感
- 头发:发丝清晰,自然蓬松带纹理
- 一致性:多视图 / 多表情须为同一演员,五官、发型、光影统一

### 服饰拆解模块
- 形式:产品摄影小图 + 局部特写(领口/拉链/面料纹理/裤腰/鞋面/鞋底)
- 材质:布料/皮革/针织/金属纹理真实清楚
- 配文:简短中文说明,排版整齐

### 饰品拆解模块
- 形式:竖向排列,产品摄影风格
- 说明文字简短,排版整齐

### 场景模块
- 真实相机参数 + 物理光照,真实透视
- 严禁舞台布景感 / 微缩模型感
