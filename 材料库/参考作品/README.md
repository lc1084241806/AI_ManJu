# 参考作品库

> **不是"看完写感想",是资产积累。**
> 每拆解一部作品,目标都是回答一个问题:"**这里有什么我能直接搬到自己作品里?**"
> **没有"可复用清单"的拆解 = 等于没拆。**

---

## 文件命名

```
材料库/参考作品/<平台>_<作品名>_<集>.md

例:
- 抖音_战神归来_第1-3集.md
- B站_某某修仙记_第1集.md
- 视频号_某甜剧_第10集.md
```

截图放本地子目录(不入 git):
```
材料库/参考作品/ref/<作品名>_<镜号>.png
```

---

## A · 选片纪律(看什么)

三条规矩:

1. **赛道对齐**:优先拆**你要做的赛道**(战神题材就拆战神,不要拆古风)
2. **数据优先**:拆**完播率 / 点赞高**的(平台数据为准,不是"我觉得好看")
3. **正反对照**:每拆 3-5 部头部,搭配拆 1 部**翻车作品**——好的难学,烂的好懂

**节奏**:每周拆 1-2 部,每月深拆 ≥ 2 部。

## B · 关注什么(完整维度清单)

不必每条都填。**⭐ 是必拆,其他选拆**。

### B.1 整体层 ⭐
- 题材 / 受众 / 平台 / 集长 / 集数
- 数据:点赞 / 评论 / 收藏 / 转发
- 标题 / 封面 / 标签
- 第一观感:**几秒被钩住 / 几秒想划走 / 看完什么感觉**

### B.2 编剧层 ⭐
- **开头 3 秒钩子**(用了什么手法:反差 / 悬念 / 冲突 / 视觉奇观?)
- 三幕结构(每幕多长 / 转折点在哪)
- 主角弧光(变了什么)
- 冲突类型(外 / 内 / 关系)
- **爽点**(几个 / 什么类型 / 放在哪)
- 反转(几次 / 怎么反)
- 钩子收尾(留什么悬念给下一集)

### B.3 导演层
- 场景数量 / 场景切换方式
- 信息密度(每镜头信息量)
- 心理外化方式(怎么把心理戏转画面)
- 场面调度(角色站位 / 视角选择)

### B.4 摄影层 ⭐(部分)
- ⭐ 镜头总数 / **平均时长**
- ⭐ **景别分布**(哪种景别占比高)
- 机位 / 运镜偏好
- 构图 / 留白
- 光线 / 调色
- 画风 / 一致性(人物 / 场景 / 风格)

### B.5 听感层
- 配音(音色 / 语速 / 情绪幅度)
- BGM(选型 / 卡点 / 出现位置)
- 音效(关键音效 / 转场音)

### B.6 后期层
- 剪辑节奏(快剪 / 慢镜的分布)
- 字幕(样式 / 位置 / 颜色)
- 转场方式

### B.7 运营层 ⭐
- ⭐ **评论区高赞**(看观众真实共鸣点)
- ⭐ **评论区差评**(看观众槽点)
- 同账号其他作品对比(找规律)

## C · 拆解成什么(产物清单)

每份拆解必须输出 5 件事:

### 1. 作品速写(1 段话)
60 字内,讲清"这是一部讲什么的、给谁看的、什么风格的作品"。

### 2. 量化数据
- 镜头数 / 总时长 / 平均镜头时长
- 景别分布(远 / 全 / 中 / 近 / 特 各占 X%)
- 爽点频率(平均每 N 秒一个)

### 3. 三亮点 + 三槽点
每项 **一句话总结 + 一句话解释为什么**。

### 4. ⭐ 可复用清单(必填,3-5 件)
**这是拆片唯一的硬产出**。每条格式:

> 我能搬:[具体动作]
> 用在哪:[我的哪部作品 / 哪种场景]
> 怎么搬:[具体怎么做]

例:
> 我能搬:开头用"主角被泼水 + 配旁白冷哼"建立反差
> 用在哪:001_战神归来 第 1 集开场
> 怎么搬:第一镜近景泼水 + 主角抬头微笑特写 + 旁白"三年前,这一巴掌他记住了"

### 5. 标签集(便于全文搜索)
固定写在文末。格式 `#类别_具体值`(见 D 节)。

## D · 标签规范

**初期不建专项子目录**——所有可复用元素用标签标记,做新作品时全文搜 `#推镜` 就能找到所有用过该手法的拆解。

**积累到 10+ 部作品 + 某标签出现 ≥ 5 次**,再单独抽出建专项库(`材料库/运镜模板/` 之类)——那时资料就现成的。

### 标准标签词表

| 类别 | 标签举例 |
|---|---|
| **钩子类型** | `#钩子_反差登场` `#钩子_家暴起源` `#钩子_穿越` `#钩子_失忆` `#钩子_重生` |
| **爽点类型** | `#爽点_打脸` `#爽点_认亲` `#爽点_救赎` `#爽点_甜爆` `#爽点_反杀` |
| **结构** | `#三幕标准` `#多反转` `#开放结尾` `#钩子收尾` |
| **景别偏好** | `#特写多` `#中景多` `#远景少` |
| **运镜** | `#推镜` `#拉镜` `#摇镜` `#跟镜` `#环绕` `#固定多` |
| **机位** | `#平视为主` `#仰拍登场` `#俯拍绝望` `#过肩对话` `#POV` |
| **光线** | `#侧光` `#逆光` `#低调光` `#高调光` `#暖光` `#冷光` `#伦勃朗` |
| **画风** | `#古风` `#现代` `#赛博` `#日漫` `#油画` `#3D写实` |
| **配音** | `#旁白叙事` `#男音磁性` `#女音清亮` `#情绪幅度大` |
| **BGM / 音效** | `#古风BGM` `#电子BGM` `#钢琴BGM` `#卡点剪辑` |
| **节奏** | `#慢启动` `#快开场` `#密集剪辑` `#情绪喘息` |
| **翻车点** | `#人物崩` `#场景跳` `#手部畸形` `#台词尬` `#口型错` `#光线乱` |

**自定义标签**自由发挥,但保持 `#类别_值` 的格式,方便后续聚合。

## E · AI 辅助拆解(把拆片成本从 2 小时压到 30 分钟)

人工逐镜拆一部完整作品要 1-2 小时,**AI 辅助能压到 20-40 分钟**。下面是 5 个实操方法。

### E.1 用 AI 拆台词(必用)

**工具链**:剪映 / 飞书妙记 提取字幕 → LLM 分析

1. 剪映打开作品 → 智能字幕 → 导出 SRT(或飞书妙记一键转写)
2. 喂给 DeepSeek / Claude:

```
你是资深短剧编剧。下面是一部 AI 漫剧的完整台词。请分析:
1. 三幕结构在哪一行分界?
2. 开头 3 秒的钩子是什么手法?
3. 全片有几个爽点?分别在第几行?属于什么类型(打脸/认亲/救赎/甜爆)?
4. 有几次反转?怎么反的?
5. 每句台词是否承担"推进剧情/塑造人物/营造情绪"中的一种?有没有水台词?
6. 如果提取这部作品的"钩子模板",会是怎样的句式?

台词:
[粘贴 SRT 内容]
```

### E.2 用多模态 AI 看图反推 prompt(必用)

**工具链**:截图 → GPT-4V / Claude / Gemini

1. 选 10-15 张关键镜头截图(开头钩子镜 + 爽点高潮镜 + 转场镜)
2. 喂给多模态 LLM:

```
你是 AI 漫剧的资深美术指导。请逐张分析以下截图:
1. 景别(远/全/中/近/特)
2. 机位(平视/仰拍/俯拍/过肩/POV)
3. 运镜倾向(从构图判断推/拉/摇/移/固定)
4. 光线类型(顺光/侧光/逆光/低调/高调)
5. 色调(冷/暖 + 主色)
6. 画风(古风/现代/日漫/写实)
7. 反推 prompt(中英文双语,可直接用)

我要把这些镜头手法,转成我能复用的 prompt 模板。
```

### E.3 用 AI 拆评论区(找观众真实反馈)

1. 翻评论区,**复制前 50 条高赞 + 10 条最长差评**
2. 喂给 LLM:

```
下面是一部 AI 漫剧的评论。请提炼:
1. 观众最在意的 3 个共鸣点(高赞集中讨论的)
2. 观众最常吐槽的 3 个槽点
3. 高频出现的"金句 / 梗"(观众自发传播的钩子)
4. 观众的"未满足期待"(他们希望但作品没给的)

评论:
[粘贴]
```

### E.4 用 AI 反推创作意图(进阶,找你的盲区)

完整台词 + 你的拆解笔记 + 截图描述 一并喂 LLM:

```
基于以上信息,假设你是该作品的编剧/导演,请回答:
1. 你为什么把开头钩子设计成这样?
2. 第 X 镜为什么用这个景别 / 运镜?
3. 如果让你写下一集,你会怎么写?为什么?
4. 这部作品最容易被新人忽视的"高级设计"是什么?

我会对照你的回答和我自己的拆解,找我的盲区。
```

### E.5 用 AI 直接套模板出初稿(最快路径)

把本 README 的 F 节"拆解笔记模板" + 完整台词 一起喂给 LLM:

```
请用我提供的模板拆解这部作品,逐项填空。我会基于你的初稿手动修订。

模板:
[粘贴本 README F 节模板]

作品信息:
- 平台:____
- 标题:____
- 完整台词:[粘贴]
- 关键镜头描述 / 截图:[粘贴或附图]
```

**铁律**:AI 出的初稿 ≠ 你的拆解。你必须基于自己的观感修订—— AI 帮你省掉的是"列框架"和"基础分析"的时间,**让你把精力聚焦在"我能学什么"上**。

## 与"我的作品"的协作

**拆解 ≠ 抄袭。** 沉淀到这里的是**手法 / 模板 / 结构**,不是"图片素材"或"台词原文"。

启动新作品时(在 `我的作品/<编号>_<名>/00_企划.md` 里):
1. **全文搜赛道关键词**(如 `战神 #打脸`)→ 找到 3-5 部相关拆解
2. **翻每篇拆解的"可复用清单"**→ 选 3-5 件搬过来
3. **创造性变形**:不能照搬桥段,但可以借鉴结构(例如"被泼水羞辱"换成"被踢出公司")

**拆解越多,新作品启动越快、底子越扎实。**

## 关于人物 / 场景为什么不进 `材料库/人物/` 和 `材料库/场景/`

那两个目录装的是**你自己作品角色 / 场景的锁定 prompt**(可直接生图用)。别人作品里的人物造型有版权风险,**只能抽象成"风格元素"借鉴,不能直接照搬 prompt 进生产**。

所以:
- 别人作品的人物截图 → 这里(`参考作品/ref/`),拆解里写**"我想学这个人设的什么特质"**(性格塑造手法 / 镜头表现手法),不是"我要这个长相"
- 你自己作品做出来的角色 → `材料库/人物/<角色名>.md`,这才是可复用生产资产
