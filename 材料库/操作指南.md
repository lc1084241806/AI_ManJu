# AI 漫剧 Agent 操作指南

> 拿来就跑。**不讲为什么,只讲怎么做**。
>
> 想了解概念去看 `材料库/agent/README.md`。

---

## §1 一次性准备

1. **agent 文件 = system prompt**。`材料库/agent/<编号>_xxx.md` 整文复制粘贴,贴到客户端的 system 槽位。
2. **每个 agent 开一个新对话窗口**。不要在一个窗口里切 agent。
3. **世界圣经.md** 放在 `我的作品/<作品名>/世界圣经.md`,每跑完一步就更新,每开新会话都把最新版贴进 user message。

### system prompt 怎么贴

| 客户端 | 操作 |
|---|---|
| Claude Web / Project | Custom Instructions → 贴整文 |
| Claude API | `system` 字段 |
| DeepSeek Web | 没有 system 字段,第一条 user message 贴整文,等回「已就绪」再发任务 |
| 豆包 / Kimi | 智能体设置 → System Prompt → 贴整文 |

## §2 粒度速查表

| Agent | 单次粒度 | 每次必带 | 最大 |
|---|---|---|---|
| A1 大纲 | 一次性(2 轮:推算-确认 + 出大纲) | — | 1 次 |
| A2 正文 | per 1-3 集 | 世界圣经 + A1 + 已生成集 logline | 3 集 |
| A3 精化 | per 1 集 | 世界圣经 + A1 + 本集 A2 + (可选)A4 采纳清单 | 1 集 |
| A4 审查 | per 5 集 | 世界圣经 + A1 + 本批 A3 | 8 集 |
| A5 阅读版导出 | per 1-5 集(旁路) | A2 或 A3 原文 | 5 集 |
| B1 剧本 | per 1 集 | 世界圣经 + 本集 A3 | 1 集 |
| B2 精简 | per 1 集 | 世界圣经 + 本集 B1 | 1 集 |
| B3 连贯审 | per 5 集 | 世界圣经 + A1 + 本批 B2 | 8 集 |
| C1 骨架 | per 1 集 | 世界圣经 + 本集剧本 + 资产卡 + 题材 | 1 集 |
| C2 增强 | per 1 集 | 世界圣经 + 本集 C1 + 题材 | 1 集 |
| C3 分镜审 | per 1 集 | 世界圣经 + 本集 C2 + 题材 | 1 集 |
| D1 视觉设定集 | 全局阶段 A + 阶段 B 7 批 | A3 资产卡 + 风格包 + 全集 C3 | 1 批/会话 |
| D2 视觉审查 | 全局一次 | D1 输出全集 + 元素清点表 | 1 次 |

## §3 启动语模板

复制粘贴改字段。

### A1 大纲(轮次 1 · 散文起手)

```
请按你的 system prompt 工作。这是新作品。

我的想法:
<3-10 句散文,讲题材方向 / 角色雏形 / 想要的爽点>

(已定字段直接说,如「集数 16 / 投抖音」)
```

→ 第一轮只回推算表 + 确认请求,不是大纲。

### A1 大纲(轮次 2 · 确认推算)

```
推算回复:
- 题材:通过
- 平台:改为 视频号
- 集数:通过
- 每集时长:通过
- Logline:改为「<新 logline>」
- 主题:补全「<15 字内>」

请出正式大纲。
```

### A1 大纲(老版本 · 字段全定好)

```
请按 system prompt 工作。所有字段已定,跳过推算-确认。

题材:战神
集数:16
每集时长:180s
平台:抖音
Logline:<...>
主题:<...>

核心想法:
<3-10 句>
```

### A2 正文(首次)

```
本次首次执行,初始化世界圣经,生成第 1 集。

A1 大纲:
<贴 A1 输出>

集编号:第 1 集
世界圣经:首次,请初始化
```

### A2 正文(后续)

```
本次生成第 4-5 集。

A1 大纲:
<贴>

集编号:第 4-5 集

世界圣经:
<贴最新版>

已生成集 logline:
- 第 1 集:<1-2 句>
- 第 2 集:<1-2 句>
- 第 3 集:<1-2 句>
```

### A3 精化(初次)

```
精化第 3 集。

本集 A2:
<贴>

世界圣经:
<贴>

A1 大纲:
<贴>
```

### A3 精化(回炉 · A4 审查后)

```
按 A4 报告回炉重写第 3 集。

本集 A3 V1:
<贴>

世界圣经:
<贴>

A1 大纲:
<贴>

A4 报告:
<贴全文,含 6 个子报告>

采纳项:P0-1, P0-2, P0-3, P1-2, P1-5
(或「全部 P0+P1」)
```

→ 产出标 `〔回炉:A4-P0-1〕` 的 V2。

### A4 审查

```
批审第 1-5 集。

平台:抖音
题材:战神
批次:第 1-5 集

本批 A3:
<贴 1-5 集 A3>

世界圣经:
<贴>

A1 大纲:
<贴>
```

→ 末尾「子报告 6 采纳清单」勾选完拿去 A3 回炉。

### A5 阅读版导出

```
导出为纯阅读版。

导出范围:第 1-3 集

工程稿:
<贴 A2 或 A3>
```

### B1 剧本

```
生成第 1 集剧本。

本集 A3:
<贴>

世界圣经:
<贴>

题材:战神
平台:抖音
每集时长:180s
```

### B2 / B3 / C1 / C2 / C3

结构都是「本集材料 + 世界圣经 + 上下文字段」,直接照 agent 文件 §输入约定 填。

### D1 / D2

见 `材料库/SOP/故事板SOP.md` §3-§5。

## §4 出问题怎么救

| 症状 | 一句话救法 |
|---|---|
| 模型主动续写、问"是否继续" | 回「按 §0 行为约束,只处理本轮」。反复出现重开会话重贴 system |
| 输出 HTML / 整文代码块 | 回「按 §0 只用 Markdown,重输」 |
| 跨集失忆、角色写错 | 检查世界圣经是不是最新版,重贴 |
| 输出半截被截断 | 回「从 <断点> 继续」,或下次降规模(3 集 → 1 集) |
| 漏字段 / 加多余字段 | 回「严格按 §输出 Schema,补 X,删 Y」 |
| 模型当聊天机器人("您好…") | system prompt 没生效。DeepSeek Web 要用第一条 user message 贴 |
| 题材模块不对(战神写成古风) | 启动语显式指定题材,从 10 个枚举选(战神/总裁/修仙玄幻/重生穿越/古风宫斗/复仇/甜宠言情/现代都市/悬疑/恐怖) |
| 多 agent 串味 | 每个 agent 一个新窗口 |
| A1 第一轮没出大纲只回推算表 | 正常。按 §3「A1 轮次 2」回复确认 |
| A4 审查完只给报告 | 正常。按 §3「A3 回炉」拿采纳清单回 A3 |
| 节拍标签碍眼想读小说 | 跑 §3「A5 阅读版导出」 |
