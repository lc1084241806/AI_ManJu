# AI 漫剧 Agent 操作指南

> 拿来就跑。**不讲为什么,只讲怎么做**。
>
> 想了解概念去看 `材料库/agent/README.md`。

---

## §1 一次性准备

1. **agent 文件 = system prompt**。`材料库/agent/<编号>_xxx.md` 整文复制粘贴,贴到客户端的 system 槽位。
2. **每个 agent 开一个新对话窗口**。不要在一个窗口里切 agent。
3. **世界圣经.md** 放在 `我的作品/<作品名>/世界圣经.md`,每跑完一步就更新,每开新会话都把最新版贴进 user message。

### system prompt 怎么贴

| 客户端 | 操作 |
|---|---|
| Claude Web / Project | Custom Instructions → 贴整文 |
| Claude API | `system` 字段 |
| DeepSeek Web | 没有 system 字段,第一条 user message 贴整文,等回「已就绪」再发任务 |
| 豆包 / Kimi | 智能体设置 → System Prompt → 贴整文 |

## §2 粒度速查表

| Agent | 单次粒度 | 每次必带 | 最大 |
|---|---|---|---|
| A1 大纲 | 一次性(2 轮:推算-确认 + 出大纲) | — | 1 次 |
| A2 正文 | per 1-3 集 | 世界圣经 + A1 + 已生成集 logline | 3 集 |
| A3 精化 | per 1 集 | 世界圣经 + A1 + 本集 A2 + (可选)A4 采纳清单 | 1 集 |
| A4 审查 | per 5 集 | 世界圣经 + A1 + 本批 A3 | 8 集 |
| A5 阅读版导出 | per 1-5 集(旁路) | A2 或 A3 原文 | 5 集 |
| B1 剧本 | per 1 集 | 世界圣经 + 本集 A3 | 1 集 |
| B2 精简 | per 1 集 | 世界圣经 + 本集 B1 | 1 集 |
| B3 连贯审 | per 5 集 | 世界圣经 + A1 + 本批 B2 | 8 集 |
| C1 骨架 | per 1 集 | 世界圣经 + 本集剧本 + 资产卡 + 题材 | 1 集 |
| C2 增强 | per 1 集 | 世界圣经 + 本集 C1 + 题材 | 1 集 |
| C3 分镜审 | per 1 集 | 世界圣经 + 本集 C2 + 题材 | 1 集 |
| D1 视觉设定集 | 全局阶段 A + 阶段 B 7 批 | A3 资产卡 + 风格包 + 全集 C3 | 1 批/会话 |
| D2 视觉审查 | 全局一次 | D1 输出全集 + 元素清点表 | 1 次 |

## §3 启动语模板

复制粘贴改字段。

### A1 大纲(轮次 1 · 散文起手)

```
请按你的 system prompt 工作。这是新作品。

我的想法:
<3-10 句散文,讲题材方向 / 角色雏形 / 想要的爽点>

(已定字段直接说,如「集数 16 / 投抖音」)
```

→ 输出:推算表 + 6 字段确认请求(不是大纲)
→ 人工:按下一段「轮次 2」回复确认 / 修改 / 补全

### A1 大纲(轮次 2 · 确认推算)

```
推算回复:
- 题材:通过
- 平台:改为 视频号
- 集数:通过
- 每集时长:通过
- Logline:改为「<新 logline>」
- 主题:补全「<15 字内>」

请出正式大纲。
```

→ 输出:全集大纲(每集 logline + 8 节拍预案)
→ 人工:存 `我的作品/<作品名>/01_A1大纲.md`

### A1 大纲(老版本 · 字段全定好)

```
请按 system prompt 工作。所有字段已定,跳过推算-确认。

题材:战神
集数:16
每集时长:180s
平台:抖音
Logline:<...>
主题:<...>

核心想法:
<3-10 句>
```

→ 输出:全集大纲
→ 人工:存 `我的作品/<作品名>/01_A1大纲.md`

### A2 正文(首次)

```
本次首次执行,初始化世界圣经,生成第 1 集。

A1 大纲:
<贴 A1 输出>

集编号:第 1 集
世界圣经:首次,请初始化
```

→ 输出:第 1 集小说正文 + 世界圣经初始化版
→ 人工:小说存 `02_A2小说/第01集.md`;**世界圣经初始化版整段保存为** `世界圣经.md`

### A2 正文(后续)

```
本次生成第 4-5 集。

A1 大纲:
<贴>

集编号:第 4-5 集

世界圣经:
<贴最新版>

已生成集 logline:
- 第 1 集:<1-2 句>
- 第 2 集:<1-2 句>
- 第 3 集:<1-2 句>
```

→ 输出:本批小说正文 + 世界圣经增量段(B 段)
→ 人工:每集分别存 `02_A2小说/第NN集.md`;**把增量段按章节号合并到 `世界圣经.md`**(§N 角色变化 / §N 场景新增等)

### A3 精化(初次)

```
精化第 3 集。

本集 A2:
<贴>

世界圣经:
<贴>

A1 大纲:
<贴>
```

→ 输出:精化版本集(Part 2) + 5 张资产卡(Part 1) + 人物分支扩展表(Part 3) + 情节强化记录(Part 4) + 世界圣经增量(Part 6)
→ 人工:
- 精化版存 `03_A3精化/第NN集.md`
- 资产卡按角色/场景/道具/兵器法宝/动物分别 **建档或更新** 到 `材料库/人物/<角色>.md` / `材料库/场景/...` / `材料库/道具/...`
- 世界圣经增量合并到 `世界圣经.md` 对应章节

### A3 精化(回炉 · A4 审查后)

```
按 A4 报告回炉重写第 3 集。

本集 A3 V1:
<贴>

世界圣经:
<贴>

A1 大纲:
<贴>

A4 报告:
<贴全文,含 6 个子报告>

采纳项:P0-1, P0-2, P0-3, P1-2, P1-5
(或「全部 P0+P1」)
```

→ 输出:V2 精化版(带 `〔回炉:A4-P0-1〕` 标注)
→ 人工:覆盖 `03_A3精化/第NN集.md`(或存 V2 副本另起文件名,任选)

### A4 审查

```
批审第 1-5 集。

平台:抖音
题材:战神
批次:第 1-5 集

本批 A3:
<贴 1-5 集 A3>

世界圣经:
<贴>

A1 大纲:
<贴>
```

→ 输出:子报告 1 合规审 + 子报告 2 改编审 + 子报告 3 优先级矩阵 + 子报告 4 总结建议 + 子报告 5 世界圣经校准 + 子报告 6 可勾选采纳清单
→ 人工:
- 报告整文存 `04_A4审查/第NN-NN集审查.md`
- 把 **子报告 5 校准段追加到** `世界圣经.md §9`
- 勾选 **子报告 6 采纳清单**(P0 默认全勾) → 拿这份清单回 A3 走「回炉模式」

### A5 阅读版导出

```
导出为纯阅读版。

导出范围:第 1-3 集

工程稿:
<贴 A2 或 A3>
```

→ 输出:去节拍标签 / 去精化标注的纯阅读稿
→ 人工:存 `阅读版/第NN-NN集.md` 或直接复制发给读者

### B1 剧本

```
生成第 1 集剧本。

本集 A3:
<贴>

世界圣经:
<贴>

题材:战神
平台:抖音
每集时长:180s
```

→ 输出:本集分场剧本(8 大段 · 场号 / 时间 / 地点 / 出场人 / 画外音 / 动作 / 对白 / 音效)
→ 人工:存 `05_B1剧本/第NN集.md`,等 B2 精简

### B2 / B3 / C1 / C2 / C3 / D1 / D2

| Agent | 启动语依据 | 输出 | 人工 |
|---|---|---|---|
| B2 精简 | agent 文件 §输入约定 | 本集精简剧本(删冗余 / 压台词 / 中文标点修复) | 覆盖 `05_B1剧本/第NN集.md` 或存 `05_B2精简/第NN集.md` |
| B3 连贯审 | 同上 | 6 子报告(时间线 / 逻辑 / 道具流转 / 铺垫回收 / 题材爆点 / 优先级) | 报告存 `06_B3审查/第NN-NN集.md`;P0/P1 项手动回 A3 / B1 / B2 改 |
| C1 骨架 | 同上 + 题材 + 资产卡 | 本集分镜骨架(片段 + 镜头 + 时长 + 角色/场景/道具占位,无特效细节) | 存 `07_C1骨架/第NN集.md` |
| C2 增强 | 同上 | 本集增强分镜(加特效 / 色温 / 景别 / 运镜 / 重排时长) | 存 `07_C2增强/第NN集.md` |
| C3 分镜审 | 同上 | 4 层审查报告(合规 / 即梦理解性 / 台词时长 / 镜头连贯) | 报告存 `07_C3审查/第NN集.md`;P0/P1 项手动回 C1 / C2 改 |
| D1 视觉设定集 | `材料库/SOP/故事板SOP.md` §3 | 7 批次按模块分文件的绘图 prompt(0 清点 + 人物/兵器/神兽/法宝/道具/场景) | 每批存 `08_D1视觉设定集/<模块>.md`;喂入 MJ/SD/即梦出图,出图存 `08_D1视觉设定集/参考图/` |
| D2 视觉审 | `材料库/SOP/故事板SOP.md` §5 | 三轮审查报告(人物专审 + 5 模块审 + 终审清点) | 报告存 `08_D2审查.md`;P0/P1 项回 D1 重出 |

> 启动语结构都是「本集材料 + 世界圣经 + 上下文字段」,具体字段照 agent 文件 §输入约定 填。

## §4 出问题怎么救

| 症状 | 一句话救法 |
|---|---|
| 模型主动续写、问"是否继续" | 回「按 §0 行为约束,只处理本轮」。反复出现重开会话重贴 system |
| 输出 HTML / 整文代码块 | 回「按 §0 只用 Markdown,重输」 |
| 跨集失忆、角色写错 | 检查世界圣经是不是最新版,重贴 |
| 输出半截被截断 | 回「从 <断点> 继续」,或下次降规模(3 集 → 1 集) |
| 漏字段 / 加多余字段 | 回「严格按 §输出 Schema,补 X,删 Y」 |
| 模型当聊天机器人("您好…") | system prompt 没生效。DeepSeek Web 要用第一条 user message 贴 |
| 题材模块不对(战神写成古风) | 启动语显式指定题材,从 10 个枚举选(战神/总裁/修仙玄幻/重生穿越/古风宫斗/复仇/甜宠言情/现代都市/悬疑/恐怖) |
| 多 agent 串味 | 每个 agent 一个新窗口 |
| A1 第一轮没出大纲只回推算表 | 正常。按 §3「A1 轮次 2」回复确认 |
| A4 审查完只给报告 | 正常。按 §3「A3 回炉」拿采纳清单回 A3 |
| 节拍标签碍眼想读小说 | 跑 §3「A5 阅读版导出」 |
