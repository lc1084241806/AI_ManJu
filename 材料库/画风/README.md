# 画风库

> 沉淀每种画风的"渲染参数包":分辨率 / 渲染引擎 / 材质流程 / 光影体系 / 美学定位 / 禁用清单。
> 一个画风一个 .md 文件,**这是解决"全流水线视觉风格统一"的核心仓库**。

---

## 画风 vs 题材的区别

| | 决定什么 | 何时定 | 影响哪些 agent |
|---|---|---|---|
| **画风** | 用什么渲染美学呈现(国漫CG / 日系2D / 水墨 / 像素 / 写实 / 赛博朋克霓虹...) | ① 选题策划阶段 | C1 全局风格字段 / **D1 视觉设定集** / D3 故事板 / E1 图生视频 |
| **题材** | 故事的世界类型(纯古风 / 玄幻 / 现代 / 科幻) | ① 选题策划阶段 | A1 大纲 / A2 正文 / A3 资产卡 / B1 剧本 / C1 分镜 / D1 模块开关 |

画风和题材**正交**——同一个题材可以套不同画风,同一个画风可以承载不同题材。

---

## 何时设定画风

画风**必须在 ① 选题策划阶段就锁定**,写入 `我的作品/<项目>/00_企划.md`。理由:
- 决定你能复用哪个 LoRA / 哪个工具栈 / 哪个画师
- 决定 C1 分镜的"全局风格"字段怎么填
- 决定 D1 视觉设定集的渲染描述用哪一段
- 决定 D3 / E1 出图视频时的 prompt 后缀

**一部作品锁一种画风,中途不换**(换 = 重做视觉设定集 + 重出全部关键帧)。

## 文件命名

```
材料库/画风/<画风名>_<可选说明>.md
```

例:
- `国漫CG_半写实.md`(默认,老师 2026-05-25 提供)
- `次世代CG_超写实.md`(照片级超写实、游戏次世代建模质感)
- `日系2D.md`
- `水墨.md`
- `赛博朋克霓虹.md`
- `写实电影感.md`

## 与 Agent 的接口

### D1 视觉设定集
D1 阶段 A 接收 `{画风}` 变量后:
1. 加载对应风格包 `材料库/画风/<画风>.md`
2. 把风格包的"通用渲染描述"覆盖到基线模板每个模块"提示词正文"的第一段
3. 把风格包的"通用禁用清单"覆盖到每模块"画面绝对不包含"段
4. 把风格包的"各模块光影/材质细则"覆盖到对应模块的相关字段
5. 输出定型模板

**默认行为**:若 `{画风}` = `国漫CG_半写实`,基线模板原样输出(老师基线即此画风)。

### C1 分镜骨架(轻度联动)
C1 输出的每片段"全局风格"字段建议从风格包 §C1 字段建议值 复制。

### D3 / E1(下游联动)
每镜 prompt 末尾建议附加风格包 §D3/E1 prompt 后缀,确保画风一致性贯穿到视频。
