# 材料库

> **作用**:沉淀"可复用的资产"——人物 / 场景 / Agent,让下一部作品的制作时间不断下降。
> **原则**:不预判结构,**学到漫剧某步后自然知道还需要什么**,届时再加子目录。

---

## 当前结构

```
材料库/
  人物/        角色 IP 库:人设 + 参考图(本地) + 提示词模板 + 音色档案
  场景/        场景库:主场景定型 + 参考图(本地) + 提示词模板
  画风/        画风库:每种画风的渲染参数包(分辨率/引擎/材质/光影/禁用清单),供 D1 阶段 A 注入
  agent/       15 个阶段性 agent 的 system prompt(.md 文件,可直接复制粘贴使用)
  参考作品/    拆解笔记库:别人作品的"可复用清单" + 手法 / 模板 / 结构沉淀
  SOP/         标准作业程序:把多个 agent 串成完整工作流(每阶段一份)
```

## 使用规范

### 通用规范
1. **每个子目录有自己的 README.md**,说明该类资产的写法和使用方法
2. **大文件(图片 / 视频 / 音频)放本地,不入 git**(`.gitignore` 已配置)
3. **md 文件入 git**,保证可追溯、可对比、可同步

### 命名规范
- 人物:`<角色名>.md`(如 `陆战神.md`)
- 场景:`<场景名>.md`(如 `战神别墅_客厅.md`)
- agent:`A<编号>_<功能名>.md`(如 `A2_小说正文.md`)
- 参考作品:`<平台>_<作品名>_<集>.md`(如 `抖音_战神归来_第1-3集.md`)
- SOP:`<阶段名>SOP.md`(如 `小说创作SOP.md`)

### 沉淀习惯
- **每攻破一个翻车点**:更新对应资产的"容易翻车的细节"段
- **每解决一个一致性问题**:更新"使用过的解法"段
- **每个 agent 修订后**:更新"修订记录"

## 与"我的作品"的关系

```
材料库/(可复用)
  ↓ 调用
我的作品/<项目>/(具体一部作品)
```

新作品启动时,**第一件事就是检查材料库**:
- 角色能复用哪些?
- 场景能复用哪些?
- 哪些 agent 需要新版本?
- **参考作品里有哪些"可复用清单"能搬过来**?

复用越多,做新作品越快。
