# 场景库

> 沉淀每个主要场景的"可复用资产":风格定调 + 视觉锁定 prompt + 多角度参考图 + 时间变体。
> 一个场景一个 .md 文件,解决"场景一致性"难题的核心仓库。

---

## 文件命名

```
材料库/场景/<场景名>.md
```

例:
- `战神别墅_客厅.md`
- `天玄宗_主殿.md`
- `小镇咖啡馆.md`

---

## "主场景策略"

每个 IP / 题材系列,**锁定 3-5 个主场景**(主角家 / 公司 / 餐厅 / 街道 / 反派老巢),80% 镜头发生在这些主场景里。

这样:
- 跨集场景一致性自动保证
- 用户产生"熟悉感"(像电视剧里"那个客厅")
- 出图效率最大化(场景 prompt 完全复用)

---
