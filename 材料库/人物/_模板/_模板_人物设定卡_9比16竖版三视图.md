# 模板:人物设定卡(出图排版骨架)

> **这不是某个具体角色,是出图排版的填空模板。**
> 文件名加 `_模板_` 前缀,排在人物目录最前,与真实角色文件(如 `苏婉清.md`)区分。

---

## 怎么用

对我说:**「按 <画风> + 人物设定卡,生成一个 <角色一句话描述>」**

例:
- 「按 国漫CG_半写实 + 人物设定卡,生成一个清冷剑修女主」
- 「按 次世代CG_超写实 + 人物设定卡,生成一个炼丹师女主」
- 「同上,再出个反派男配」

我会:
1. 读本模板拿到**排版骨架 + 要填的字段**
2. 读 `材料库/画风/<画风>.md`,把渲染关键词填进【画风插槽】
3. 按你的描述填【可变层】各字段
4. 拼成一整段可直接粘贴的出图 prompt

你只需说三件事:**哪个画风 + 用人物设定卡 + 角色是谁**。

## 【画风插槽】(出图时按所选画风替换)

> 默认:本仓库 `材料库/画风/` 下的画风包"人物模块渲染描述"。
> - 选 `次世代CG_超写实` → 超写实次世代CG、影视级建模、游戏角色设定图质感
> - 选 `国漫CG_半写实` → 半写实国漫审美、伦勃朗光+边缘光、陶瓷肤质
> 出图时此段被替换为对应画风包的"人物模块第一段"。

## 【固定层】画面结构(排版骨架,不要改)

9:16 竖版构图,规整排版,角色设定板,三视图+细节展示。
- 左侧:人物正面全身立绘
- 右侧:正面 / 侧面 / 背面三视图排版
- 下方与侧边:局部细节特写(脸部、发饰、服装纹理、饰品、足部)
- 整体 UI 风格干净高级

## 完整示例(参考:东方玄幻炼丹师女主)

> 下面是本模板填充后的样子,供对照。画风插槽此处用"超写实次世代CG"。

```
[画风插槽=次世代CG_超写实]
3D次世代角色设定图,电影级CG质感,超写实渲染,Unreal Engine 5风格,PBR物理材质,
全局光照,体积光,柔和冷调自然光,8K超高清。

[画面结构]
9:16竖版,角色设定板,三视图+细节展示。左侧正面全身立绘;右侧正面/侧面/背面三视图;
下方与侧边局部细节特写;UI风格干净高级。

[角色] 东方玄幻,天秤座,女性,约25-30岁。气质温柔优雅但带强控制感,恬静中带刁蛮,
成熟但不老,带隐约危险气息,有故事感。

[脸部] 柔和鹅蛋脸,下颌线干净不锋利;五官精致自然偏成熟,骨相立体但柔和;
细长丹凤眼/微垂桃花眼,上眼睑略压,眼神温和却带掌控力;鼻梁柔挺;唇形饱满,
嘴角微微一侧上扬带轻微戏谑;皮肤白皙带暖调,真实质感与细微光泽。

[发型发饰] 乌黑或深棕长发,半束发或松散低挽,发丝蓬松带细碎碎发与轻微凌乱(像刚炼完丹);
发饰简约:桂花玉簪/细金属簪/小型丹瓶挂饰/细链坠。

[服装] 东方轻奢炼丹风,贴身上身+流动长裙摆,多层半透明轻纱,袖宽内层收紧(功能性),
桂花底纹刺绣;材质轻纱/丝绸/少量金属点缀;主色米白/暖灰/淡杏,辅以琥珀色/暗红细节
(象征丹火与过往情感)。

[关键元素] 腰间多个精致小桂花金链流苏、小玉瓶;饰品带旧物感(微裂玉佩/旧戒指/略磨损发簪,
暗示过往情史);指尖干净修长,带一点药粉或微光残留。

[气质] 整体温柔安静但隐约压迫,像轻声说话却让人不敢违抗,带慵懒与掌控欲。

[动作] 自然站立,或轻托手腕,或指尖轻触药瓶,放松但有掌控感。

[细节展示区] 面部特写(眼神表情);发饰细节;胸口与服装纹理;桂花底纹与饰品;
裙摆与材质层次;足部(精致高跟或软靴,带细链或装饰)。
```
