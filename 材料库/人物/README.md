# 人物库

> 沉淀每个角色的"可复用资产":人设 + 视觉锁定 prompt + 参考图 + 音色档案 + 翻车经验。
> 一个角色一个 .md 文件,**这是解决"人物一致性"难题的核心仓库**。

---

## 文件命名

```
材料库/人物/<角色名>.md
```

例:
- `陆战神.md`
- `苏婉清.md`
- `阿狸.md`

---

## 大文件存放

参考图(.png / .jpg)放在 `材料库/人物/ref/` 子目录(此目录会被 .gitignore 排除,**只在本地保留**)。

`ref/` 目录里命名规范:

```
<角色名>_<视角>.png
<角色名>_<情绪>.png
<角色名>_<服装>.png
```

例:
- `陆战神_正面.png`
- `陆战神_愤怒.png`
- `陆战神_西装.png`

---

## 复用工作流

新作品启动时:

1. **检查现有角色**:有没有合适的角色可以直接复用?
2. **如果有**:复制该角色的 prompt + 参考图,直接用
3. **如果没有**:用 A5 三视图 agent 创建新角色,完成后回这里建档
4. **每次出图微调**:把"翻车的细节"和"使用过的解法"沉淀到这个文件

**复用越多,出图越快、越稳。**
