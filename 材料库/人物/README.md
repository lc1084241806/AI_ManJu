# 人物库

> 沉淀每个角色的"可复用资产":人设 + 视觉锁定 prompt + 参考图 + 音色档案 + 翻车经验。
> 一个角色一个 .md 文件,**这是解决"人物一致性"难题的核心仓库**。

---

## 目录结构

按**题材**分目录(题材是角色所属的故事世界,固定不变;画风是出图渲染选择,不用于分目录)。

```
材料库/人物/
├── _模板/            ← 出图排版模板,不是真实角色
│   ├── _模板_人物设定卡_9比16竖版三视图.md
│   └── _模板_人物设定卡_16比9横版作品集.md
├── 现代都市/
│   ├── 陆沉舟_冷峻克制_投资精英男主.md
│   ├── 顾屿_温柔阳光_治愈系暖男男主.md
│   ├── 林晚晴_温柔治愈_初恋系女主.md
│   └── ref/         ← 本题材角色参考图,只在本地保留,不入 git
│       ├── 顾屿_参考.png
│       └── 林晚晴_参考.png
└── 东方玄幻/
    ├── 苏栀_温婉危险_桂花炼丹师女主.md
    └── ref/
```

新题材直接新建同名目录(如 `古风/`、`科幻/`、`悬疑/`)。

> **参考图就近存放**:每个题材目录下各有自己的 `ref/` 子目录,图片跟角色同题材放一起,
> 不同题材互不混。`ref/` 经 `.gitignore`(`材料库/**/ref/`)排除,只在本地保留。
> 命名:`<角色名>_<视角/情绪>.png`,如 `顾屿_正面.png`、`林晚晴_微笑.png`。

## 文件命名

```
材料库/人物/<题材>/<名字>_<气质/风格关键词>_<角色定位>.md
```

目录已表达题材,文件名再带「名字 + 气质 + 定位」,角色多了也能一眼区分:
- `陆沉舟_冷峻克制_投资精英男主.md`
- `苏栀_温婉危险_桂花炼丹师女主.md`

> **模板文件**:`_模板/` 目录里的是可复用出图模板,不是真实角色。
> - `_模板_人物设定卡_9比16竖版三视图.md`:竖版精简设定卡(三视图+细节展示)。
> - `_模板_人物设定卡_16比9横版作品集.md`:横版作品集设计板(信息表+小传+三视图+服饰/饰品拆解+发型+表情),信息最丰富。
>
> 用法:对我说「按 <画风> + <竖版三视图 / 横版作品集>设定卡,生成一个 <角色描述>」,画风从 `材料库/画风/` 选(如 `国漫CG_半写实` / `次世代CG_超写实` / `写实真人摄影`),我据此填字段拼出完整出图 prompt。

## 大文件存放

参考图(.png / .jpg)放在**所属题材目录下的 `ref/` 子目录**(如 `材料库/人物/现代都市/ref/`),
经 `.gitignore`(`材料库/**/ref/`)排除,**只在本地保留**。图片跟角色同题材归置,不同题材互不混。

`ref/` 目录里命名规范:

```
<角色名>_<视角>.png
<角色名>_<情绪>.png
<角色名>_<服装>.png
```

例:
- `陆战神_正面.png`
- `陆战神_愤怒.png`
- `陆战神_西装.png`

## 复用工作流

新作品启动时:

1. **小说阶段**:A3 输出"文字版资产卡"——把新角色的文字描述(外貌/性格/服化)归档到本目录
2. **剧本/分镜阶段**:文字资产卡直接喂 B1 / C1,锁角色描述一致性
3. **故事板阶段**:跑 D1 视觉设定集(在 C3 之后),为每个出场角色生成图像 prompt + 参考图;**先查本目录有没有现成的可复用**,有就直接用,没有再让 D1 出新的
4. **每次出图微调**:把"翻车的细节"和"使用过的解法"沉淀回本目录

**复用越多,出图越快、越稳。**

> D1 视觉设定集位置:V1.2 起,D1 从小说后并行环节挪到"分镜审查 C3 之后、故事板 D3 之前",理由是分镜锁定后才能精准覆盖所有服装变化。
