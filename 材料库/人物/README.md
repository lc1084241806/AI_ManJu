# 人物库

> 沉淀每个角色的"可复用资产":人设 + 视觉锁定 prompt + 参考图 + 音色档案 + 翻车经验。
> 一个角色一个 .md 文件,**这是解决"人物一致性"难题的核心仓库**。

---

## 文件命名

```
材料库/人物/<角色名>.md
```

例:
- `陆战神.md`
- `苏婉清.md`
- `阿狸.md`

## 大文件存放

参考图(.png / .jpg)放在 `材料库/人物/ref/` 子目录(此目录会被 .gitignore 排除,**只在本地保留**)。

`ref/` 目录里命名规范:

```
<角色名>_<视角>.png
<角色名>_<情绪>.png
<角色名>_<服装>.png
```

例:
- `陆战神_正面.png`
- `陆战神_愤怒.png`
- `陆战神_西装.png`

## 复用工作流

新作品启动时:

1. **小说阶段**:A3 输出"文字版资产卡"——把新角色的文字描述(外貌/性格/服化)归档到本目录
2. **剧本/分镜阶段**:文字资产卡直接喂 A5 / A8,锁角色描述一致性
3. **故事板阶段**:跑 A11 三视图(在 A10 之后),为每个出场角色生成图像 prompt + 参考图;**先查本目录有没有现成的可复用**,有就直接用,没有再让 A11 出新的
4. **每次出图微调**:把"翻车的细节"和"使用过的解法"沉淀回本目录

**复用越多,出图越快、越稳。**

> A11 三视图位置:V1.2 起,A11 从小说后并行环节挪到"分镜审查 A10 之后、故事板 A12 之前",理由是分镜锁定后才能精准覆盖所有服装变化。
