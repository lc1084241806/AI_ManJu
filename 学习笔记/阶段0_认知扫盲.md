# 阶段 0 · 认知扫盲

> **阶段目标**:从"完全不懂"到"听得懂行业黑话"。
> **预计用时**:1-3 天(纯认知,不动手)
> **学完你能做到**:能用 3 句话向亲戚解释 AI 漫剧,看任何行业文章生词数 ≤ 5%,看过至少 10 部代表作能说出 3 种不同画风。
> **本笔记前半段是教学内容,后半段"我的学习记录"留给你边学边填。**

## A · AI 漫剧到底是什么

### A.1 一句话定义

**AI 漫剧** = 用 AI 工具(文本 + 绘图 + 视频 + 语音)把"小说式的故事"转成"短视频形态的连续画面",通常发布在抖音 / 视频号 / B 站 / 快手 / 小红书。

形态特征:
- **画面**:AI 生成的图 → AI 生成的视频(图动起来)
- **声音**:AI 配音 + 自选 BGM + 音效
- **节奏**:每集 1-5 分钟,符合短视频平台调性
- **故事**:有人物、有冲突、有反转,通常改编自网文或原创短故事

### A.2 它和"邻居们"的区别

| 形态 | 画面来源 | 制作周期 | 单人能做 | 核心差别 |
|---|---|---|---|---|
| **AI 漫剧** | AI 生成 | 1-7 天/集 | ✅ | 需要美术 + 镜头思维 |
| 真人短剧 | 真人拍摄 | 7-30 天/集 | ❌ 需要团队 | 需要演员、场地、灯光 |
| 漫画 | 手绘 / 板绘 | 数天/页 | ✅ | 不动、无声 |
| 番剧动画 | 手绘 / CG | 数月/集 | ❌ | 24 帧 / 秒、画面精度极高 |
| 静态漫剧(漫画 PPT) | AI / 手绘 | 1-2 天/集 | ✅ | 画面不动,只是图片翻页 |
| **AI 漫剧** | AI 生成 | 1-7 天/集 | ✅ | 画面"动起来" + 配音 + 节奏 |

**关键区分**:AI 漫剧 ≠ 静态漫画 PPT,**必须画面会动**(图生视频),否则只是"会说话的漫画"。

### A.3 它**不是**什么(破除小白幻觉)

❌ **不是"一键生成"**:AI 工具只是替代了"画师 / 演员 / 配音员",但**导演、编剧、美术指导、剪辑这些活儿还是你的**。
❌ **不是"不用写剧本"**:相反,剧本质量是 AI 漫剧的命脉——AI 能画出来,但不能替你想故事。
❌ **不是"学一个软件就行"**:它是 **5-10 个工具的组合拳**,工具会更替,流程不会。
❌ **不是"短期暴富"**:大部分新人做半年到一年才能稳定产出,商业化更晚。
❌ **不是"不要美术基础"**:虽然不用会画画,但**镜头语言、构图、配色**这些"看图的能力"必须有。

## B · 行业现状速览

### B.1 谁在做

- **个人 UP 主 / 自媒体**(主力):一人或小团队作战,粉丝 1k-100w 不等
- **MCN 机构**:批量孵化 AI 漫剧账号,工业化产出
- **网文公司**:把自家网文 IP 改成漫剧,引流到小程序短剧或会员
- **AI 工具公司**:可灵 / 即梦 / 智谱 / 字节,既做工具也直接下场做内容

### B.2 哪些题材火(2024-2026 主流)

- **女频**:总裁 / 重生 / 复仇 / 穿越 / 古装言情 / 婆媳家长里短
- **男频**:战神 / 兵王 / 修仙 / 系统流 / 都市赘婿
- **猎奇 / 悬疑**:民间故事改编 / 真实案件改编 / 都市怪谈
- **治愈 / 情感**:童话风 / 萌宠拟人 / 情感语录
- **科普 / 知识**:历史故事 / 名人传记 / 冷知识

**新人入门建议**:先做**女频家长里短**或**男频战神/复仇**——题材成熟、模板多、用户基数大。

### B.3 主流平台调性差异

| 平台 | 用户画像 | 内容偏好 | 变现模式 |
|---|---|---|---|
| **抖音** | 全年龄,下沉为主 | 强钩子、快节奏、情绪化 | 小程序短剧 / 中视频 / 带货 / 投流 |
| **视频号** | 中年 + 长辈 | 治愈 / 情感 / 家长里短 | 视频号小店 / 私域引流 |
| **B 站** | 年轻 / 二次元 | 高质量画面、有梗、有世界观 | 创作激励 / 充电 / 商单 |
| **快手** | 下沉市场 | 接地气、生活化 | 直播 / 小程序 |
| **小红书** | 年轻女性 | 唯美画风、情感共鸣 | 品牌合作 / 笔记带货 |

**选平台 = 选用户 = 选题材 = 选画风**,这四件事是绑定的。

### B.4 主流变现模式(从易到难)

1. **平台创作激励**:发够数量、播放够多就有现金奖励(最容易)
2. **小程序短剧分成**:把流量引到付费短剧小程序,分流量费
3. **接广告 / 带货**:有粉丝量后接品牌或挂购物车
4. **付费内容 / 充电**:在 B 站、知识星球做付费内容
5. **接单代做**:给小说公司、品牌方做定制漫剧
6. **IP 授权 / 教学 / 课程**:做出名了卖知识

## C · 核心名词扫盲表(40 个必懂)

这是 AI 漫剧圈最常见的 40 个词,看完这一节,80% 的行业文章都能看懂。

### C.1 故事类(8 个)

| 名词 | 含义 |
|---|---|
| **大纲** | 故事的整体走向,分章 / 分集列出主线、副线、转折 |
| **设定集** | 锁死人物长相 / 性格 / 场景风格的文档 + 图集,保证不同集人物一致。<br>**本仓库流水线分两段**:**文字版** = A3 在小说阶段顺手产出的资产卡(沉淀到 `材料库/人物/`、`材料库/场景/`);**视觉版** = D1 视觉设定集在分镜锁定后做的三视图 + 关键道具 reference。 |
| **剧本** | 把小说改写成"可拍"的格式,每场戏有时间、地点、人物、台词、动作 |
| **分场剧本** | 按"场景"切分的剧本(一个场景 = 一个连续时空) |
| **分镜** | 把每场戏拆成具体镜头,每个镜头一个画面,标景别 / 运镜 / 时长 |
| **钩子** | 让用户继续看下去的悬念 / 反转 / 爆点,通常在开头 3 秒和每集结尾 |
| **爽点** | 让用户解气 / 满足 / 爆发的情节点(战神打脸、女主反击……)|
| **完播率** | 用户从开头看到结尾的比例,平台推流的核心指标 |

### C.2 画面类(12 个)

| 名词 | 含义 |
|---|---|
| **关键帧** | 每个镜头的代表画面(通常是镜头开头那一帧),决定整个镜头的视觉效果 |
| **景别** | 镜头距离主体的远近:远 / 全 / 中 / 近 / 特写 |
| **运镜** | 镜头怎么动:推 / 拉 / 摇 / 移 / 跟 / 升 / 降 / 旋 |
| **构图** | 画面元素怎么摆:中心 / 三分 / 对角线 / 引导线 / 框中框…… |
| **提示词 (Prompt)** | 喂给 AI 绘图的文字描述,决定出图效果 |
| **负面提示词** | 告诉 AI"不要"什么(畸形手、模糊、水印) |
| **风格** | 视觉风格:写实 / 动漫 / 国风 / 厚涂 / 赛博朋克 / 像素…… |
| **LoRA** | 一种小型微调模型,可以让 SD/Flux 出图固定某个角色或某种画风 |
| **ControlNet** | 控制 AI 出图的构图 / 姿势 / 边缘的插件,SD 体系核心 |
| **IP-Adapter** | 给 AI 一张"参考图",让它学习风格或角色长相的插件 |
| **垫图** | 给 AI 一张图作为基础,让它生成"类似的"图(用法多种) |
| **一致性** | 同一角色 / 场景在不同镜头长一个样,**行业第一痛点** |

### C.3 视频类(7 个)

| 名词 | 含义 |
|---|---|
| **图生视频** | 输入一张图 + 一段描述,AI 输出一段视频(主流工艺) |
| **文生视频** | 直接输入文字 AI 输出视频(不需要图,但可控性差) |
| **首尾帧** | 给 AI 两张图(开头一张、结尾一张),让它生成中间过渡(高级用法) |
| **运镜提示词** | 视频生成时的镜头描述:zoom in / pan left / dolly out…… |
| **崩帧** | AI 生成视频中突然画面崩掉(角色变形 / 物体扭曲) |
| **5 秒视频** | 主流图生视频工具单段时长上限通常是 5-10 秒 |
| **拼镜** | 把多段短视频拼接成完整一集的过程 |

### C.4 音频类(6 个)

| 名词 | 含义 |
|---|---|
| **TTS** | Text-to-Speech,文本转语音(AI 配音的本质) |
| **音色** | 配音的声线类型:磁性男声 / 软萌少女 / 老者 / 御姐…… |
| **韵律** | 语速 / 停顿 / 重音 / 情绪起伏 |
| **声音克隆** | 给 AI 一段某人的音频,让它模仿这个人的声音 |
| **BGM** | Background Music,背景音乐 |
| **音效 (SFX)** | Sound Effects,具体音效(开门声 / 脚步 / 打斗 / 转场……) |

### C.5 剪辑 / 发布类(7 个)

| 名词 | 含义 |
|---|---|
| **SRT** | 字幕文件格式,标注"几秒到几秒,显示什么字" |
| **卡点** | 让剪辑节奏和音乐节拍对齐 |
| **转场** | 镜头之间的过渡效果:硬切 / 淡入淡出 / 滑动 / 缩放…… |
| **调色** | 调整画面色温 / 饱和度 / 对比度,统一风格 |
| **封面** | 视频的预览图,决定点击率 |
| **标签 (Tag)** | 发布时打的关键词,影响平台推流 |
| **投流** | 付费推广,买流量,加速涨粉 |

## D · 小白最常见的 5 个误解

### 误解 1:"AI 不是一键生成吗?为什么还要学这么多?"

真相:AI 替代的是"执行层"(画师 / 配音员 / 视频剪辑工),没替代"决策层"(导演 / 编剧 / 美术指导 / 剪辑师)。
工具越强,**对你的"审美 + 判断"要求越高**——你得知道什么是好,才能让 AI 做出好的。

### 误解 2:"我只要学好 Midjourney / 可灵就够了"

真相:AI 漫剧是 **5-10 个工具的组合**,且工具半年一换代。
**先学流水线,再学工具**。流水线 5 年不变,工具半年一换。
学工具时学"用法 + 替代品",不要只会一个。

### 误解 3:"剧本不重要,反正画面好看就行"

真相:平台推流看完播率,完播率看钩子和节奏,钩子和节奏在**剧本和分镜**。
画面好看只是"留下来的前提",留下来之后**完播看故事**。
2024-2026 行业共识:**故事 > 画面 > 配音 > BGM**。

### 误解 4:"我画风很特别,做出来一定爆"

真相:画风是"差异化",但**不是流量来源**。
**流量来源是钩子 + 题材 + 平台调性**。
独特画风在 B 站 / 小红书有用,在抖音 / 视频号几乎无效——下沉市场要的是"题材对、看得懂、爽得快"。

### 误解 5:"我要做精品,做一部火一部"

真相:几乎所有头部 UP 主都是从"日更 / 周更烂作品"开始的。
**数量 > 质量,迭代速度 > 单次质量**。
平台算法奖励持续更新者,小白做精品的代价是没人看到你的精品。

## E · 怎么"看懂"代表作

学完上面那些,**不要立刻动手**,先去 B 站 / 抖音搜"AI 漫剧",看至少 10 部代表作。看的时候带着以下问题:

### E.1 每看一部,问自己 7 个问题
1. **题材是什么**?(战神 / 重生 / 修仙 / 家长里短……)
2. **平台是什么**?(抖音 / B 站 / 视频号……)
3. **画风是什么**?(写实 / 动漫 / 国风 / 厚涂……)
4. **第一个镜头讲了什么**?(钩子是什么)
5. **每个镜头多长**?(平均 2-3 秒还是 5-8 秒)
6. **配音是 AI 还是真人**?(听音色辨)
7. **完播率会高吗**?(自己看完了吗?)

### E.2 推荐看哪些类型(平台 + 题材组合)

不要只看一种风格,至少看到这 5 种组合:

- 抖音 + 女频战神 / 复仇(主流爆款,学钩子)
- 抖音 + 男频系统流(学爽点节奏)
- B 站 + 国风 / 古风(学画风和镜头)
- 视频号 + 家长里短(学情感共鸣)
- 小红书 + 唯美治愈(学审美)

### E.3 看完做笔记
看完 10 部,在下面的"我的学习记录"里写:
- 我最喜欢的 3 部 + 为什么
- 我最讨厌的 3 部 + 为什么
- 我想做的题材 + 平台 + 画风
