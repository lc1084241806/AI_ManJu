# 阶段 1 · 全流程鸟瞰

> **阶段目标**:看清整条 10 步流水线,**亲手跑通一个最简陋的端到端**。
> **预计用时**:3-7 天
> **学完你能做到**:口述 10 步流水线及每步产物,有一条不超过 60 秒、不超过 5 个镜头的"端到端作品"。

---

## A · 为什么是这 10 步,不是 5 步或 20 步

AI 漫剧的核心矛盾:**你想表达的故事(文字)** 必须被翻译成 **AI 能产出的画面 / 声音**。

中间需要一系列**降维**:

```
脑里的故事(模糊、抽象)
  ↓ 选题策划:这故事讲给谁听
  ↓ 小说创作:把脑里的故事变成文字(顺便建文字版资产卡)
  ↓ 剧本改编:把小说改成"可拍"的格式
  ↓ 分镜脚本:把每场戏拆成具体镜头(并锁定全角色服装/道具)
  ↓ 故事板:先做三视图锁角色,再出每镜首帧关键画面
  ↓ 图生视频:让画面"动起来"
  ↓ 配音:让人物开口
  ↓ 音乐音效:让画面有情绪
  ↓ 剪辑后期:把所有素材拼成完整一集
  ↓ 发布运营:让别人看到
最终:用户在抖音刷到你的作品
```

**每多一步,翻译损耗 +10%,但可控性 +20%**。所以 10 步是"控制力 vs 工作量"的平衡点(V1.2 起把"设定集"合并入小说阶段衍生 + 把"关键帧出图"重命名为"故事板")。

新手可能尝试**跳步**(比如跳过分镜直接出图)——结果就是:镜头不连贯、人物不一致、节奏失控。**跳步省的时间,后期返工 10 倍补回来**。

---

## B · 10 步详解

### ① 选题策划

| 项 | 内容 |
|---|---|
| 输入 | 你的兴趣 + 目标平台 + 目标受众 |
| 产出 | 一份"题材定位单":题材 + 受众画像 + 卖点 + 竞品分析 |
| 主要工具 | 人脑 + 巨量算数 / 蝉妈妈 / 新榜(看数据) + LLM(辅助分析) |
| 时长占比 | 5%(但决定作品上限) |
| 对应 Agent | 无(更多靠人脑判断) |
| 难点 | "我喜欢" ≠ "用户喜欢",新手最容易在这一步走偏 |

**关键问题**:这部作品给谁看?在哪个平台?他们为什么要看?

### ② 小说创作

| 项 | 内容 |
|---|---|
| 输入 | 题材定位 + 人物初步设定 |
| 产出 | 完整小说(5000-30000 字)或大纲(800-3000 字) |
| 主要工具 | DeepSeek / Claude / 豆包 / Kimi(中文场景重 DeepSeek + 豆包) |
| 时长占比 | 15-25% |
| 对应 Agent | **A1 大纲 + A2 正文 + A3 精化 + A4 审查(可选)** |
| 难点 | AI 写出的网文容易"水",需要反复精化;同一角色性格容易飘 |

**为什么切 4 个 agent**:大纲负责骨架、正文负责血肉、精化负责细节、审查负责合规——单点优化、可替换、可并行。

### ③ 资产建档(由 A3 衍生,无独立 agent)

| 项 | 内容 |
|---|---|
| 输入 | A3 精化版小说(包含每角色/场景/道具的文字版资产卡) |
| 产出 | `材料库/人物/<角色>.md`、`材料库/场景/<场景>.md` 文字档案 |
| 主要工具 | 手动建档(无 agent),A3 输出已结构化 |
| 时长占比 | < 5%(分摊到 A3 阶段) |
| 对应 Agent | 无独立 agent;A3 输出即资产卡;**A11 图像版三视图挪到了"⑤故事板"阶段(见下)** |
| 难点 | 命名重名 / 资产复用对接 / 跨作品检索效率 |

**为什么取消独立"设定集"阶段(V1.2 调整)**:原设计把 A11 三视图放在剧本之前,但实际上**剧本/分镜会新增/调整角色服装与道具**——提前出图必然返工。新方案:文字资产卡(A3)在小说阶段就建好,服务剧本与分镜;**图像资产(A11 三视图)等分镜锁定后再做**,挪到⑤故事板阶段。

### ④ 剧本改编

| 项 | 内容 |
|---|---|
| 输入 | 精化版小说 + A3 文字版资产卡(角色/场景/道具描述) |
| 产出 | 分场剧本(每场戏:时间 / 地点 / 人物 / 台词 / 动作 / 镜头建议) |
| 主要工具 | DeepSeek / Claude |
| 时长占比 | 10-15% |
| 对应 Agent | **A5 剧本生成 + A6 精简 + A7 连贯审查(可选)** |
| 难点 | 把"小说的内心描写"转成"可视化的画面 + 台词" |

**剧本和小说的本质差别**:
- 小说可以写"她心如刀绞"——AI 没法画
- 剧本必须写"她紧握双拳,指节发白,眼眶通红地转身离开"——AI 能画

### ⑤ 分镜脚本

| 项 | 内容 |
|---|---|
| 输入 | 剧本 + 资产卡 |
| 产出 | 镜头清单(每条:景别 / 构图 / 运镜 / 时长 / 画面描述 / 台词 / 音效 / 特效)+ 全角色服装变化清单(给下一阶段 A11 用) |
| 主要工具 | LLM(产 Excel 表格或 Markdown 表) |
| 时长占比 | 10-15% |
| 对应 Agent | **A8 分镜骨架 + A9 分镜增强 + A10 分镜审查** |
| 难点 | 镜头语言(景别 / 运镜 / 节奏)需要看片量积累;台词时长与镜头时长对齐;即梦理解性 |

**分镜的产物长这样**:

| 镜号 | 景别 | 构图 | 运镜 | 时长 | 画面描述 | 台词 / 音效 |
|---|---|---|---|---|---|---|
| 1.1 | 中景 | 三分 | 推 | 3s | 男主背对镜头站在雨中,手中握刀 | (雷声) |
| 1.2 | 特写 | 中心 | 静 | 2s | 男主侧脸,雨水沿下巴滴落 | "够了" |
| 1.3 | 远景 | 对角 | 拉 | 3s | 远处出现 5 个黑衣人围拢 | (脚步声) |

### ⑥ 故事板(三视图 + 关键帧)

| 项 | 内容 |
|---|---|
| 输入 | 分镜表 + 文字资产卡 + 全角色服装变化清单 |
| 产出 | **第一步 A11**:全角色三视图 prompt + 关键道具 reference;**第二步 A12**:每镜首帧关键画面 prompt(整集 30-60 张) |
| 主要工具 | MJ / SD / 即梦 / 可灵 / 文心 |
| 时长占比 | 20-30%(最耗时) |
| 对应 Agent | **A11 三视图(先做,锁角色一致性)+ A12 关键帧提示词** |
| 难点 | 一致性 / 手部畸形 / 多角色同框 / 复杂动作 |

> **A11 + A12 拆为两步**:A11 先做全角色三视图(覆盖每个角色"基础造型 + 关键换装"),作为 A12 的图像 reference。这是 V1.2 调整 —— A11 不再放在剧本前并行,而是在分镜锁定后做,确保所有服装变化(战神揭身份换军装、总裁出席酒会换礼服等)都覆盖到。

**为什么这步最耗时**:
- 30 个镜头 × 平均 5-15 次重抽 = 150-450 次出图
- 每次 30 秒到 2 分钟
- 一集出图常需要 4-12 小时

### ⑦ 图生视频

| 项 | 内容 |
|---|---|
| 输入 | 关键帧 + 运镜描述 |
| 产出 | 每个镜头一段 3-10 秒视频 |
| 主要工具 | 可灵 / 即梦 / Runway / Pika / Vidu / Sora |
| 时长占比 | 15-25% |
| 对应 Agent | **A13 视频提示词** |
| 难点 | 崩帧 / 物体扭曲 / 角色面部漂移 / 运镜失控 |

**实战经验**:每个镜头平均生成 2-4 次才能挑出可用版本,新手可能需要 5-10 次。

### ⑧ 配音

| 项 | 内容 |
|---|---|
| 输入 | 剧本台词 + 角色音色定调 |
| 产出 | 每句台词一条 wav / mp3 |
| 主要工具 | ElevenLabs / Fish Audio / 魔音工坊 / 剪映自带 TTS |
| 时长占比 | 5-10% |
| 对应 Agent | **A14 配音指令(标音色 / 情绪 / 停顿 / 重音)** |
| 难点 | 情绪表达 / 多角色音色区分 / 口型对齐 |

### ⑨ 音乐音效

| 项 | 内容 |
|---|---|
| 输入 | 剧本情绪曲线 + 关键节点 |
| 产出 | BGM 文件 + 音效清单 |
| 主要工具 | 网易云音乐 / 抖音音乐库 / Suno(AI 生成) / 各音效库 |
| 时长占比 | 3-5% |
| 对应 Agent | 无(选歌很难标准化) |
| 难点 | 选歌 / 卡点 / 音量平衡 |

**新手避坑**:不要用未授权 BGM——抖音、视频号会限流甚至下架。

### ⑩ 剪辑后期

| 项 | 内容 |
|---|---|
| 输入 | 视频片段 + 配音 + BGM + 音效 |
| 产出 | 成片(含字幕、转场、调色) |
| 主要工具 | 剪映(新手首选) / PR / 达芬奇 |
| 时长占比 | 10-15% |
| 对应 Agent | 无(剪辑是手感活儿) |
| 难点 | 节奏 / 转场 / 字幕 / 调色统一 |

### ⑪ 发布运营

| 项 | 内容 |
|---|---|
| 输入 | 成片 |
| 产出 | 在平台发布 + 标题 + 封面 + 标签 + 数据复盘 |
| 主要工具 | 各平台原生发布工具 + 巨量算数 / 蝉妈妈(数据) |
| 时长占比 | 5-10% |
| 对应 Agent | 无 |
| 难点 | 标题钩子 / 封面点击率 / 发布时机 / 算法理解 |

```
   │           └── A3 同时输出文字资产卡 → 材料库/人物 / 场景
   ▼
[3.剧本] ──── A5 → A6 → A7
   │
   ▼
[4.分镜] ──── A8 → A9 → A10
   │
   ▼
[5.故事板] ── A11 三视图 → A12 关键帧 prompt
   │           └── A11 在 A10 之后:此时所有角色/服装/道具已锁定,一次到位
   ▼

   │
   ▼

   │
   ▼
[9.剪辑后期] ── 把 6/7/8 的素材拼起来
   │
   ▼
[10.发布运营]
```

## D · 时间预算参考(单集 3 分钟漫剧)

| 经验等级 | 总耗时 | 占比分布 |
|---|---|---|
| 完全小白第一次 | 30-60 小时 | 大部分时间在踩坑、改 prompt、等渲染 |
| 跑通过 5-10 部 | 10-20 小时 | 流水线熟练,但单步质量提升要时间 |
| 工业化老手 | 4-8 小时 | 有 IP 库、agent 库、SOP,大量复用 |

**这就是为什么要建材料库**——把每次的积累沉淀下来,下一部作品复用。

## E · 端到端实操:用最简陋工具跑通一遍

**目标**:用免费 / 最低门槛工具,做一条 **30-60 秒、3-5 个镜头**的漫剧。
**不追求质量,只追求"亲手走过一遍"**。这一步比看 100 篇教程都有用。

### E.1 极简工具清单(全部免费 / 有免费额度)

| 步骤 | 工具 | 备注 |
|---|---|---|
| 故事 | DeepSeek 网页版 | 免费,中文最强之一 |
| 出图 | 即梦(jimeng.jianying.com) | 免费每天 100+ 次,可灵也行 |
| 视频 | 即梦 / 可灵 网页版 | 都有免费额度 |
| 配音 | 剪映自带 TTS | 免费,音色够用 |
| 剪辑 | 剪映 | 免费,新手首选 |

### E.2 五步走完

#### Step 1:写一个 200 字的微故事(15 分钟)

打开 DeepSeek,粘贴这个 prompt:

```
我要做一条 30 秒的 AI 漫剧,主题:战神归来打脸初恋。
请帮我写一个 200 字以内的故事,包含:
- 1 个明确的钩子(开头 5 秒)
- 1 个反转
- 1 个爽点
- 至多 2 个角色
- 适合 5 个镜头讲完
```

把输出存到 `我的作品/000_练手作/01_小说.md`。

#### Step 2:拆 5 个镜头(15 分钟)

继续在 DeepSeek 里发:

```
基于上面的故事,帮我拆 5 个镜头。每个镜头一行表格:
| 镜号 | 景别 | 画面描述(30 字以内) | 时长 | 台词 |
注意:第 1 个镜头是钩子,第 5 个镜头是爆点。
```

把输出存到 `我的作品/000_练手作/02_分镜.md`。

#### Step 3:出 5 张关键帧(1-2 小时)

打开 [即梦](https://jimeng.jianying.com) 或可灵:

1. 选"AI 作图"
2. 把分镜表里"画面描述"翻译成中文提示词(可以让 DeepSeek 帮你翻)
3. 每张图重抽 2-3 次,选最满意的
4. 5 张图都下载,**统一存到** `我的作品/000_练手作/05_关键帧/`

**新手最容易犯的错**:**5 张图人物长相不一致**。这是正常的,这就是阶段 4 要解决的难点。**先不管,继续往下走**。

#### Step 4:5 张图都做"图生视频"(1-2 小时)

同样在即梦 / 可灵,选"图生视频":

1. 上传每一张关键帧
2. 写一句简单运镜:"主角缓慢转身" / "镜头拉近" / "雨水落下"
3. 时长选 5 秒
4. 生成,挑可用版本(可能要重抽 1-3 次)
5. 5 段视频都下载,存到 `我的作品/000_练手作/06_视频/`

#### Step 5:剪映拼成片(1-2 小时)

打开剪映:

1. 5 段视频按顺序拖到时间轴
2. 把"02_分镜.md"里的台词,用"文字 → 朗读"功能,逐句生成配音(选个 TTS 音色),拖到对应位置
3. 从剪映自带的音乐库选一段 30 秒的 BGM,音量调到 -15dB
4. 字幕用"自动识别字幕"功能,识别完检查一下
5. 导出 1080p

**完成!** 这是你的第一部 AI 漫剧。

### E.3 重要心态

✅ **作品很烂**:这是正常的,99% 的人第一部都很烂
✅ **人物不一致**:这是阶段 4 要解决的,先不管
✅ **画面崩了**:正常,挑能看的几张就行
✅ **配音很 AI**:正常,这一阶段不优化配音

❌ **不要追求完美**:完美主义会让你卡在这一步永远跑不通
❌ **不要换工具**:用上面推荐的工具就行,不要折腾

**核心目的**:**让流水线跑起来**。跑过一次,你就知道每一步真实的工作量,知道自己卡在哪里,后面的学习就有的放矢。
