# 阶段 5 · 体系化与工业化

> **阶段目标**:从"个人手作"升级为"个人工厂",**让单部作品制作时间下降 50% 以上**。
> **预计用时**:2-6 个月
> **学完你能做到**:角色出场不需要重新生成、12 个 agent 全部稳定使用并有自己的修订版、有一份属于自己的 SOP。

---

## 体系化 vs 手作的区别

| 维度 | 手作模式(阶段 3-4) | 工业化模式(阶段 5+) |
|---|---|---|
| 角色出场 | 每次重新写 prompt + 重抽 | 直接调用 IP 库,一键复用 |
| 写小说 | 每部都从零开始 | 题材模板 + 角色库 |
| 出图 | 每张都自己挑工具 | 标准化流程,工具栈固定 |
| 配音 | 临时定音色 | 角色音色档案,自动绑定 |
| 剪辑 | 每次按感觉剪 | 有固定 SOP,机械化执行 |
| 时间预算 | 1 集 / 月 | 1 集 / 周 → 1 集 / 天 |

**核心思想**:**沉淀 + 复用 + 自动化**。

## A · 建立角色 IP 库

### A.1 IP 库的价值
- **复用**:同一角色出现在多部作品里,品牌识别度积累
- **加速**:出图不用重新调,直接用沉淀的 prompt + 参考图
- **品牌**:多个作品共用一组角色 = 你的"宇宙观"

### A.2 IP 库的内容(每个角色一份)

存到 `材料库/人物/<角色名>.md`:

```markdown
# 角色:陆战神

## 基础设定
- 年龄:30 岁
- 性别:男
- 身份:战神归来 / 上市公司 CEO
- 性格:外冷内热、护妻狂魔

## 外观锁定 prompt
亚洲男性,30 岁,短黑发,英气锋利眉,深邃眼眸,
方正下颌,薄唇,身高 185cm 体格强壮,
左眼角有一道疤,常穿黑色风衣

## 服装变体
- 战服:黑色风衣 + 战靴
- 商务:深灰西装 + 银表
- 便服:黑卫衣 + 黑色长裤

## 参考图(本地,不入 git)
- ref/陆战神_正面.png
- ref/陆战神_侧面.png
- ref/陆战神_背面.png
- ref/陆战神_愤怒.png
- ref/陆战神_温柔.png

## 音色
工具:魔音工坊 → 沉稳商务男
参数:语速 0.95、音调 -2
情绪范围:冷峻 / 愤怒 / 悲悯 / 温柔

## 关键特征(必须出现)
- 左眼角的疤
- 右手食指戴黑色戒指
- 不笑时嘴角微微下垂

## 容易翻车的细节
- 眼睛容易画成"眯起"(实际应该是"深邃锐利")
- 疤痕位置容易画错(应在左眼角下方 2cm)
- 西装领带容易乱(尽量避免特写)

## 使用过的解法
- 即梦"角色参考"功能 + 上述 3 张定型图,一致性 75%
- 用 Flux + IP-Adapter,一致性 85%
- (未尝试):LoRA 训练
```

### A.3 IP 库使用规范
- **每部新作品启动时**:先去 IP 库看有没有合适角色,能复用就复用
- **每次出图**:复制 IP 库里的 prompt + 服装变体 + 关键特征清单
- **每次解决一个翻车**:回 IP 库更新"容易翻车的细节"和"使用过的解法"

## B · 建立场景库

### B.1 场景库的内容

存到 `材料库/场景/<场景名>.md`:

```markdown
# 场景:战神别墅·客厅

## 基础设定
- 风格:现代欧式 / 极简奢华
- 灯光:暖黄主灯 + 落地灯柔光
- 色调:米白 + 深木色 + 金属点缀

## 锁定 prompt
现代欧式客厅,极简奢华风格,米白色大理石地面,
深胡桃木家具,弧形米色沙发,黑色钢琴,
落地窗,夜景城市灯光,暖黄主灯,影视级打光

## 参考图(本地)
- ref/战神别墅_客厅_白天.png
- ref/战神别墅_客厅_夜晚.png
- ref/战神别墅_客厅_全景.png
- ref/战神别墅_客厅_沙发特写.png

## 必含元素
- 黑色钢琴(主角早年遗物,多次出现)
- 落地窗外的城市夜景
- 沙发上的灰色羊绒毯

## 时间变体
- 白天:自然光从落地窗照入,暖调
- 夜晚:落地灯 + 城市灯光,半暗
- 雷雨:窗外闪电,冷调,黑暗

## 使用过的镜头
- 作品 001:第 3 集第 12 镜头(全景)
- 作品 002:第 1 集第 4 镜头(沙发特写)
```

### B.2 场景库的"主场景"策略
- 每个 IP / 题材系列,**锁定 3-5 个主场景**(主角家 / 公司 / 餐厅 / 街道 / 反派老巢)
- 80% 镜头发生在这些主场景里
- 这样跨集场景一致性自动保证

## D · 沉淀自己的 SOP

### D.1 什么是 SOP
SOP (Standard Operating Procedure)= 标准作业程序。把"做一部漫剧的全流程"固化成一份**清单 + 时间表**,机械化执行,不再凭感觉。

### D.2 SOP 模板(单集 3 分钟漫剧)

存到 `材料库/`(可建 `SOP/` 子目录):

```markdown
# SOP · 3 分钟漫剧标准流程

## Day 1(2 小时):企划 + 大纲
- [ ] 题材选择(选历史模板 / 看竞品)(30min)
- [ ] 受众 / 平台定位(15min)
- [ ] A1 大纲生成(15min)
- [ ] 大纲人工审核 + 微调(60min)
- 产出:00_企划.md, 01_小说_大纲.md

## Day 2(3 小时):小说
- [ ] A2 正文生成(30min,含等待)
- [ ] A3 精化(30min)
- [ ] A4 审查(可选,30min)
- [ ] 人工通读修改(60min)
- 产出:01_小说.md

## Day 3(1.5 小时):剧本(V1.2:设定集拆到 Day 1 文字卡 + Day 5 三视图)
- [ ] 检查 IP 库:角色 / 场景能复用哪些(15min)
- [ ] A5 剧本生成(30min)
- [ ] A6 精简 + A7 审查(45min)
- 产出:03_剧本.md(文字资产卡已在 A3 阶段沉淀到材料库)

## Day 4(2 小时):分镜
- [ ] A8 分镜骨架(30min)
- [ ] A9 分镜增强(30min)
- [ ] A10 分镜审查 + 应用建议(60min)
- 产出:04_分镜.md(含全角色服装变化清单,给 Day 5 A11 用)

## Day 5(4-6 小时):故事板(V1.2:A11 三视图 + A12 关键帧)
- [ ] A11 三视图 prompt 生成 + 出图(角色 × 服装变化,30-90min)
- [ ] A12 关键帧 prompt 批量生成(15min)
- [ ] 30 个镜头出图(每张 3-5 抽)(3-4h)
- [ ] 挑图存档(30min)
- 产出:05a_三视图/<角色>/*.png + 05b_关键帧/<镜号>.png × 30

## Day 6(3-4 小时):图生视频
- [ ] A13 运镜 prompt 批量生成(15min)
- [ ] 30 个镜头视频生成(2-3 次/段)(2-3h)
- [ ] 挑视频存档(30min)
- 产出:06_视频/<镜号>.mp4 × 30

## Day 7(2-3 小时):配音 + 音乐 + 剪辑
- [ ] A14 配音指令生成(15min)
- [ ] 配音生成 + 试听(1h)
- [ ] BGM 选 + 音效(30min)
- [ ] 剪映剪辑(1h)
- [ ] 字幕审核 + 调色(30min)
- 产出:成片

## Day 8(0.5 小时):发布 + 复盘
- [ ] 标题 + 封面 + 标签(15min)
- [ ] 发布(5min)
- [ ] 24h 后记录数据(10min)
- 产出:09_复盘.md(24h 后填)

## 单集总耗时:18-23 小时(分散在 8 天)
## 提速空间:
- 复用 IP 库:节省 1-2 小时(无需出新角色)
- 复用场景库:节省 1 小时
- 熟练度提升:每多做 10 部,节省 30%
```

### D.3 SOP 的关键纪律
- **不跳步**:每一步未完成不进入下一步
- **每步打勾**:不能含糊
- **定时复盘**:每 5 部作品复盘一次 SOP,优化时间分布

## E · 自动化工作流(高级)

阶段 5 后期可以尝试,**不是必须**。

### E.1 自动化的几个层次

| 层次 | 工具 | 自动化程度 |
|---|---|---|
| L0 手工 | 网页版逐步操作 | 0% |
| L1 半自动 | LLM API + 简单脚本(Python) | 30-50% |
| L2 工作流 | Coze / Dify / n8n / Claude Agent SDK | 60-80% |
| L3 全自动 | 自建 Agent 系统 + 调度器 | 80-95% |
| L4 完全自动 | (理论上限,现实几乎不存在,因为需要"人工挑选") | 95%+ |

### E.2 入门:LLM API 半自动(L1)

把 agent prompt + 输入文件,批量丢给 DeepSeek / Claude API:

```python
import anthropic
client = anthropic.Anthropic(api_key="sk-ant-...")

# 读取 agent prompt
with open("材料库/agent/A5_剧本生成.md", encoding="utf-8") as f:
    system_prompt = f.read()

# 读取输入(小说)
with open("我的作品/003_战神归来/01_小说.md", encoding="utf-8") as f:
    novel = f.read()

# 调用 API
response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=16000,
    system=system_prompt,
    messages=[{"role": "user", "content": novel}]
)

# 存输出
with open("我的作品/003_战神归来/03_剧本.md", "w", encoding="utf-8") as f:
    f.write(response.content[0].text)
```

### E.3 进阶:工作流(L2)

- **Coze**(字节,免费):拖拽式工作流,接 DeepSeek / 豆包
- **Dify**(开源):可自部署,接各家 LLM
- **n8n**(开源):通用工作流,接 API / 文件 / 通知
- **Claude Agent SDK**:用 Claude 作为大脑,调动各种工具

### E.4 自动化的边界

**永远不能完全自动化的环节**:
- 出图的"挑图"(需要人眼审美)
- 视频的"挑段"(需要人眼判断崩没崩)
- 标题 / 封面的"判断"(需要市场感)

**可以高度自动化的环节**:
- 文本类(小说 / 剧本 / 分镜 / 提示词)
- 批量喂入 API → 批量收输出

## F · 时间预算的飞跃

### F.1 阶段对比

| 阶段 | 单集耗时 | 月产能 |
|---|---|---|
| 阶段 3(手作起步) | 30-60 小时 | 1-2 集 |
| 阶段 4(攻克难点) | 20-30 小时 | 2-3 集 |
| 阶段 5 初期(有 IP 库) | 12-18 小时 | 4-6 集 |
| 阶段 5 后期(自动化) | 6-10 小时 | 10-15 集 |
| 阶段 6(团队 / 多账号) | 4-8 小时 | 30+ 集 |

### F.2 关键提速点
1. **IP 库复用**:省去 1/3 出图时间
2. **SOP 标准化**:消除"想下一步做什么"的犹豫
3. **API 批量化**:文本步骤几乎瞬间完成
4. **工具选型固定**:不再纠结"用哪个工具"
