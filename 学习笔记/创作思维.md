# 创作思维 · 编剧 / 导演 / 摄影

> **这份笔记不是"按阶段学的一节"——是贯穿所有阶段的工具书。**
> AI 能出图、能写文、能剪片,但"哪个剧本立得住、哪个分镜对、哪张关键帧'有戏'",必须人来判断。没有这套判断力,你永远只能要 AI 中位水平的产出。
>
> **怎么用这份笔记**:
> - 阶段 2 学完工具后通读一遍,知道有哪些维度
> - 阶段 3 做每一步时,**对应章节反复回查**(尤其是 ②/④/⑤/⑥/⑦/⑩)
> - 每拆完一部别人的作品 / 做完自己的一集,用 D 节"自检清单"过一遍

## A · 编剧思维

### A.1 故事的底层结构(三幕)

最简模型,所有故事都套得上:

| 幕 | 占比 | 任务 |
|---|---|---|
| 第一幕 · 开端 | 25% | 立人设 + 立世界 → **触发事件**(打破平衡的那件事) |
| 第二幕 · 对抗 | 50% | 主角追求目标,障碍逐级升级 → **中点反转** |
| 第三幕 · 结局 | 25% | 高潮 → 解决 → 新平衡 |

**漫剧短剧的特殊性**:
- 60 秒短剧,三幕被压到 10s / 30s / 20s
- **前 3 秒必须钩住人**——通常用"反常识反转"开篇(战神归来、被退婚、被赶出家门……)
- 长剧(每集 3-5 分钟)每集都是一个小三幕,**集与集之间用悬念串联**

### A.2 人物弧光

**没有变化的角色不是主角,是工具人。**

- 起点性格 → 触发事件 → 经历障碍 → 内心转变 → 终点性格
- 变化的推动力:**外部事件(逼他)+ 内部决定(他选)**
- 漫剧爽文的弧光通常很简单:**"被瞧不起 → 翻身打脸 → 重新被尊重"**,但要让人信服必须有"为什么这次他不一样了"
- 配角可以是功能性的(只为推动主角),主角不行

### A.3 冲突

故事 = 主角 × 障碍 × N。**没有冲突就没有故事。**

三类障碍,好作品三种都要有:
- **外部障碍**:反派 / 环境 / 命运(爽文重点)
- **内部障碍**:性格缺陷 / 价值观矛盾(让角色立体)
- **关系障碍**:亲情 / 爱情 / 友情的拉扯(让故事有温度)

**新手常犯的错**:全是外部冲突,主角像 NPC 被推着走 → 看着爽,但记不住。

### A.4 爽点机制(短剧特化)

**爽点公式 = 之前憋了多久 × 翻转的力度。**

四种最常见的漫剧爽点:

| 类型 | 模式 | 代表 |
|---|---|---|
| 打脸 | 被瞧不起 → 翻身 → 反向羞辱 | 战神归来、赘婿 |
| 认亲 | 身世悬念 → 揭晓 → 待遇逆转 | 隐藏豪门 |
| 救赎 | 绝境 → 主角出手 → 化险为夷 | 扮猪吃老虎 |
| 互动 | 暧昧推拉 → 突破 → 甜爆 | 言情 / 总裁 |

**节奏铁律**:
- **每 30-60 秒一个小爽点**(短剧)
- **每 3 分钟一个大爽点**(中长剧)
- 没有爽点的镜头叫"水戏",必须删

### A.5 悬念 vs 反转

容易混的两个概念:

- **悬念**:观众**知道**有事会发生,但不知道**怎么**发生
  - 例:观众看到桌下有炸弹,角色不知道——观众揪心
- **反转**:观众**以为是 A**,结果是 B
  - 例:看着像反派,结果是被冤枉的好人

漫剧节奏推荐:**开头扔悬念 → 中段反转 → 结尾再翻一次**。
- 钩住的是悬念
- 留人的是反转
- 出圈的是"反转之后再反转"

### A.6 节奏控制

短剧不允许"什么都不做"的镜头。**每个镜头必须做以下三件事之一**:
1. 推进剧情
2. 塑造人物
3. 营造情绪

否则就是水戏,必须删。

其他节奏要点:
- **长场景必须夹快剪**——5 秒慢镜头 + 5 秒快剪 + 3 秒慢镜头喘息
- **一句台词不超过 12 字**(网文风),长台词必须配画面动态
- **静与动交替**——全程动观众累,全程静观众睡

### A.7 漫剧 vs 网文 的差异(改编必读)

| 维度 | 网文 | 漫剧 |
|---|---|---|
| 节奏单元 | 章(3000 字) | 镜头(3-5 秒) |
| 描写手段 | 心理 + 对话 + 动作 | 画面 + 台词 + 表情 |
| 信息密度 | 可大段铺垫 | 每镜头都必须有信息 |
| 内心戏 | 大段独白 OK | **必须外化为表情 / 动作 / 台词** |
| 时间感 | 一章可写一秒,也可写一年 | 时长 ≈ 真实时间 |

**网文改漫剧的核心动作**:把"他心里想的"全部转成"他脸上 / 手上 / 嘴上"。

## B · 导演思维

### B.1 导演到底在做什么?

一句话:**把文字翻译成画面。**

编剧给你:"小红走进咖啡馆,看到小明在等她。"
导演要决定 6 件事:
1. 镜头**从哪儿开始**?(从门口推开门?还是先给桌前的小明?)
2. 用**什么景别**?(中景看动作?近景看表情?)
3. 镜头**怎么动**?(固定?跟拍?推镜?)
4. 信息**怎么排序**?(先给"她紧张"还是先给"他笑"?)
5. **多长**?(2 秒还是 5 秒?)
6. **下一个镜头怎么接**?(切?淡?用什么过渡?)

**漫剧时代,这 6 个决定全部体现在 prompt 设计里。** 不写 = AI 替你乱选。

### B.2 场面调度

谁站哪 / 怎么动 / 镜头怎么看他们 —— 这三件事的组合就是场面调度。

漫剧时代它变成了 prompt 设计:
- 角色站位 → 写进 prompt
- 视角(过肩 / 正面 / POV)→ 写进 prompt
- 动作 → 写进图 prompt 一遍 + 视频 prompt 再写一遍

**新手通病**:prompt 里只写"小红和小明在咖啡馆",不写谁站哪、谁在干嘛——AI 随便出。

### B.3 信息密度

一个镜头能让观众接收的信息是有限的。导演要决定:
- **主体**:这一秒,观众必须看到什么?
- **陪体**:顺带让观众看到什么?
- **屏蔽**:不让观众看到什么(虚化 / 出框)?

**铁律**:
- 一个镜头 1 个核心信息,最多 2 个
- 堆 5 个信息 = 观众什么都没看清 = 等于 0 个信息

### B.4 戏剧张力的视觉化

"她很愤怒"——怎么拍?

❌ 字幕打"她很愤怒"
❌ 让她大喊"我好生气!"
✅ 推镜到眼睛 + 手攥拳 + 背景虚化 + 色调偏冷
✅ 摔东西的特写 + 远景里的孤立身影

**铁律:能用画面说的,绝不用台词。**

漫剧由于受 AI 视频技术限制,有时不得不用台词补——但仍要努力**让画面承担 70% 的情绪**,台词只承担 30%。

### B.5 场景切换的逻辑

切换不能乱切,必须有理由:

| 切换类型 | 衔接方式 |
|---|---|
| **时间切换** | 空镜过渡(日落 / 月升 / 时钟 / 翻日历) |
| **空间切换** | 动作衔接(开门 → 进入新场景;低头喝水 → 抬头已在别处) |
| **情绪切换** | 音乐 / 节奏卡点(音乐变 → 画面切) |
| **闪回** | 画面去饱和 + 加颗粒 + 偏黑白 |
| **想象 / 心理** | 画面虚化 / 慢动作 / 色调偏冷或偏暖 |

## C · 摄影 / 镜头思维

### C.1 景别——你和被摄物的距离

| 景别 | 拍到什么 | 用在哪 |
|---|---|---|
| 远景 | 人和环境(人小) | 交代环境 / 渲染氛围(开篇 / 转场) |
| 全景 | 全身入画 | 表现动作 / 多人关系 |
| 中景 | 腰部以上 | 对话戏标配 / 动作 + 表情都要看 |
| 近景 | 胸部以上 | 看清表情 / 表现细节 |
| 特写 | 脸 / 手 / 眼 / 物 | 强调情绪 / 关键物品 |
| 大特写 | 局部(眼睛 / 嘴唇) | 极端情绪 / 关键暗示 |

**漫剧选择依据**:
- 让观众看清"谁" → 近景 / 特写
- 让观众看清"在哪" → 远景 / 全景
- 让观众看清"怎么了" → 中景
- **3 秒短镜头里,90% 不要用远景**(看不清观众就划走)
- 一集里景别要**至少 3 种变化**,否则视觉疲劳

### C.2 机位——你从哪个角度拍

| 机位 | 心理效果 | 用在哪 |
|---|---|---|
| 平视 | 中立 / 叙事 | 大部分对话戏 |
| 仰视 | 被摄物变大 / 压迫感 / 崇敬 | 反派登场 / 主角觉醒 |
| 俯视 | 被摄物变小 / 渺小 / 全局 | 主角绝望 / 上帝视角 |
| 过肩 | 体现两人空间关系 | 对话戏标配 |
| 主观 POV | 代入感 / 沉浸 | 重要发现 / 第一视角紧张 |
| 荷兰角(倾斜) | 不安 / 混乱 / 错位 | 反派 / 心理失衡 |

**常见错误**:
- 全片只用平视 → 平淡无聊
- 滥用仰视 / 俯视 → 观众晕

### C.3 运镜——镜头怎么动

| 运镜 | 效果 | 用在哪 |
|---|---|---|
| 推 | 强调主体 / 拉近情绪 | 反转 / 关键发现 / 情绪爆发 |
| 拉 | 揭示环境 / 拉开距离 | 结尾 / 角色孤立 / 转场 |
| 摇 | 横向扫视 / 跟随视线 | 角色看向某物 / 介绍空间 |
| 移 | 平行跟随 | 角色行走 / 表现动态 |
| 跟 | 跟随角色运动 | 追逐戏 / 沉浸感 |
| 升 / 降 | 揭示纵向空间 | 史诗感 / 渺小感 / 战场全景 |
| 环绕 | 360° 看主体 | 重要登场 / 静态场景动态化 |
| 固定 | 不动 | 对话戏 / 静止突出张力 |

**漫剧的特殊原则**:
- **静止情绪戏 → 固定 + 推**(最稳)
- **动态戏 → 跟 + 移**
- **揭示式 → 拉 / 升降**
- **AI 图生视频里,运镜越简单越稳**——新手不要一个镜头塞多种运镜,AI 会乱
- prompt 里**没写运镜 = AI 默认轻微晃动**——这是新手作品"廉价感"的主因之一

### C.4 构图——画面怎么排

最基础的三种:
1. **三分法**:画面九宫格,重要元素放在 1/3 线 / 交叉点
2. **对称**:庄严 / 仪式感 / 反派老巢
3. **引导线**:用道路 / 视线 / 光线引导观众视线到主体

构图思考点:
- 主体在哪?(观众第一眼看哪)
- 留白:观众的"呼吸空间"
- 前景 / 中景 / 背景:画面层次
- 视线方向:角色看哪儿,引导观众看哪儿

### C.5 光线——画面的情绪密码

| 光线类型 | 效果 |
|---|---|
| 顺光 | 平淡但脸部清晰(新手默认 → 平) |
| 侧光 | 立体感(对话戏首选) |
| 逆光 | 剪影 / 神秘 / 戏剧化 |
| 顶光 | 压抑 / 阴森 |
| 底光 | 恐怖 / 反派(经典恐怖片用法) |
| 伦勃朗光 | 一侧脸亮一侧暗 + 三角形高光 → 油画质感 |
| 暖光(3000K) | 温馨 / 回忆 / 室内 |
| 冷光(6000K) | 冷酷 / 科技 / 现代 / 凌晨 |
| 低调光 | 大面积暗 + 局部光 → 戏剧 / 悬疑 |
| 高调光 | 整体亮 + 少阴影 → 梦境 / 纯净 |

**漫剧 prompt 的杀手锏**:
- 不写光线 → AI 出顺光均匀光 → 平
- 写"侧光 + 暖色 + 局部高光"→ 立刻有戏
- 写"低调光 + 冷色 + 伦勃朗"→ 立刻有质感

### C.6 色彩——画面的潜意识

| 色 | 心理 |
|---|---|
| 红 | 爱 / 危险 / 愤怒 / 激情 |
| 蓝 | 冷静 / 忧郁 / 科技 / 距离 |
| 黄 | 温暖 / 怀旧 / 警告 |
| 绿 | 生机 / 嫉妒 / 不安 / 病态 |
| 紫 | 神秘 / 高贵 / 怪异 |
| 黑白 | 回忆 / 闪回 / 仪式感 |
| 高饱和 | 卡通 / 年轻 / 戏剧 |
| 低饱和 | 写实 / 沉重 / 文艺 |

**调色策略**:
- 整部作品定一个**主色调**(冷 / 暖 / 高饱 / 低饱)
- **关键场景偏离主色调**来制造对比(回忆戏去饱和、爆发戏加红)
- 同一场景前后色调要一致——这是"风格统一"的视觉基础

## D · 判断力训练

### D.1 "七问法"——拆解一个优秀镜头

看一部你觉得好的漫剧,逐镜头问 7 个问题:

1. 这个镜头**给了什么信息**?(剧情 / 人物 / 情绪 三选一或多)
2. 这个镜头用了**什么景别 / 机位 / 运镜**?**为什么用这个**?
3. 这个镜头**多长**?为什么是这个时长?
4. 这个镜头**和上 / 下镜头怎么衔接**?
5. 这个镜头**有什么不必要的元素**?(如果有)
6. **如果是我,我会怎么改**?
7. 这个镜头**给我留下了什么情绪**?**为什么**?

**节奏建议**:每周深拆 1-2 个优秀镜头,坚持 3 个月。

### D.2 自检清单——做完一集后必须过一遍

**编剧层**:
- [ ] 前 3 秒钩住了吗?(回放给同事看,他看完前 3 秒有没有"接着看"的欲望)
- [ ] 主角有变化吗?(哪怕一点点)
- [ ] 有 30-60 秒一次的小爽点吗?
- [ ] 有水戏吗?(每个镜头都必须做 推进剧情 / 塑造人物 / 营造情绪 三件事之一)
- [ ] 心理活动都外化成画面了吗?有没有"直接打字幕说她很愤怒"?

**导演层**:
- [ ] 每个镜头的**主体明确**吗?(观众第一眼应该看哪?)
- [ ] **信息密度**合理吗?(不太多也不太少)
- [ ] 场景切换**有理由**吗?
- [ ] 戏剧张力**视觉化**了吗?

**摄影层**:
- [ ] **景别有变化**吗?(没有全片都是中景或全是近景)
- [ ] **运镜服务于情绪**吗?(没有为了"动起来"而乱动)
- [ ] **光线营造了情绪**吗?(还是全程顺光?)
- [ ] **调色统一**吗?(没有这一镜暖那一镜冷)

**节奏层**:
- [ ] **静与动交替**了吗?
- [ ] **音乐卡点**了吗?
- [ ] 倍速看一遍,**节奏对不对**?(0.5x 看是否拖,2x 看是否乱)

### D.3 红灯信号——这些症状一出现就是有问题

| 症状 | 病灶 |
|---|---|
| 别人看完问"你想讲什么?" | 故事结构问题(三幕没立住) |
| 别人说"画面好看但没意思" | 戏剧张力问题(没冲突 / 没爽点) |
| 别人在第 X 秒划走 | 这一秒前后的镜头有问题(信息量 / 节奏) |
| 自己重看也觉得无聊 | 节奏问题(水戏太多) |
| 评论区在讨论"配音 / 画风" | 故事没立住(观众没东西可聊,只能聊外壳) |
| 完播率低于 30% | 钩子失败 + 中段水戏 |
| 3 秒完播率低于 60% | 开头 3 秒不行 |

### D.4 训练资源

**看**:每周看 ≥ 10 部代表作,每月**深拆 ≥ 2 部**(用 D.1 七问法,写在下面的"我的学习记录")。

**读**(推荐入门读物,挑 1-2 本):
- 《故事》(罗伯特·麦基)——编剧圣经,讲三幕和人物弧光
- 《救猫咪》(布莱克·斯奈德)——通俗易懂,讲爽点节奏
- 《电影镜头设计》(史蒂文·卡茨)——景别 / 机位 / 运镜入门
- 网文:挑 3 本完结爆款,**只看前 10 章**,学钩子和节奏

**临**:挑一个你觉得好的 3 秒镜头,自己 AI 复刻一遍,**对比差距**——这是最快的提升方法。

**练**:每集做完先**过一遍 D.2 自检清单**,有 1 项不合格就不发。
