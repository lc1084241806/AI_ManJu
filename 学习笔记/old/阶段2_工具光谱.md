# 阶段 2 · 工具光谱

> **阶段目标**:面对一堆工具不再焦虑,知道每个工具的脾性、价格、商用授权。
> **预计用时**:5-10 天
> **学完你能做到**:给出"500 元/月预算"的最优工具组合,知道哪些工具不能商用、哪些有水印、哪些限分辨率。

---

## A · 工具选择的三大原则

学工具之前先记住:

### 原则 1:先学流水线,再学工具
工具半年一换代,流水线 5 年不变。**所有工具都是可替换的**,不要把"我会用 X"当成竞争力。

### 原则 2:每类工具至少会两个
- 一个**主力**(日常用)
- 一个**备胎**(主力崩了 / 限流时用)
- 各类工具都有"风格盲区",**不同工具擅长不同的题材**

### 原则 3:商用授权是底线
**未授权使用会被平台限流、下架、甚至封号**。每个工具开始用之前先看一遍授权条款:
- 免费版能不能商用?
- 付费版的具体权限是什么?
- 输出内容版权归谁?

- 高频生产建议用**官方付费 API**(更稳定、更高额度、有商用条款保障)

### C.1 选型表

| 工具 | 画风 | 一致性 | 可控性 | 中文支持 | 价格 | 商用 |
|---|---|---|---|---|---|---|
| **即梦(字节)** | 国漫 / 写实 / 多风格 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 免费+付费 | ✅ |
| **可灵图像** | 写实 / 影视感 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 免费+付费 | ✅ |
| **Midjourney (MJ)** | 艺术性最强 | ⭐⭐⭐⭐ | ⭐⭐⭐ | ❌ 需英文 | $10-$60/月 | ✅(付费版) |
| **Stable Diffusion (SD)** | 最灵活,LoRA 多 | ⭐⭐⭐⭐⭐(配 LoRA) | ⭐⭐⭐⭐⭐(配 ControlNet) | ❌ 需英文 | 免费但要硬件 | ✅ |
| **Flux (黑森林)** | 写实精细 / 文字渲染好 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ❌ | 部分免费 | 看版本 |
| **文心一格 / 通义万象** | 国风强 | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ | 免费+付费 | ✅ |
| **NanoBanana (Gemini)** | 多模态编辑、保持一致性 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 付费 | ✅ |

### C.2 各工具的"风格盲区"

- **MJ**:艺术感强但**中文场景不接地气**,做"中国家长里短"画面会显得"洋"
- **即梦**:国漫 / 中式场景强,**写实欧美人物较弱**
- **SD/Flux**:**没插件就难用**,需要 ComfyUI + LoRA + ControlNet 才能发挥
- **可灵图像**:**影视写实强**,但 Q 版 / 动漫风格弱

### C.3 实战推荐组合

| 题材方向 | 推荐 |
|---|---|
| 战神 / 复仇 / 都市 / 重生(主流抖音) | **即梦主力 + 可灵图像备胎** |
| 玄幻 / 修仙 / 古装 | **即梦 + 文心一格(国风)** |
| 高质量艺术向 / B 站 / 小红书 | **MJ 主力**(配合中文翻译) |
| 极致可控 / 同角色多镜头一致性 | **SD + LoRA + ControlNet**(学习曲线陡,但天花板高) |
| 写实影视感 | **可灵图像 + Flux** |

### C.4 商用底线
- **MJ**:**必须付费版**才能商用,免费版商用违规
- **SD**:模型本身免费,但**用的 LoRA / Checkpoint 可能有商用限制**,下载前看许可证
- **即梦 / 可灵**:免费版通常允许,但要看具体版本条款
- 所有平台:**输出图不可包含明确受版权保护的角色 / 品牌 logo**

### D.2 工具的真实差距

**2025-2026 主流梯队**:
- **第一梯队**(主力):可灵、即梦、Hailuo —— 中文用户首选,免费额度多,效果好
- **第二梯队**(高端):Runway Gen-3、Sora —— 顶级画质,但贵 + 海外访问
- **第三梯队**:Pika、Luma、Vidu —— 各有特色,做备胎

### D.3 实战推荐组合

| 预算 | 推荐 |

| **0 元(纯免费额度)** | 可灵 + 即梦 + Vidu(三家轮流用免费额度) |
| **100-200 元/月** | 可灵会员 + 即梦会员 |
| **500 元/月** | 可灵高级 + 即梦高级 + 偶尔 Runway 单次 |
| **海外发布 / 顶级品质** | Runway Gen-3 + Sora |

### D.4 商用与版权
- 可灵 / 即梦:**免费版可商用但有水印**,付费版无水印
- Runway / Pika:**必须付费**版才能商用
- 所有平台都禁止生成涉及真实人物 / 政治 / 暴力 / 色情的内容

### E.2 实战推荐

| 阶段 | 推荐 |
|---|---|
| **新手第一部** | 剪映自带 TTS(免费、内嵌、方便) |
| **稳定生产** | 魔音工坊 / 配音狗(中文音色丰富、便宜) |
| **追求质感** | Fish Audio / ElevenLabs(情绪表达最好) |
| **想做"独家声线"** | 用 Fish Audio / 魔音工坊的声音克隆 |

### E.3 商用与版权
- **音色版权**:不同工具对音色有不同限制,有的音色只允许"播放",不允许"二次商业化"
- **声音克隆**:**只能克隆自己的声音 / 有授权的他人声音**,克隆名人 / 明星会被起诉
- 抖音 / 视频号对 AI 配音越来越敏感,**最好加"AI 生成"标签**

## H · 学习重点优先级

如果时间有限,**优先把这 5 个工具学透**:

1. **DeepSeek**:故事 + 剧本 + 提示词的命脉
2. **即梦**:中文 AI 漫剧出图主力
3. **可灵**:图生视频主力
4. **剪映**:剪辑 + TTS 一体化
5. **抖音 / 视频号 的创作中心**:看数据、看推流、复盘

其余工具都是"会用一个"即可,不要陷入"工具学习焦虑"。
