# 阶段 3 · 单点深入

> **阶段目标**:10 步每一步都从"能做"到"做对",产出一部完整作品(≥ 3 分钟、≥ 30 镜头)。
> **预计用时**:4-12 周(边学边做)
> **学完你能做到**:完成一部完整作品,16 个 agent 中至少使用过 8 个,能指出自己作品里"最弱的一步"。

---

## 怎么使用本笔记

这一阶段最长,**不要按顺序一气呵成**——按"流水线顺序"边做边学:
- 做第 ① 步时读 A 节
- 做完后回笔记记录 + 填心得
- 再去做第 ② 步、读 B 节
- ……

**每一步都有对应的 agent 在 `材料库/agent/`**,做的时候直接用。

## A · ① 选题策划

### 核心要点

1. **题材 = 受众 × 平台 × 你的能力**:三者必须匹配
2. **不要做"我想做"的,做"用户想看"的**
3. **跟风期 vs 蓝海期**:跟风易起量但天花板低,蓝海难起量但天花板高

### 选题三问

每个选题问自己 3 个问题:
- **谁会看**?(年龄 / 性别 / 平台 / 偏好)
- **为什么 30 秒钟内不划走**?(钩子 / 反转 / 颜值 / 情绪)
- **看完后会做什么**?(点赞 / 关注 / 完播 / 评论 / 分享)

### 实操步骤

1. 上 **巨量算数 / 蝉妈妈 / 新榜**,搜"AI 漫剧"相关标签,看近 30 天爆款
2. 列出 3 个候选题材,每个题材找 3 个同行参考作品
3. 用以下表格 PK:

| 候选题材 | 月均播放参考 | 竞品数 | 我的优势 | 我的劣势 | 平台 |
|---|---|---|---|---|---|
| | | | | | |

4. 选定题材后,产出"题材定位单":

```
题材:[XX]
受众:[年龄/性别/兴趣]
平台:[抖音/视频号/B 站]
卖点(3 个):
- [钩子点]
- [爽点 / 情绪点]
- [差异化]
集长:[60s / 180s / 300s]
计划集数:[3 集试水 / 10 集系列]
预期完播:[%]
```

### 常见错误

❌ 凭兴趣选题材,做完发现没人看
❌ 同时做 3 个题材,每个都不深
❌ 不看竞品就开做,做出来全是别人玩剩的套路

### Agent

**无 agent**——这一步是人脑判断 + 数据分析,LLM 帮不了核心决策。

## B · ② 小说创作

### 核心要点

1. **网文叙事三板斧**:**钩子 + 节奏 + 反转**
2. **每 30 秒一个小爽点 / 每 5 分钟一个大爽点**
3. **同一角色性格容易飘**——AI 写到一半角色会"变软" / "变蠢"
4. **AI 写出的网文很"水"**——必须精化、去重、删冗余

### 网文叙事三板斧

- **钩子**:开头 3 秒就要给一个让用户停下来的悬念 / 冲突 / 反差
  - 例:"她是被全家算计死的""他从未输过,直到遇见她""三年了,我终于找到杀我妻子的人"
- **节奏**:动 - 静 - 动 - 静(打斗 → 思考 → 反转 → 抒情……),不能一根直线
- **反转**:每集至少一个反转(谁是真正的反派 / 真相 / 身份 / 关系)

### 4 个 Agent 怎么用

| Agent | 输入 | 输出 | 何时跳过 |
|---|---|---|---|
| **A1 大纲** | 题材 + 集数 + 主角 | 全集大纲 | 不可跳 |
| **A2 正文** | 大纲 + 主角设定 | 完整小说(5000-30000 字) | 不可跳 |
| **A3 精化** | 小说初稿 | 补人物 / 场景 / 道具的精化版 | 短剧可跳,长剧必跑 |
| **A4 审查** | 精化版小说 | 合规 + 爽点审查报告 | 治愈 / 日常题材可跳 |

**Agent 跑法**:
- 每个 agent 用**独立对话窗口**(避免上下文污染)
- 上一个 agent 的输出 → 复制到下一个 agent 的输入
- 不满意就修改 agent prompt,**不要在原对话里反复调试**

### 实操步骤

1. 把 `材料库/agent/A1_小说大纲.md` 复制到 DeepSeek 智能体,填好变量
2. 发输入(题材 + 主角设定),得到大纲
3. 把 `材料库/agent/A2_小说正文.md` 复制到另一个 DeepSeek 智能体
4. 输入大纲,得到正文初稿
5. 用 A3 精化、(可选)A4 审查
6. 把最终版小说存到 `我的作品/<项目>/01_小说.md`

### 常见错误

❌ 在一个对话窗口里反复"再来一段、改一改" → 上下文污染严重
❌ AI 写得不好就一直让 AI 改 → **应该改 prompt,而不是对话**
❌ 跳过大纲直接写正文 → 写到一半故事崩了

### 资源

- 网文叙事:看《番茄 / 七猫 / 起点》头部短篇
- 钩子设计:看抖音 #短剧 标签前 100 名
- 精化方向:研究"金手指 / 系统流 / 重生 / 战神"几大套路

## C · 设定集思维(跨 ② → ⑤,不占独立流水线步号)

> **V1.2 调整说明**:原"设定集"独立阶段拆为两部分,分散到两个时点——
> - **文字版资产卡** = A3 精化阶段衍生(角色/场景/道具的文字描述),归入"②小说"阶段,沉淀到 `材料库/人物/`、`材料库/场景/`
> - **视觉版设定集**(三视图 / 关键道具 reference)= **D1 视觉设定集** 挪到"⑤故事板"阶段,在 C3 分镜审查之后做,然后是 D3 关键帧 prompt
>
> 设定集 = A3 文字资产卡 + D1 视觉设定集图像版——两者合在一起就是传统意义上的"设定集"。本节保留是因为"角色一致性""画风统一"等概念跨阶段贯穿,集中讲清楚比拆到各步讲更清楚。

### 核心要点

1. **资产卡 = 视觉锁死的源头**:角色/场景/道具的统一描述是后续出图一致性的基础
2. **拆三件套 + 分两阶段**:角色定型(D1 视觉设定集,故事板阶段)+ 场景定型(D1/D3,故事板阶段)+ 画风定调(全流程统一后缀)
3. **活文档**:剧本/分镜阶段发现要加角色,回来补文字卡;D1 视觉设定集在分镜锁定后一次性出
4. **行业第一痛点**:这一步做得马虎,后面 30 个镜头人都长不一样

### 角色定型(每个主要角色至少 3 张图)

每个角色至少出:
- **三视图**:正面 / 侧面 / 背面(锁死外观)
- **表情图**:平静 / 喜 / 怒 / 哀 / 震惊(锁死情绪)
- **服装图**:不同场景的服装(战服 / 便服 / 礼服)

**关键**:把每个角色的"特征 prompt"沉淀到 `材料库/人物/<角色名>.md` 里——后续每张图都引用这段 prompt。

### 场景定型

每个主要场景出:
- **建立镜头**(整体远景)
- **关键道具特写**(标志性物品)
- **不同时间**(白天 / 夜晚 / 雨天,如剧本需要)

存到 `材料库/场景/<场景名>.md`。

### 画风定调

整部作品的统一调性:
- 色调(暖 / 冷 / 中性 / 高对比)
- 画风(写实 / 半写实 / 厚涂 / 平涂 / 国漫……)
- 笔触(精细 / 粗犷 / 卡通……)

写成 1 段 50 字的"画风 prompt 后缀",每张图都加上。

### D1 视觉设定集 Agent(V1.2:挪到分镜审查之后)

**输入**:C3 分镜词 + A3 文字资产卡 + B1 剧本(精化版)
**输出**:可直接喂 MJ / 即梦 / SD 的提示词组,覆盖**全角色** × **全服装变化** × **关键道具**

**为什么挪到分镜之后**:
- 分镜锁定后,所有出场角色 + 所有服装变化(战神揭身份换军装、总裁出席酒会换礼服、宫斗女主册封换大袖衫等)+ 关键道具都已列清
- 此时一次出三视图,可以不返工
- D1 输出直接服务下游 D3 故事板锚定参考图,信息衰减最小

### 实操步骤(V1.2 流程)

1. **小说阶段(A3)**:文字资产卡建档到 `材料库/人物/` `材料库/场景/`,只写文字描述
2. **剧本/分镜阶段(B1-C3)**:用文字卡保持角色描述一致,C2 阶段从分镜中抽出"全角色服装变化清单"
3. **故事板阶段(D1)**:让 D1 agent 基于分镜词 + 文字卡 + 服装清单,生成每个角色 × 每套服装的 prompt
4. **出图**:在 MJ / 即梦 / SD 出三视图,挑满意的存到 `材料库/人物/<角色>/三视图/`
5. **回填**:把"满意的 prompt + 参考图文件名 + 容易翻车的特征"沉淀回 `材料库/人物/<角色>.md`
6. **下游 D3**:每镜首帧出图时,从本目录复制 prompt + 参考图作为锚点

### 常见错误

❌ 没出三视图就直接做正片,30 个镜头里人物长 30 个样
❌ 每个角色只用文字描述,不上传参考图 → 一致性靠运气
❌ 画风不统一(这个镜头写实那个镜头动漫)
❌ 只做角色不做场景 → 场景跳来跳去用户出戏

### 资源

- 一致性技巧:看阶段 4 "人物一致性"
- 工具:即梦的"角色参考"功能 / SD 的 LoRA + IP-Adapter / MJ 的 --cref

## D · ③ 剧本改编

### 核心要点

1. **剧本 ≠ 小说**:小说是写给人看的,剧本是写给 AI 拍的
2. **每一句都要"可视化"**:把"她心如刀绞"改成"她眼眶通红,死死咬住嘴唇"
3. **每场戏一个核心动作 / 一个核心情绪**
4. **剧本里禁止出现"她想起" / "他暗自决定"**——内心戏要外化

### 标准剧本格式

```
【场景 X · 时间 · 地点】
人物:A、B
道具:剑、信件

(A 站在窗边,背对 B)

A:(冷声)你还有什么话要说?
B:(颤抖)我……我没有背叛你。

(B 跪下,A 转身,目光锐利如刀)

A:那这封信怎么解释?
```

### 3 个 Agent 怎么用

| Agent | 输入 | 输出 | 何时跳过 |
|---|---|---|---|
| **B1 剧本生成(标准 / 类型特化)** | 小说 | 分场剧本 | 不可跳 |
| **B2 精简** | 剧本初稿 | 删除冗余、压缩台词 | 短剧可跳(剧本本来就短) |
| **B3 连贯审查** | 精简后剧本 | 检查时间线 / 人物逻辑 / 道具流转 | 单集短剧可跳,长剧必跑 |

### 实操步骤

1. 把"01_小说.md"喂给 B1 agent,选"类型特化"版本(玄幻 / 都市 / 古装)
2. 得到分场剧本,存到 `我的作品/<项目>/02_剧本.md`
3. 检查剧本,如果太长或啰嗦,跑 B2 精简
4. 长剧或改编多次后,跑 B3 连贯审查

### 常见错误

❌ 剧本保留太多心理描写 → AI 没法拍
❌ 一场戏里塞 5 个动作 → 镜头会乱
❌ 台词写得太书面 → 配音很假
❌ 没标"时间 / 地点"→ 后续分镜不知道场景

### 资源

- 看《一年一度喜剧大赛 / 脱口秀》剧本:学"短时间内的强冲突 + 反转"
- 看电影剧本(豆瓣 / 影视宝典):学"动作 + 情绪"的可视化写法

## E · ④ 分镜脚本

### 核心要点

1. **分镜 = 把剧本拆成镜头**
2. **每个镜头 2-5 秒**(抖音节奏);**长视频可 5-15 秒**(B 站)
3. **不超过一个"动作 + 情绪"** per 镜头
4. **景别要变化**:不能 30 个镜头都是中景

### 镜头语言基础(必背)

**景别**(由远到近):
- 远景:交代环境
- 全景:看到全身,常用于动作
- 中景:腰部以上,常用于对话
- 近景:胸部以上,情绪重点
- 特写:面部 / 局部,极强情绪

**运镜**:
- **推 (zoom in)**:拉近 → 强调情绪 / 焦点
- **拉 (zoom out)**:拉远 → 揭示环境 / 收尾
- **摇 (pan)**:左右转动 → 跟随人物 / 浏览场景
- **移 (dolly)**:平移 → 跟随移动主体
- **跟 (follow)**:跟随主体 → 紧跟主角
- **升 / 降**:升降 → 史诗感 / 压迫感
- **静止 (static)**:不动 → 沉稳 / 对话

**镜头时长 vs 节奏**:
- 1-2 秒:快节奏,适合打斗 / 反转
- 3-5 秒:常规节奏,主流抖音漫剧
- 5-10 秒:慢节奏,适合情感 / 抒情

### 分镜表格式

| 镜号 | 景别 | 构图 | 运镜 | 时长 | 画面描述 | 台词 | 音效 / 备注 |
|---|---|---|---|---|---|---|---|
| 1.1 | 远景 | 中心 | 推 | 3s | 雨中的废墟,男主背影 | (无) | 雷声 |
| 1.2 | 特写 | 三分 | 静 | 2s | 男主侧脸,雨水滴落 | "够了" | 雨声 |
| 1.3 | 中景 | 对角 | 拉 | 3s | 远处 5 个黑衣人围拢 | (无) | 脚步声 |

### C1 分镜 Agent

输入:剧本 + 风格指示(快节奏 / 慢节奏 / 抖音 / B 站)
输出:完整分镜表(Markdown 表格 / Excel)

### 实操步骤

1. 把"02_剧本.md"喂给 C1 agent,指定"抖音快节奏 / 30 镜头 / 平均 3 秒"
2. 得到分镜表,存到 `我的作品/<项目>/03_分镜.md`
3. **人工审核**:每个镜头看"是否过于复杂" / "景别变化是否合理"
4. 修改不合理的镜头,**人工最终拍板**

### 常见错误

❌ 全是中景 → 无聊
❌ 一个镜头要发生 3 个动作 → AI 拍不出来
❌ 不标时长 → 后续视频生成 / 剪辑迷茫
❌ 不写音效备注 → 后期剪辑要重看一遍剧本

### 资源

- 看好作品时**默数镜头数和时长**,建立直觉
- 学习镜头语言:B 站搜"电影镜头语言入门"

## F · ⑤ 故事板(V1.2 重命名,原"⑥ 关键帧出图")

> **V1.2 调整**:本阶段拆为两步 ——
> 1. **先做 D1 视觉设定集**:基于分镜锁定的"全角色 × 全服装变化 × 关键道具"清单,一次性出三视图 prompt(图像 reference)
> 2. **再做 D3 关键帧**:用 D1 视觉设定集作为锚定参考,把每镜首帧出图 prompt 写出来
>
> 设定集 = A3 文字资产卡 + D1 视觉设定集图像版,两者合在一起就是新概念下的"设定集"。

### 核心要点

1. **每个镜头出 1 张关键帧**(代表性那一帧)
2. **复用资产**:角色 prompt + 场景 prompt + 画风后缀(从文字卡 + D1 视觉设定集复制)
3. **重抽 3-5 次挑最满意的**——AI 出图随机性大
4. **一致性 > 美感**:宁要"差一点但角色对"的图,不要"美但角色不对"的图

### 提示词工程基础

提示词通用结构:

```
[人物](角色 prompt 从设定集复制)
[动作 / 表情](从分镜表"画面描述"提取)
[场景](场景 prompt 从设定集复制)
[镜头](景别 + 运镜 + 视角)
[氛围](情绪 + 时间 + 天气)
[画风后缀](从设定集复制,整部作品统一)
[负面提示词](畸形手 / 模糊 / 多人 / 水印……)
```

### 一致性技巧(本步骤的核心难点)

1. **每个角色 prompt 永远复用**:不要每次重新描述
2. **用"角色参考图"功能**:即梦的"角色参考"、SD 的 IP-Adapter、MJ 的 --cref
3. **同一画风后缀贯穿全集**
4. **种子值锁定**(SD):同一种子 + 同一 prompt = 类似结果
5. **LoRA 训练**(SD 高级):为主角训练专属 LoRA,无敌一致性

### D3 关键帧 Agent

输入:分镜表 + 设定集摘要
输出:每个镜头一段完整可用的"绘图 prompt"

### 实操步骤

1. 把"03_分镜.md"+"材料库/人物/" + "材料库/场景/" 喂给 D3 agent
2. 得到 30 条 prompt(每个镜头一条)
3. 逐镜头到即梦 / MJ / SD 出图,**每张图重抽 3-5 次**
4. 选最满意的存到 `我的作品/<项目>/05_关键帧/<镜号>.png`
5. **不合格的镜头**(角色变了 / 严重崩坏):
   - 回去微调 prompt
   - 或用更精确的参考图
   - 或换工具(即梦不行试 MJ)

### 常见错误

❌ 一张图只抽 1 次就用 → 质量差
❌ 不用角色参考图 → 一致性差
❌ 30 个镜头用 30 套不同的画风后缀 → 风格跳
❌ 见不得"差一点"的图就重抽 50 次 → 卡死,做不完

### 资源

- 学提示词:civitai.com / lexica.art 抄优秀 prompt
- 一致性:阶段 4 有专题
- 工具选型:阶段 2 工具光谱

## G · ⑥ 图生视频

### 核心要点

1. **输入 = 关键帧 + 运镜描述**
2. **5 秒视频是主流单段时长**,长镜头要拼接
3. **崩帧是常态**,挑能用的就行
4. **简单运镜 > 复杂运镜**,描述越简单越稳

### 运镜描述写法

**推荐格式**(简洁、明确):
```
[主体]+ [动作]+ [镜头运动]+ [氛围词]
```

**例子**:
- "主角缓慢转身,镜头推近,雨水落下"
- "镜头从远处拉到主角面部特写,主角眨眼"
- "黑衣人从左侧入画,主角侧头看向他"

**禁忌**:
- ❌ 一段视频里 3 个动作("转身然后挥剑然后大喊")
- ❌ 抽象描述("营造紧张氛围")
- ❌ 复杂运镜("先推近再环绕再拉远")

### E1 视频提示词 Agent

输入:分镜表 + 关键帧描述
输出:每个镜头的"图生视频 prompt"

### 实操步骤

1. 把"03_分镜.md"+关键帧文件名喂给 E1 agent
2. 得到 30 条简洁运镜描述
3. 逐镜头到可灵 / 即梦,上传关键帧 + 粘贴运镜描述
4. **每个镜头生成 2-3 次**,挑可用版本
5. 存到 `我的作品/<项目>/06_视频/<镜号>.mp4`

### 翻车修复

| 现象 | 原因 | 解决 |
|---|---|---|
| 角色面部漂移 | 关键帧分辨率太低 | 上传更高分辨率关键帧 |
| 物体凭空出现 / 消失 | 运镜描述太复杂 | 简化描述 |
| 整体崩坏 | AI 没理解关键帧 | 换工具 / 换种子 / 改 prompt |
| 动作太僵硬 | 没描述运动方向 | 加"slowly" / "smoothly" / "gradually" |
| 镜头乱晃 | 没指定运镜 | 加"static camera" / "no camera movement" |

### 常见错误

❌ 用未经选择的关键帧硬上 → 视频也崩
❌ 一句描述包含 3 个动作 → AI 抓不住重点
❌ 重抽 10 次都崩还坚持用 → 应该回去改关键帧或重写描述

### 资源

- 可灵 / 即梦官方教程
- B 站搜"可灵图生视频技巧"

## H · ⑦ 配音

### 核心要点

1. **音色固化**:每个角色锁定一个音色,不要换来换去
2. **情绪表达 > 字正腔圆**:有情绪的"塑料音"比无情绪的"专业音"好
3. **停顿和重音是灵魂**:逗号 / 破折号 / 省略号要明确写
4. **多角色作品要听感区分**:男主 / 女主 / 男配 / 旁白 必须音色分明

### 音色定调

每个角色一份"音色档案"(可写在 `材料库/人物/<角色>.md` 里):

```
角色:陆战神
音色:磁性低音男声(40 岁)
工具:魔音工坊 → 沉稳商务男 → 语速 0.95 → 音调 -2
情绪默认:冷峻
情绪范围:[冷峻、愤怒、悲悯、温柔]
```

### F1 配音指令 Agent

输入:剧本台词 + 角色音色档案
输出:每句台词的"TTS 指令"——含音色 / 语速 / 情绪 / 停顿标记

例:
```
原台词:你还有什么话要说?
TTS 指令:[音色:沉稳商务男][语速:0.9][情绪:冷峻]你还有什么话要说?
```

### 实操步骤

1. 配置好每个角色的音色档案,存到 `材料库/人物/<角色>.md`
2. 把剧本台词 + 音色档案喂给 F1 agent
3. 得到带 TTS 指令的台词清单
4. 在配音工具(魔音工坊 / Fish Audio / 剪映)逐句生成
5. 每句存为 wav / mp3,存到 `我的作品/<项目>/07_音频/配音/<镜号>.wav`

### 常见错误

❌ 全集用同一个音色 → 角色辨识度为零
❌ AI 配音直接用,不调情绪 → 听起来像导航播报
❌ 台词太长没断句 → 配音读得喘不过气
❌ 不预览就一次性生成 → 后期才发现错字、错音

### 资源

- 听优秀漫剧的配音(尤其是抖音 / B 站头部账号)
- 配音教程:B 站"AI 配音情绪调教"

## I · ⑧ 音乐音效

### 核心要点

1. **BGM 决定情绪基调** ——选错 BGM 比画面崩还致命
2. **音效让画面"活"过来** ——脚步声 / 风声 / 雷声 / 武器声
3. **音量分级**:人声 > 音效 > BGM(BGM 音量比配音低 8-15dB)
4. **卡点**:重要节奏(反转 / 爆点)要和音乐节拍对齐

### BGM 选型

| 情绪 | 推荐方向 |
|---|---|
| 紧张 / 悬疑 | 电子鼓点 / 弦乐颤音 / 低频脉冲 |
| 爽点 / 打脸 | 强鼓点 / Brass / 加速类电子 |
| 悲伤 / 抒情 | 钢琴独奏 / 弦乐 / 简单旋律 |
| 浪漫 / 治愈 | 民谣 / Lofi / 钢琴+弦乐 |
| 史诗 / 大场面 | 交响 / 合唱 / Trailer Music |

### BGM 来源(商用合规)

1. **剪映音乐库**:免费、商用合规、抖音视频号优先(同生态)
2. **抖音 / 视频号 创作中心**:平台原生 BGM 包,推流加成
3. **Suno**:AI 生成,可商用(注意条款)
4. **国外免版税库**:Epidemic Sound / Artlist(付费订阅)
5. **网易云"创作者素材库"**:免费 + 商用

⚠️ **绝对禁止**:
- 用未授权流行歌(周杰伦 / 抖音热歌)→ 必限流 / 下架
- 用电影 / 番剧 OST → 大概率版权方追责

### 音效来源

- **剪映音效库**(免费、够用)
- **freesound.org**(免费,CC 协议要注意)
- **Soundsnap / Splice**(付费)

### 卡点技巧

1. 听 BGM,标出节拍点(每 2-3 秒一个鼓点)
2. 安排"爆点画面"对齐鼓点(剧本里的反转 / 爆头 / 真相揭示)
3. 转场点选在节拍点(切镜头跟着鼓点走)

### 常见错误

❌ BGM 一首到底 → 单调,情绪不变化
❌ BGM 比配音大声 → 听不清台词
❌ 没有音效 → 画面"飘"、不真实
❌ 用流行歌 → 限流

### Agent

**无 agent**(选歌很难标准化为 prompt)。但可以建立**自己的 BGM 库**:每首歌标"情绪 / 节奏 / 长度",存到 `材料库/`(后续可建 `材料库/音乐/` 子目录)。

## J · ⑨ 剪辑后期

### 核心要点

1. **节奏 = 镜头切换频率**:抖音快节奏 = 平均 2-3 秒切一刀
2. **转场克制**:90% 用硬切(直接切),10% 用淡入淡出 / 滑动
3. **字幕必加**:平台用户多在静音状态刷,没字幕就划走
4. **调色统一**:整部作品的色温 / 饱和度 / 对比度要一致

### 剪辑工作流(剪映)

1. **导入素材**:把 06_视频/ 下所有镜头按顺序拖到时间轴
2. **配音对位**:把 07_音频/配音/ 下的台词逐一拖到对应镜头
3. **加 BGM**:拖到独立轨道,音量 -15dB 起步,卡到节拍点
4. **加音效**:雨声 / 雷声 / 武器声 / 脚步声…… 散布到合适位置
5. **加字幕**:用"自动识别字幕",手动校对错字,选合适的字体 / 颜色
6. **加片头片尾**:1-2 秒的 Logo / 频道名
7. **调色**:统一滤镜 / 色温 / 饱和度
8. **导出**:1080p,H.264,码率 8-15Mbps

### 字幕规范

- **位置**:画面底部 1/4 处,避开人物面部
- **字体**:抖音用"思源黑体 / 阿里普惠"等粗黑体;B 站可用方正字体
- **颜色**:白字 + 黑色描边 + 半透明黑底(最稳)
- **每行字数**:≤ 15 字,超过自动换行
- **时长**:每条字幕 ≥ 1.5 秒(留够阅读时间)

### 调色基本套路

| 题材 | 色调 |
|---|---|
| 玄幻 / 仙侠 | 高饱和 + 偏蓝绿(仙气) |
| 都市 / 战神 | 低饱和 + 高对比(电影感) |
| 治愈 / 童话 | 高亮度 + 暖色(温暖感) |
| 悬疑 / 恐怖 | 低饱和 + 冷色 + 高对比 |

### 常见错误

❌ 转场花哨(每个镜头不同转场) → 廉价感
❌ 不加字幕 → 静音播放完播率暴跌
❌ BGM 喧宾夺主 → 听不清台词
❌ 节奏一根直线(全是 5 秒) → 用户失去耐心

### Agent

**无 agent**(剪辑是手感活)。但可以建立**自己的剪辑 SOP**(标准流程):记录"导入 → 配音 → BGM → 字幕 → 调色 → 导出"的固定动作,效率翻倍。

## K · ⑩ 发布运营

### 核心要点

1. **标题决定点击,封面决定停留,前 3 秒决定完播**
2. **平台调性 = 标题语气 + 封面风格 + 标签策略**
3. **数据驱动迭代**:不爆的作品复盘"哪一步导致没人看",下一部修正

### 标题钩子套路(抖音 / 视频号)

- **悬念式**:"她以为离婚就解脱,没想到……"
- **冲突式**:"老公给小三 100 万,我笑着递上离婚协议"
- **反差式**:"看似废物的赘婿,竟是隐藏的天王"
- **数字式**:"3 分钟看完一段虐恋"
- **代入式**:"如果你也遇到这样的事,你会怎么办?"

### 封面规范

- **大字标题**:占封面 1/3,最显眼的钩子词
- **主角面部 / 表情**:情绪强烈的特写
- **对比 / 反差**:好坏两方 / 前后对比 / 强弱对比
- **统一风格**:整个账号封面颜色 / 字体一致(账号视觉锤)

### 标签策略

- 大标签(高竞争):#AI漫剧 #短剧 #战神
- 中标签(精准):#AI漫剧推荐 #战神归来 #女频
- 长尾标签(低竞争 / 高匹配):你的题材独有词

每条作品打 3-5 个标签,**前 2 个最重要**(平台优先识别)。

### 发布时机

| 平台 | 推荐发布时间 |
|---|---|
| 抖音 | 中午 12-13 点 / 晚上 19-22 点 |
| 视频号 | 早上 7-9 点 / 晚上 20-22 点 |
| B 站 | 晚上 18-22 点 / 周末白天 |
| 小红书 | 中午 11-13 点 / 晚上 20-23 点 |

### 数据复盘要点

发布 24h 后,记录:
- 播放量
- 完播率(关键指标)
- 点赞 / 评论 / 分享比例
- 涨粉数
- 评论关键词(用户在说什么)

**复盘四问**:
1. 标题钩子够吗?(看点击率)
2. 前 3 秒留住人了吗?(看 3 秒完播率)
3. 中段有掉粉吗?(看完整完播曲线)
4. 结尾引发互动了吗?(看点赞 / 评论 / 关注)

### 常见错误

❌ 标题平铺直叙没钩子 → 没人点
❌ 封面用作品截图 → 不显眼
❌ 一个时间段发完一周内容 → 平台限流
❌ 不复盘数据 → 永远不进步

### Agent

**无 agent**(运营靠平台理解和数据感觉)。但可以建立**标题模板库** / **封面模板库**,存到 `材料库/`(后续可建 `材料库/运营/` 子目录)。
