# SOP · 剧本制作阶段(流水线第 ④ 步)

> 用 **B1 → B2 → B3** 三个 agent,把"小说终稿"变成"可直接进入分镜的剧本成稿"。

> **⚠️ V2.0 节奏更新(2026-05-25)**:
> - **B1** per 1 集,每集喂入 A3 精化版 + 世界圣经
> - **B2** per 1 集,每集喂入 B1 输出 + 世界圣经
> - **B3** per 5 集批审,喂入本批 B2 + A3 + 世界圣经 + A1 大纲
>
> 完整启动语见 `材料库/操作指南.md` §3。世界圣经模板见 `材料库/世界圣经模板.md`。
> 下文若仍有"整本一次跑"的描述,以本提示与各 agent §输入约定为准。

## 0 · 前置准备(0.25 小时)

### 0.1 确认上游产物齐全

需要:
- [ ] `01_小说.md` 终稿(A4 已审过)
- [ ] A3 输出的资产卡(角色 / 场景 / 道具 / 武器法宝)
- [ ] A1 大纲(查铺垫清单要用)

如缺,**回到小说创作 SOP 补完**。

### 0.2 确认 5 个字段

| 字段 | 用在哪 |
|---|---|
| 题材 | B1 类型特化模块选择(战神 / 总裁 / 修仙玄幻 / 重生穿越 / 古风宫斗 / 复仇 / 甜宠言情 / 现代都市 / 悬疑 / 恐怖,与 A1/A4 枚举对齐) |
| 集数 | B1 集集对应约束 |
| 每集时长 | B1 字数 / 时长换算依据 |
| 平台 | B3 题材爆点审 |
| 小说总字数 | 估算剧本字数预期(≈ 1.5-2 倍) |

### 0.3 与 D1 视觉设定集的关系(V1.2 调整)

**D1 视觉设定集不再与 B1 并行**,已挪到分镜审查(C3)之后、故事板(D3)之前。原因:
- 分镜词出来后,所有出场角色 + 所有服装变化(战神揭身份换军装、总裁出席酒会换礼服 ...)+ 关键道具都已锁定,此时做三视图可一次到位、不返工
- D1 输出是图像 reference,直接服务 D3 故事板锚定角色形象,信息衰减最小
- A3 输出的"文字版资产卡"足以支撑 B1 剧本写作,不需要 D1 图像版

**所以剧本阶段不需要 D1**——直接跑 B1 → B2 → B3 即可,D1 等分镜锁定后再做。

## 1 · B1 剧本生成(2-4 小时)

### 1.1 配置

DeepSeek 智能体 / Claude Project / 新对话,system prompt 用 `材料库/agent/B1_剧本生成.md` 全文。

### 1.2 喂输入

```
{小说终稿}: <01_小说.md 全文 + A3 资产卡>
{题材}: 战神归来
{集数}: 10
{平台}: 抖音
{每集时长}: 180s
```

### 1.3 接收输出

B1 会按"剧本格式标准"输出:
- 每集开头有 logline + 节拍位置标注
- 每集 N 场,场号 `N-1` ~ `N-X`
- 每场标:章节 / 序号 / 场景画面 / 人物 / 道具(关键/常规) / 对应小说节拍 / 预估时长
- 剧本正文用 △ 动作 + 角色对白 + (音效) + 转场标记
- **按题材自动注入特化标记**(玄幻的特效 / 战神的旁人反应 / 古风的服饰特写 / 悬疑的线索 ...)

### 1.4 卡口检查 ⭐⭐⭐

这是剧本阶段最关键的卡口。逐项自检:

- [ ] **集集对应**:小说第 N 集 → 剧本第 N 集场号 `N-1` ~ `N-X`?
- [ ] **对白原句保留**:任抽 5 句小说关键对白,对比剧本是否一字不差?
- [ ] **心理外化测试**:翻 5 段心理戏,看是否都转成动作 / 表情 / 环境音?(超过 50 字的内心独白 = 违规)
- [ ] **道具分级标注**:每场道具都标了"(关键)" / "(常规,特写×N)"?
- [ ] **类型特化标记**:按 {题材} 注入了对应模块的标记?
- [ ] **中文标点**:全文无英文标点("." → "。", "," → ",", '"' → """")
- [ ] **时长合理**:每场 1-3 分钟?总时长 ≈ {每集时长}?
- [ ] **镜头连接性完整**:动作有起承转合?(转身 → 走向 → 抬手 → 看向 这种连续不能缺中间)
- [ ] **节拍位置标注完整**:每集开头都标了 8 节拍对应的场号?

不通过 → 在 B1 对话里**精确指出哪集哪场哪条规则违反**,要求重写**那一场或那一集**——不要让 B1 全文重来。

### 1.5 存档

存到:`我的作品/<项目>/03a_剧本初稿.md`

## 2 · B2 剧本精简(0.5-1.5 小时)

### 2.1 配置

**新对话窗口**,不复用 B1 的——避免上下文污染。
system prompt:`材料库/agent/B2_剧本精简.md`

### 2.2 喂输入

`03a_剧本初稿.md` 全文。

### 2.3 接收输出

- 精简版剧本全文
- 删改说明表(删除统计 + 精彩度保障 + 字数变化)

### 2.4 卡口检查 ⭐⭐

- [ ] **镜头连接性 100% 保留**:对照 B1 原稿抽查 10 个动作,精简后是否完整?
- [ ] **对白实质不变**:抽查 5 句关键对白,精简后是否一字不差?
- [ ] **铺垫 / 伏笔 100% 保留**:对照 A1 大纲铺垫清单逐条核对
- [ ] **类型特化标记 100% 保留**:玄幻的特效 / 战神的旁人反应等不能丢
- [ ] **8 节拍位置 100% 保留**:每集开头的节拍标注不能丢
- [ ] **精简率 15-30%**:过低 = 没精简,过高 = 可能伤剧情
- [ ] **冲突戏全保留**:对峙 / 反转 / 爽点戏不能压缩

⚠️ **重点检查"镜头连接性"**:这是 B2 最容易出问题的地方。例:

B1 原稿:
```
△他缓缓站起。
△他走向妻妹。
△他抬手。
```
✅ B2 合理精简:`△他缓缓站起,走向妻妹,缓缓抬手。`(三动作合并,但起承转合保留)
❌ B2 错误精简:`△他抬手。`(从坐姿突然到抬手前,**后续分镜会跳帧**)

### 2.5 存档

存到:`我的作品/<项目>/03b_剧本精简.md`
删改说明存:`我的作品/<项目>/03b_删改说明.md`

---

## 3 · B3 连贯审查(0.5-1 小时)

### 3.1 配置

新对话窗口。system prompt:`材料库/agent/B3_剧本连贯审查.md`

### 3.2 喂输入

两段:
- `01_小说.md` 全文
- `03b_剧本精简.md` 全文
- (建议同时给 `01a_大纲.md` 用于铺垫清单审查)

### 3.3 接收输出

6 个子报告:
1. **集集对应审**(逐集节拍齐全度)
2. **关键信息保留审**(对白 / 铺垫 / 道具)
3. **场与场连贯审**(5 维:时间线 / 空间 / 道具流转 / 人物动机 / 配角)
4. **整体节奏审**(集钩子 / 爽点 / 题材爆点)
5. **修订优先级矩阵**(P0 / P1 / P2)
6. **给作者的总结建议**(≤ 200 字)

### 3.4 卡口决策

- **P0 必改**:全改,不改不发布(集集对应错误 / 关键对白丢失 / 铺垫断裂 / 时空跳跃)
- **P1 建议改**:挑提升明显的改
- **P2 可选**:能放就放

### 3.5 应用建议 + 输出完整剧本(关键闭环 ⭐)

B3 只审不写,**应用 P0/P1 建议是你的工作**。按修订量级选路径:

| 修订量级 | 操作方式 | 产出 |
|---|---|---|
| **小范围**(单场对白 / 单段微调) | **你自己手改** `03b_剧本精简.md` | 改完直接覆盖 |
| **中范围**(单集 1-2 场重写 / 单场连贯断裂) | 回到 **B1 对话**(同窗口),精确指出改哪集哪场,要求重写;然后回到 **B2 对话**重新精简变更场次 | 更新 `03a/03b` |
| **大范围**(集集对应错误 / 整集节奏崩 / 铺垫断裂) | 改 B1 输入(小说终稿)+ 回 B1 重跑变更集 → 回 B2 精简 → 回 B3 复审 | 更新 `03a/03b/03c` |
| **修订量 > 30%** | 把改后剧本**重新喂回 B3 再审一遍**(避免修订引入新问题) | 二次审查报告 → 覆盖 `03c_审查报告.md` |

### 3.6 输出终稿

应用完所有 P0(必改)+ 决定采纳的 P1 后:

- **审查报告** → `我的作品/<项目>/03c_审查报告.md`
- **最终剧本**(应用建议后的完整版) → `我的作品/<项目>/03_剧本.md`(终稿,可进 C1 分镜)
- 在终稿头部加一段元数据:`<!-- 应用 B3 建议:P0 全改(N 项) / P1 改 M 项 / P2 全保留 -->`

## 常见卡点 + 应对

| 卡点 | 应对 |
|---|---|
| B1 输出对白被改写 | B1 prompt 加重"对白原句保留"约束,新对话重跑那一集 |
| B1 心理戏没外化(出现大段独白) | 用户消息追加:"按 B1 心理活动外化策略重写第 N 集第 X 场" |
| B1 类型特化标记缺失 | 检查输入字段 {题材} 是否填了;改后重跑 |
| B1 使用英文标点 | 直接在对话里说"全文换中文标点重新输出" |
| B2 精简过度删了镜头连接动作 | 让 B2 对照 B1 原稿恢复连续动作,合并而非删除 |
| B2 精简率 < 15% | 让 B2 重新精简,重点压缩龙套和车轱辘话 |
| B3 报告太笼统 | 改 B3 prompt 加重"结构化表格 + 具体改写建议"约束 |
| B3 漏审某集 | 在 B3 对话里直接补:"请补审第 N 集" |
| 总耗时 > 8 小时 | 多半是 B1 一次写整剧后段崩 → 分集喂入,每次只让 B1 处理 1-2 集 |
