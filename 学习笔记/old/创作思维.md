# 创作思维 · 编剧 / 导演 / 摄影 / 声音 / 剪辑

> **这份笔记不是"按阶段学的一节"——是贯穿所有阶段的工具书。**
> AI 能出图、能写文、能剪片,但"哪个剧本立得住、哪个分镜对、哪张关键帧'有戏'、哪段音乐合适、哪个剪辑点准",必须人来判断。没有这套判断力,你永远只能要 AI 中位水平的产出。
>
> **怎么用这份笔记**:
> - 阶段 2 学完工具后通读一遍,知道有哪些维度
> - 阶段 3 做每一步时,**对应章节反复回查**(尤其是 ②/④/⑤/⑥/⑦/⑧/⑨/⑩)
> - 每拆完一部别人的作品 / 做完自己的一集,用 G 节"自检清单"过一遍

## A · 编剧思维

### A.1 Logline(故事核一句话)

**写不出 logline = 故事还没立住,不要开拍。**

Logline 是用 15-30 字概括整部作品的"故事核"。标准句式:

> 一个 [主角特质] 的 [主角身份],为了 [目标],必须 [行动],尽管 [障碍]。

漫剧 logline 必须强化**反差**——这是钩子的源头。

例子:
- **战神归来**:被退婚 5 年的废婿,实则是镇守边疆的战神,如今归来要让所有人付出代价
- **总裁文**:被霸总当替身爱了 3 年的灰姑娘,发现自己竟是真正的豪门继承人
- **修仙**:被宗门赶出的废柴,被野老乞丐传授无上神功,十年后归来踏破师门

**Logline 的三重价值**:
1. 自检:写不出 = 故事松散
2. 标题来源:漫剧标题往往就是 logline 缩短
3. Pitch:30 秒说清楚你做的是什么,合伙人/平台编辑才听得懂

### A.2 主题(Theme)

主题 ≠ Logline。
- Logline:**讲什么故事**(情节)
- 主题:**讲这个故事是为了说什么**(关于人性/社会/价值观)

漫剧主题往往很朴素:

| 题材 | 典型主题 |
|---|---|
| 战神归来 | 真正的强者不需要他人证明 |
| 重生 | 如果重来一次,你会怎样 |
| 总裁 | 贫贱不能移其志 |
| 修仙 | 大道在心,不在天 |
| 复仇 | 善有善报,恶有恶报 |

**主题决定**:
- 角色做关键选择时的方向(主角面对诱惑会不会动摇?取决于主题)
- 爽点的形态(打脸是因为"实力终被认可",而非"运气好")
- 结尾的处理(主题没立起来,结局怎么写都空)

**铁律**:你说不出自己作品的主题 → 作品就是空壳 → 观众看完不会有"为什么而感动"。

### A.3 故事的底层结构(三幕)

最简模型,所有故事都套得上:

| 幕 | 占比 | 任务 |
|---|---|---|
| 第一幕 · 开端 | 25% | 立人设 + 立世界 → **触发事件**(打破平衡的那件事) |
| 第二幕 · 对抗 | 50% | 主角追求目标,障碍逐级升级 → **中点反转** |
| 第三幕 · 结局 | 25% | 高潮 → 解决 → 新平衡 |

**漫剧短剧的特殊性**:
- 60 秒短剧,三幕被压到 10s / 30s / 20s
- **前 3 秒必须钩住人**——通常用"反常识反转"开篇
- 长剧(每集 3-5 分钟)每集都是一个小三幕,**集与集之间用悬念串联**

### A.4 节拍表(Save the Cat 漫剧化)

三幕太粗,真正写时用 8 节拍卡时间轴(3-5 分钟一集版):

| # | 节拍 | 时长 | 内容 |
|---|---|---|---|
| 1 | 钩子 | 0-3 秒 | 反差开场(被打 / 被退婚 / 被嘲笑) |
| 2 | 立人设+立世界 | 3-30 秒 | 主角是谁、在哪、什么处境 |
| 3 | 触发事件 | 30-60 秒 | 打破平衡的那件事 |
| 4 | 行动+第一次升级 | 60-120 秒 | 主角做出反应,障碍升级 |
| 5 | 中点反转 | 120-180 秒 | 看似要赢 → 突然挫败 / 看似要败 → 突然转机 |
| 6 | 至暗时刻 | 180-240 秒 | 看似没救了 |
| 7 | 高潮+爽点 | 240-280 秒 | 主角的决断 + 翻转 |
| 8 | 钩子收尾 | 280-300 秒 | 新平衡 + 留悬念给下一集 |

**60 秒短剧版**:压成 4 节拍 → 钩子(0-3s) / 升级(3-30s) / 反转(30-50s) / 爽点收尾(50-60s)。

**用法**:动笔写之前**先列节拍表**,时间轴卡死 → 不会写到一半发现节奏崩 / 写不到爽点 / 留不下钩子。

### A.5 人物弧光

**没有变化的角色不是主角,是工具人。**

- 起点性格 → 触发事件 → 经历障碍 → 内心转变 → 终点性格
- 变化的推动力:**外部事件(逼他)+ 内部决定(他选)**
- 漫剧爽文的弧光通常很简单:**"被瞧不起 → 翻身打脸 → 重新被尊重"**,但要让人信服必须有"为什么这次他不一样了"
- 配角可以是功能性的(只为推动主角),主角不行

### A.6 冲突

故事 = 主角 × 障碍 × N。**没有冲突就没有故事。**

三类障碍,好作品三种都要有:
- **外部障碍**:反派 / 环境 / 命运(爽文重点)
- **内部障碍**:性格缺陷 / 价值观矛盾(让角色立体)
- **关系障碍**:亲情 / 爱情 / 友情的拉扯(让故事有温度)

**新手常犯的错**:全是外部冲突,主角像 NPC 被推着走 → 看着爽,但记不住。

### A.7 单场戏写作(目标 / 冲突 / 转折)

一场戏 = 一个**戏剧单位**,内部必须有"开始 → 中间 → 结束"的微型三幕。

写每场戏前,先回答三件事:

1. **场景目标**:这场戏里,谁想要什么?(可能是主角,也可能是反派)
2. **场景冲突**:阻碍是什么?(对手 / 环境 / 内心)
3. **场景转折**:这场戏结束时的状态必须**和开始不同**——信息得到了 / 关系改变了 / 决心强化了 / 反派下定决心 ...

**没有转折的场景 = 水戏,删**。哪怕只是"主角的怀疑变成了确信"也算转折。

漫剧场景通常 15-30 秒一场(更碎),但这三件事仍然必须齐。

**例子**:
> 场景:女主进咖啡馆见前男友
> - 目标:女主想要"了断"
> - 冲突:前男友试图挽回
> - 转折:进场时女主还有动摇,出场时彻底决绝(转折点是前男友说漏的那句话)

### A.8 对白写作(潜台词 / 差异化)

漫剧 60% 时长是对白,写不好就是灾难。三大原则:

**原则 1:潜台词 > 字面**

好对白说的**不是字面意思**。

| 场景 | ❌ 字面对白 | ✅ 潜台词对白 |
|---|---|---|
| 妻子怀疑丈夫出轨 | "你是不是不爱我了?" | "你今天加班吗?……又是和那个赵小姐?" |
| 反派试探主角 | "你到底是谁?" | "听说你最近添了块好表" |
| 表白 | "我喜欢你" | "明天的雨,你想看吗?" |

**原则 2:角色语言差异化**

不同角色说同一意思,说话方式必须不同。

| 角色 | "敢动她你就死定了" 的不同说法 |
|---|---|
| 战神 | 动她,你死。(短、硬、不解释) |
| 文人 | 动她一根头发,我让你后悔来这世上。(长、绕、文气) |
| 阴谋家 | 你确定要这么做?(不威胁,反问,更冷) |
| 痞子 | 你他妈再碰她试试?(脏字,粗暴) |

**自检铁律**:对白写完通读,**把角色名字盖住,看你能否分辨出来**。分不出 = 对白没写到角色身上。

**原则 3:少即是多**

- 每句台词不超过 12 字(网文风,适合短剧)
- 长台词必须配画面动态(走动 / 摔东西 / 镜头推拉),不能干说
- 能用一个眼神替代的台词,**全部删掉**
- 反派对白尤其要立体——好反派必须"听起来有他的道理"

### A.9 铺垫与回收(Setup & Payoff)

**漫剧爽点的 90% 引擎。**

- **铺垫(Setup)**:前期不动声色地"埋"一个细节 / 道具 / 台词
- **回收(Payoff)**:后期"砰"地兑现,观众"哦原来如此!"

**漫剧典型铺垫**:
- 主角的"无能"表象 → 后面揭示真实身份(战神归来)
- 反派早期欺辱的小细节 → 后面被一一打脸回应("你当年踩我那一脚,记得吗?")
- 主角不经意提到的"我朋友" → 后期出现的真正大佬
- 第一集的某个道具 → 关键时刻成为反转钥匙

**三大铁律**:

1. **铺垫必须不显眼,但可回忆**——观众看完会想"原来第 1 集就提过"
2. **回收必须比铺垫力度大**——产生"卧槽"感,而不是"哦"感
3. **不回收的铺垫 = 烂尾**——埋了就必须收,否则全部删除

**漫剧的层级用法**:
- **同集内**:30 秒短铺垫 + 30 秒短回收(每集都有小爽)
- **跨集**:第 1-3 集埋,第 10 集前后回收(吊住整个追剧周期)

### A.10 爽点机制(短剧特化)

**爽点公式 = 之前憋了多久 × 翻转的力度。**

四种最常见的漫剧爽点:

| 类型 | 模式 | 代表 |
|---|---|---|
| 打脸 | 被瞧不起 → 翻身 → 反向羞辱 | 战神归来、赘婿 |
| 认亲 | 身世悬念 → 揭晓 → 待遇逆转 | 隐藏豪门 |
| 救赎 | 绝境 → 主角出手 → 化险为夷 | 扮猪吃老虎 |
| 互动 | 暧昧推拉 → 突破 → 甜爆 | 言情 / 总裁 |

**节奏铁律**:
- **每 30-60 秒一个小爽点**(短剧)
- **每 3 分钟一个大爽点**(中长剧)
- 没有爽点的镜头叫"水戏",必须删

### A.11 悬念 vs 反转

容易混的两个概念:

- **悬念**:观众**知道**有事会发生,但不知道**怎么**发生
  - 例:观众看到桌下有炸弹,角色不知道——观众揪心
- **反转**:观众**以为是 A**,结果是 B
  - 例:看着像反派,结果是被冤枉的好人

漫剧节奏推荐:**开头扔悬念 → 中段反转 → 结尾再翻一次**。
- 钩住的是悬念
- 留人的是反转
- 出圈的是"反转之后再反转"

### A.12 节奏控制

短剧不允许"什么都不做"的镜头。**每个镜头必须做以下三件事之一**:
1. 推进剧情
2. 塑造人物
3. 营造情绪

否则就是水戏,必须删。

其他节奏要点:
- **长场景必须夹快剪**——5 秒慢镜头 + 5 秒快剪 + 3 秒慢镜头喘息
- **一句台词不超过 12 字**(网文风),长台词必须配画面动态
- **静与动交替**——全程动观众累,全程静观众睡

### A.13 漫剧 vs 网文 的差异(改编必读)

| 维度 | 网文 | 漫剧 |
|---|---|---|
| 节奏单元 | 章(3000 字) | 镜头(3-5 秒) |
| 描写手段 | 心理 + 对话 + 动作 | 画面 + 台词 + 表情 |
| 信息密度 | 可大段铺垫 | 每镜头都必须有信息 |
| 内心戏 | 大段独白 OK | **必须外化为表情 / 动作 / 台词** |
| 时间感 | 一章可写一秒,也可写一年 | 时长 ≈ 真实时间 |

**网文改漫剧的核心动作**:把"他心里想的"全部转成"他脸上 / 手上 / 嘴上"。

## B · 导演思维

### B.1 导演到底在做什么?

一句话:**把文字翻译成画面。**

编剧给你:"小红走进咖啡馆,看到小明在等她。"
导演要决定 6 件事:
1. 镜头**从哪儿开始**?(从门口推开门?还是先给桌前的小明?)
2. 用**什么景别**?(中景看动作?近景看表情?)
3. 镜头**怎么动**?(固定?跟拍?推镜?)
4. 信息**怎么排序**?(先给"她紧张"还是先给"他笑"?)
5. **多长**?(2 秒还是 5 秒?)
6. **下一个镜头怎么接**?(切?淡?用什么过渡?)

**漫剧时代,这 6 个决定全部体现在 prompt 设计里。** 不写 = AI 替你乱选。

### B.2 场景目标(开拍前必答 3 题)

编剧给你一场戏,**导演要在设计镜头之前回答 3 个问题**:

1. **剧作目标**:这场戏给观众什么信息?推进哪条线?
2. **角色目的**:这场戏里角色各自"想要什么"?(支配 / 表白 / 探听 / 试探 / 拖延 / 试错……)
3. **情绪曲线**:这场戏的情绪怎么走?(平 → 升 → 顶?平 → 降 → 谷?升 → 降?)

想清楚这 3 个再开始设计镜头。

**漫剧时代,这影响**:第一镜从哪儿开始、最后一镜停在哪里、中间用什么镜头节奏。

**例**:女主进咖啡馆见前男友(配合 A.7 例子)
- 剧作目标:让观众知道女主决定了断
- 角色目的:女主想"快刀斩乱麻",前男友想"挽回"
- 情绪曲线:平(进场克制)→ 升(被对方话刺激)→ 顶(决绝起身离开)
- 镜头设计:开场从女主推门走入(平视稳定镜头)→ 对话(过肩切换)→ 顶点(推镜近景,眼神坚定)→ 收尾(她起身离开的背影,前男友脸部失焦)

### B.3 场面调度

谁站哪 / 怎么动 / 镜头怎么看他们 —— 这三件事的组合就是场面调度。

漫剧时代它变成了 prompt 设计:
- 角色站位 → 写进 prompt
- 视角(过肩 / 正面 / POV)→ 写进 prompt
- 动作 → 写进图 prompt 一遍 + 视频 prompt 再写一遍

**新手通病**:prompt 里只写"小红和小明在咖啡馆",不写谁站哪、谁在干嘛——AI 随便出。

### B.4 轴线规则(180° 线)

**做分镜最容易踩坑的硬技术。**

**什么是轴线**:两个角色之间的连线(对话戏)/ 一个角色的视线或动作方向线(单人戏)。

**规则**:镜头机位**始终在轴线的同一侧**,不可越过。

**违反后果**:观众会觉得"两人方向反了"——空间错乱,本能不适。

**例:A 和 B 在咖啡桌两侧对话**
- ✅ A 在画面**左**,B 在画面**右** → 切到 A 特写,A **仍然在画面左**(脸朝右,指向 B 的位置)
- ❌ A 在画面**左**,B 在画面**右** → 切到 A 特写,A **突然跑到画面右**(脸朝左)

唯一允许越线的情况:**用一个运动镜头连贯地越过去**(镜头绕到对面)。

**漫剧时代的执行**:
- AI 出图你要在 prompt 里**明确标"A 在 B 的左侧"**,然后**整场戏保持**这个站位
- AI 不懂轴线,你不标它就乱来——这是漫剧"分镜看着别扭"的最大根源
- 在分镜表里专门加一列"**A/B 站位**"标记

**单人戏的轴线**:角色看向画面外的方向决定下一个镜头从哪边切入(眼神匹配剪辑)。

### B.5 信息密度

一个镜头能让观众接收的信息是有限的。导演要决定:
- **主体**:这一秒,观众必须看到什么?
- **陪体**:顺带让观众看到什么?
- **屏蔽**:不让观众看到什么(虚化 / 出框)?

**铁律**:
- 一个镜头 1 个核心信息,最多 2 个
- 堆 5 个信息 = 观众什么都没看清 = 等于 0 个信息

### B.6 戏剧张力的视觉化

"她很愤怒"——怎么拍?

❌ 字幕打"她很愤怒"
❌ 让她大喊"我好生气!"
✅ 推镜到眼睛 + 手攥拳 + 背景虚化 + 色调偏冷
✅ 摔东西的特写 + 远景里的孤立身影

**铁律:能用画面说的,绝不用台词。**

漫剧由于受 AI 视频技术限制,有时不得不用台词补——但仍要努力**让画面承担 70% 的情绪**,台词只承担 30%。

### B.7 场景切换的逻辑

切换不能乱切,必须有理由:

| 切换类型 | 衔接方式 |
|---|---|
| **时间切换** | 空镜过渡(日落 / 月升 / 时钟 / 翻日历) |
| **空间切换** | 动作衔接(开门 → 进入新场景;低头喝水 → 抬头已在别处) |
| **情绪切换** | 音乐 / 节奏卡点(音乐变 → 画面切) |
| **闪回** | 画面去饱和 + 加颗粒 + 偏黑白 |
| **想象 / 心理** | 画面虚化 / 慢动作 / 色调偏冷或偏暖 |

## C · 摄影 / 镜头思维

### C.1 景别——你和被摄物的距离

| 景别 | 拍到什么 | 用在哪 |
|---|---|---|
| 远景 | 人和环境(人小) | 交代环境 / 渲染氛围(开篇 / 转场) |
| 全景 | 全身入画 | 表现动作 / 多人关系 |
| 中景 | 腰部以上 | 对话戏标配 / 动作 + 表情都要看 |
| 近景 | 胸部以上 | 看清表情 / 表现细节 |
| 特写 | 脸 / 手 / 眼 / 物 | 强调情绪 / 关键物品 |
| 大特写 | 局部(眼睛 / 嘴唇) | 极端情绪 / 关键暗示 |

**漫剧选择依据**:
- 让观众看清"谁" → 近景 / 特写
- 让观众看清"在哪" → 远景 / 全景
- 让观众看清"怎么了" → 中景
- **3 秒短镜头里,90% 不要用远景**(看不清观众就划走)
- 一集里景别要**至少 3 种变化**,否则视觉疲劳

### C.2 机位——你从哪个角度拍

| 机位 | 心理效果 | 用在哪 |
|---|---|---|
| 平视 | 中立 / 叙事 | 大部分对话戏 |
| 仰视 | 被摄物变大 / 压迫感 / 崇敬 | 反派登场 / 主角觉醒 |
| 俯视 | 被摄物变小 / 渺小 / 全局 | 主角绝望 / 上帝视角 |
| 过肩 | 体现两人空间关系 | 对话戏标配 |
| 主观 POV | 代入感 / 沉浸 | 重要发现 / 第一视角紧张 |
| 荷兰角(倾斜) | 不安 / 混乱 / 错位 | 反派 / 心理失衡 |

**常见错误**:
- 全片只用平视 → 平淡无聊
- 滥用仰视 / 俯视 → 观众晕

### C.3 运镜——镜头怎么动

| 运镜 | 效果 | 用在哪 |
|---|---|---|
| 推 | 强调主体 / 拉近情绪 | 反转 / 关键发现 / 情绪爆发 |
| 拉 | 揭示环境 / 拉开距离 | 结尾 / 角色孤立 / 转场 |
| 摇 | 横向扫视 / 跟随视线 | 角色看向某物 / 介绍空间 |
| 移 | 平行跟随 | 角色行走 / 表现动态 |
| 跟 | 跟随角色运动 | 追逐戏 / 沉浸感 |
| 升 / 降 | 揭示纵向空间 | 史诗感 / 渺小感 / 战场全景 |
| 环绕 | 360° 看主体 | 重要登场 / 静态场景动态化 |
| 固定 | 不动 | 对话戏 / 静止突出张力 |

**漫剧的特殊原则**:
- **静止情绪戏 → 固定 + 推**(最稳)
- **动态戏 → 跟 + 移**
- **揭示式 → 拉 / 升降**
- **AI 图生视频里,运镜越简单越稳**——新手不要一个镜头塞多种运镜,AI 会乱
- prompt 里**没写运镜 = AI 默认轻微晃动**——这是新手作品"廉价感"的主因之一

### C.4 构图——画面怎么排

最基础的三种:
1. **三分法**:画面九宫格,重要元素放在 1/3 线 / 交叉点
2. **对称**:庄严 / 仪式感 / 反派老巢
3. **引导线**:用道路 / 视线 / 光线引导观众视线到主体

构图思考点:
- 主体在哪?(观众第一眼看哪)
- 留白:观众的"呼吸空间"
- 前景 / 中景 / 背景:画面层次
- 视线方向:角色看哪儿,引导观众看哪儿

### C.5 光线——画面的情绪密码

| 光线类型 | 效果 |
|---|---|
| 顺光 | 平淡但脸部清晰(新手默认 → 平) |
| 侧光 | 立体感(对话戏首选) |
| 逆光 | 剪影 / 神秘 / 戏剧化 |
| 顶光 | 压抑 / 阴森 |
| 底光 | 恐怖 / 反派(经典恐怖片用法) |
| 伦勃朗光 | 一侧脸亮一侧暗 + 三角形高光 → 油画质感 |
| 暖光(3000K) | 温馨 / 回忆 / 室内 |
| 冷光(6000K) | 冷酷 / 科技 / 现代 / 凌晨 |
| 低调光 | 大面积暗 + 局部光 → 戏剧 / 悬疑 |
| 高调光 | 整体亮 + 少阴影 → 梦境 / 纯净 |

**漫剧 prompt 的杀手锏**:
- 不写光线 → AI 出顺光均匀光 → 平
- 写"侧光 + 暖色 + 局部高光"→ 立刻有戏
- 写"低调光 + 冷色 + 伦勃朗"→ 立刻有质感

### C.6 色彩——画面的潜意识

| 色 | 心理 |
|---|---|
| 红 | 爱 / 危险 / 愤怒 / 激情 |
| 蓝 | 冷静 / 忧郁 / 科技 / 距离 |
| 黄 | 温暖 / 怀旧 / 警告 |
| 绿 | 生机 / 嫉妒 / 不安 / 病态 |
| 紫 | 神秘 / 高贵 / 怪异 |
| 黑白 | 回忆 / 闪回 / 仪式感 |
| 高饱和 | 卡通 / 年轻 / 戏剧 |
| 低饱和 | 写实 / 沉重 / 文艺 |

**调色策略**:
- 整部作品定一个**主色调**(冷 / 暖 / 高饱 / 低饱)
- **关键场景偏离主色调**来制造对比(回忆戏去饱和、爆发戏加红)
- 同一场景前后色调要一致——这是"风格统一"的视觉基础

## E · 声音

> 漫剧 30% 的情绪由声音承载。声音做得不对 = 画面再好都"廉价"。

### E.1 声音的五层级

任何成熟的画面都至少叠加 2 层声音:

| 层级 | 作用 |
|---|---|
| **对白** | 角色说的话(主要叙事载体) |
| **旁白** | 画外音,交代背景 / 主角内心(漫剧高频使用) |
| **环境声** | 风声 / 雨声 / 街道 / 人群嘈杂(让场景"活") |
| **拟音** | 脚步 / 关门 / 喝水 / 翻书(增强真实感) |
| **音乐** | BGM / 主题曲 / 情绪烘托 |

**铁律**:**任何镜头都至少有 2 层声音叠加**——纯对白干声 = 廉价感的最大来源。

漫剧常见失误:只有对白 + 音乐,没有环境声和拟音 → 听感"塑料"。

### E.2 声画关系(同步 / L-cut / J-cut)

三种关系:

| 关系 | 定义 | 效果 |
|---|---|---|
| **同步** | 画面 A 配声音 A | 标准,叙事性 |
| **L-cut**(声延音) | 声音先出现,画面后切 | 下一场对白先来,这一场画面还在 → **强力叙事推进** |
| **J-cut**(画延音) | 画面先切走,声音还在 | 上一场余音延续到下一场 → **情绪延展** |

L-cut 和 J-cut 是好剪辑的标志,**漫剧很少用,用好了立刻显档次**。

例:
- L-cut:画面是女主在咖啡馆愣神,音轨已经响起下一场"砰"的关门声 → 切到男主开门进家
- J-cut:画面已切到第二天清晨,但上一场女主的"我恨你"还在余音 → 暗示她整夜未眠

### E.3 静音的力量

**关键时刻所有声音降到 0**(或只留一个低频心跳),让观众屏息。

用在哪:
- **高潮前 1-2 秒**:蓄势
- **反转那一帧**:让冲击落地
- **角色绝望 / 顿悟时**:让观众感受角色的"世界静了"

漫剧常见错误:全程 BGM 不停 → 重要时刻没有"重"的感觉。

### E.4 音乐的 4 大功能

| 功能 | 用法 |
|---|---|
| **烘托情绪** | 悲 / 喜 / 怒 / 惧——最基础 |
| **推动剧情** | 节奏快的音乐 = 加速感;慢板 = 沉重 |
| **转场标记** | 音乐变 = 章节变(观众下意识接受) |
| **主题动机(Leitmotif)** | 主角/反派各有专属旋律,出现就预示其登场 |

**漫剧选 BGM 的铁律**:
- **不要选带歌词的中文歌**——和对白抢观众脑力
- **纯音乐 / 外语歌 / 古风纯器乐**优先
- 同一情绪用同一首/同一系列(建立观众条件反射:"这首响 = 主角要爆发了")

### E.5 配音表演

漫剧配音(无论真人还是 AI)的 4 个维度:

| 维度 | 说明 |
|---|---|
| **音色** | 角色定位(磁性 / 清亮 / 沙哑 / 稚嫩) |
| **语速** | 情绪指标(快 = 紧张 / 慢 = 沉重) |
| **重音** | 同一句话强调字不同,意思就变(**我**没说你偷的 / 我**没**说你偷的 / 我没说**你**偷的) |
| **停顿** | 有意的停顿 = 戏剧张力(说完 "我..." 顿 2 秒 "...同意") |

**AI 配音的局限**:重音和停顿差,要在配音文本里**加标点 / 拼音音调 / 中括号情绪标注**辅助:

```
[冷] 我...[停 2 秒] 同意。
```

**漫剧特殊技巧**:
- **旁白配音 ≠ 角色配音**——旁白第三人称视角、语调更平;角色配音要带表演
- 同一角色不同情绪要分别试配,选最贴的存档,做成 IP 资产(`材料库/人物/<角色>.md` 的"音色档案")

## F · 剪辑

> 剪辑不是"接素材",是**用素材重新讲一个故事**。同一批素材,不同剪辑 = 不同作品。

### F.1 一场戏的"进点"与"出点"(省略法)

- **进点** = 这场戏从什么时候开始
- **出点** = 这场戏在什么时候结束

**经典法则**:从动作开始之前 1 秒进,到动作结束之前 1 秒出。

**漫剧的极端化**:进得更狠、出得更狠。

❌ 拖沓版:
> 她推门 → 走进咖啡馆 → 环顾 → 找到位置 → 拉开椅子 → 坐下 → 拿菜单 → 翻一下 → 开口说话

✅ 漫剧版:
> 她坐下,直接开口:"你为什么找我?"

**铁律**:**有疑虑就剪——多剪一秒,观众就少留一秒。**

### F.2 正反打(对话戏的标准剪辑)

两人对话的标准模式:

> A 说话(给 A 的镜头) → B 反应(给 B 的镜头) → B 回话(给 B 的镜头) → A 反应(给 A 的镜头)

**关键**:**反应镜头比说话镜头更重要**——演员表情对观众情绪的影响 > 听到的话本身。

漫剧执行:
- 每条对话尽量给一个**反应镜头**,哪怕只 1 秒
- 进阶:**三角调度**——A、B、C 三人对话用 6 个机位(每两人之间一对正反打)
- **常见陷阱**:全程 AB 中景对话 → 没有反应特写 → 没有情绪聚焦 → 看着很疲

### F.3 动作匹配剪辑

一个动作跨两个镜头**无缝衔接**:**前一镜的动作终点 = 后一镜的动作起点**。

**例**:
- 前镜:A 伸手要开门(手抬到一半)
- 后镜:门从里面打开(B 站在门内)

**漫剧的核心应用**:**场景切换用动作匹配**(开门 / 关门 / 抬头 / 低头 / 转身),比硬切自然 10 倍。

**进阶**:**眼神匹配剪辑**——A 看向画面外的某方向 → 切到 A 看的东西(对应方向)。这种切法**最不费观众脑力**,空间感天然连贯。

### F.4 蒙太奇的 3 种实用类型

| 类型 | 手法 | 用在哪 |
|---|---|---|
| **平行蒙太奇** | 两条线交替剪 | 主角线 + 反派线交替 → 制造紧张 |
| **对比蒙太奇** | 对立两个画面交替 | 豪宅 vs 棚户、笑脸 vs 哭脸 → 制造冲击 |
| **隐喻蒙太奇** | 用物象象征情绪 | 凋零的花 = 角色之死;燃烧的烟头 = 怒火 |

**漫剧典型用法**:开头 5 秒可以全用平行蒙太奇制造钩子("一边洞房一边手术,哪边赢?")。

### F.5 漫剧剪辑的特殊性

| 项 | 漫剧标准 |
|---|---|
| **单镜头时长** | **3-5 秒最舒服**(因为 AI 视频通常生成 5 秒);<2 秒观众反应不过来,>8 秒 AI 视频后段必崩 |
| **卡点剪辑** | 重要镜头切在 BGM 的鼓点 / 节拍上(用剪映自动检测节拍点) |
| **转场偏好** | **80% 硬切 + 15% 动作匹配 + 5% 特效转场**(过度炫技反而廉价) |
| **字幕** | 关键台词字幕**加粗 / 变色** → 帮助观众在划走前抓到关键信息 |
| **节奏自检** | 倍速看一遍:0.5x 看是否拖;2x 看是否乱 |

## G · 判断力训练

### G.1 "九问法"——拆解一个优秀镜头

看一部你觉得好的漫剧,逐镜头问 9 个问题(原 7 问 + 声音 + 剪辑):

1. 这个镜头**给了什么信息**?(剧情 / 人物 / 情绪 三选一或多)
2. 这个镜头用了**什么景别 / 机位 / 运镜**?**为什么用这个**?
3. 这个镜头**多长**?为什么是这个时长?
4. 这个镜头**怎么剪进来、怎么剪出去**?(硬切 / 动作匹配 / 声画错位)
5. 这个镜头**声音怎么设计的**?(对白 / 旁白 / 环境 / 拟音 / 音乐 / 静音 的组合)
6. 这个镜头**有什么不必要的元素**?(如果有)
7. **如果是我,我会怎么改**?
8. 这个镜头**给我留下了什么情绪**?**为什么**?
9. 这个镜头**和上下文的关系**是什么?(铺垫 / 回收 / 转折 / 喘息)

**节奏建议**:每周深拆 1-2 个优秀镜头,坚持 3 个月。

### G.2 自检清单——做完一集后必须过一遍

**编剧层**:
- [ ] 一句话能不能讲清 logline?
- [ ] 有没有主题?(不能说出来 = 没有)
- [ ] 节拍表 8 个节拍齐了吗?有没有缺位的?
- [ ] 前 3 秒钩住了吗?
- [ ] 主角有变化吗?
- [ ] 有 30-60 秒一次的小爽点吗?
- [ ] 每场戏有目标 / 冲突 / 转折吗?有水戏吗?
- [ ] 对白盖住角色名,能分辨是谁说的吗?
- [ ] 铺垫都回收了吗?有没有"埋了不收"?
- [ ] 心理活动都外化成画面了吗?

**导演层**:
- [ ] 每场戏的 3 个剧作问题(目标 / 角色目的 / 情绪曲线)都想清楚了吗?
- [ ] 每个镜头的**主体明确**吗?
- [ ] **信息密度**合理吗?
- [ ] **轴线**有没有破?(画面里 A 突然从左跳到右?)
- [ ] 场景切换**有理由**吗?
- [ ] 戏剧张力**视觉化**了吗?

**摄影层**:
- [ ] **景别有变化**吗?(没有全片都是中景)
- [ ] **运镜服务于情绪**吗?(没有为了"动起来"而乱动)
- [ ] **光线营造了情绪**吗?(还是全程顺光?)
- [ ] **调色统一**吗?(没有这一镜暖那一镜冷)

**声音层**:
- [ ] 每个镜头**至少 2 层声音**叠加吗?(不是干对白)
- [ ] BGM 没有抢台词吗?(中文歌词覆盖说话?)
- [ ] 高潮 / 反转前有没有"静音蓄势"?
- [ ] 配音的重音 / 停顿对吗?(尤其 AI 配音要逐句听)

**剪辑层**:
- [ ] 每场戏的进点 / 出点是不是"再剪一秒会更好"?
- [ ] 对话戏有给反应镜头吗?
- [ ] 场景切换有用动作匹配吗?(还是全硬切)
- [ ] 单镜头时长在 3-5 秒区间吗?
- [ ] 音乐卡点了吗?

**节奏层**(总览):
- [ ] **静与动交替**了吗?
- [ ] 倍速看一遍,**节奏对不对**?(0.5x 看是否拖,2x 看是否乱)

### G.3 红灯信号——这些症状一出现就是有问题

| 症状 | 病灶 |
|---|---|
| 别人看完问"你想讲什么?" | 故事结构问题(logline / 主题 / 三幕没立住) |
| 别人说"画面好看但没意思" | 戏剧张力问题(没冲突 / 没爽点 / 单场戏没转折) |
| 别人在第 X 秒划走 | 这一秒前后的镜头有问题(信息量 / 节奏 / 钩子) |
| 自己重看也觉得无聊 | 节奏问题(水戏太多 / 没夹快剪) |
| 评论区在讨论"配音 / 画风" | 故事没立住(观众没东西可聊,只能聊外壳) |
| 完播率低于 30% | 钩子失败 + 中段水戏 |
| 3 秒完播率低于 60% | 开头 3 秒不行 |
| **关掉声音看一遍,故事还讲得通吗?** | 通了说明对白冗余(画面替你说了) |
| **把字幕关掉看一遍,看得懂吗?** | 看不懂说明画面承载不够 |
| **只听声音(关画面)看一遍,情绪还在吗?** | 不在说明声音设计不足 |
| **观众分不清两个角色谁说的话** | 对白没差异化 |
| **铺垫了但观众觉得"没必要"** | 铺垫没回收 / 回收力度不够 |

### G.4 训练资源

**看**:每周看 ≥ 10 部代表作,每月**深拆 ≥ 2 部**(用 G.1 九问法 + `材料库/参考作品/` 拆解模板)。

**读**(分维度推荐,挑相关的看):

| 维度 | 入门读物 |
|---|---|
| 编剧(结构 / 弧光) | 《故事》(罗伯特·麦基)——编剧圣经 |
| 编剧(节拍表) | 《救猫咪》(布莱克·斯奈德)——通俗易懂,讲爽点节奏 / 15 节拍 |
| 编剧(剧本格式) | 《剧本》(悉德·菲尔德)——三幕结构标准教材 |
| 编剧(对白) | 《对白》(罗伯特·麦基)——对白潜台词 / 差异化的圣经 |
| 摄影 | 《电影镜头设计》(史蒂文·卡茨)——景别 / 机位 / 运镜 |
| 剪辑 | 《电影剪辑的魔力》(沃尔特·默奇)——剪辑哲学入门 |
| 声音 | 《声音设计》(大卫·桑萨拉)——音画关系 / 拟音 |
| 网文(钩子节奏) | 挑 3 本完结爆款,**只看前 10 章**,学钩子和节奏 |

**临**:挑一个你觉得好的 3 秒镜头,自己 AI 复刻一遍,**对比差距**——最快的提升方法。

**练**:每集做完先**过一遍 G.2 自检清单**,有 1 项不合格就不发。
