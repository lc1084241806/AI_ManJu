# 学习笔记分类框架

> 用途:给现有学习笔记一个分类参考。**这只是思路文档,具体怎么归、要不要合并,自己动手决定。**
> 整理日期:2026-06-04
> 覆盖范围:`学习笔记/20260530` ~ `20260604` 共 6 篇

---

## 一、核心思路:按「知识的性质和用途」分,而不是按时间

同样是笔记,有的是**即插即用的生产资产**,有的是**可迁移的硬技能**,有的是**会过时的工具操作**。
混在一起会越攒越乱,所以按"它是什么、拿来干嘛"来分。

---

## 二、细分:7 类

### ① 画风 / 视觉风格资产(渲染层)
- **是什么**:出图时填进"画风插槽"的渲染关键词包
- **出处**:`20260530_不同风格的任务提示词模板`
- **含**:次世代CG_超写实、国漫CG_半写实、写实真人摄影;每个画风分模块(人物/兵器/神兽/法宝/道具/场景)给出渲染描述、光影材质细则、禁用清单、负向词
- **性质**:纯生产资产,越攒越值钱

### ② 排版 / 设定卡模板(版式骨架)
- **是什么**:管版面结构的填空骨架(跟①正交——①管画风,②管版式)
- **出处**:`20260531_人物设定卡模板`
- **含**:人物设定卡 9:16 竖版三视图、16:9 横版作品集两套(固定层 + 可变层 + 画风插槽)
- **性质**:生产资产,和①配套使用

### ③ 视听语言 / 分镜技法
- **是什么**:跟工具无关的创作硬功底
- **出处**:`20260601` 第二~三节;`20260603` 能力模型里的"镜头语言/节奏"
- **含**:五种景别功能与组接公式、四种蒙太奇(时间/情绪/平行/联想)
- **性质**:可迁移的硬技能,长期保值

### ④ 一致性控制方法
- **是什么**:专门解决"跨镜头/跨集不穿帮"
- **出处**:`20260601` 场景一致性五法
- **含**:俯视九宫格、场景九宫格+人物图、720°全景、360°环绕截图、image2改机位;关键参数(焦段/光圈/动态模糊)
- **性质**:独立成体系的技术方法

### ⑤ 工具操作 / 实操链路(SOP)
- **是什么**:绑定具体工具的操作步骤
- **出处**:`20260602` LibTV 全链路;`20260604` oiioii 用法 + 故事板 libTV 成片
- **含**:写剧本→提设定→720°环绕→导演台占位→出视频;oiioii 多 agent 成片流程;故事板生成提示词三步
- **性质**:时效性最强,工具一换就可能失效

### ⑥ 行业认知 / 赛道趋势
- **是什么**:"做什么 / 为什么"的战略判断,不动手
- **出处**:`20260602` 红利演进 + 热门赛道;`20260603` 变现底层逻辑、漫剧题材优势、收益逻辑
- **含**:红利四阶段(工具→模型→内容→IP)、赛道分析、变现模式、爽点反转情绪节奏
- **性质**:战略层认知

### ⑦ 能力模型 / 学习路径(元认知)
- **是什么**:教你"怎么学"的导航
- **出处**:`20260603` 六大能力 + 影片赏析方法;`20260604` 线下课三周大纲
- **含**:六大能力(审美/导演/节奏/镜头/情绪/洞察)、拆片模板(EV录屏→切镜头→填表)、课程路线图
- **性质**:元认知,后续学习的地图

## 三、7 类的内在逻辑:一条"从虚到实"的链路

```
⑦学习路径 → ⑥行业认知 → ③视听语言 → ④一致性方法 → ⑤工具SOP → ②排版模板 → ①画风资产
  (怎么学)    (做什么)     (创作功底)    (技术难点)    (动手操作)   (版式)     (画风)
  元认知 ───── 战略 ────── 方法论 ──────────────── 资产/SOP ──────────────
```

- 越靠左越"软"、越保值(认知、方法论,几年不过时)
- 越靠右越"硬"、越具体(模板、画风词包,直接出活)
- 中间 ⑤ 工具 SOP 最易过时(LibTV / oiioii 明年可能就换)
