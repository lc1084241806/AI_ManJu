> **阶段目标**:打掉行业 80% 创作者卡死的坎,把作品质量从"能看"提到"能爆"。

## A · 难点 1:人物一致性(行业第一痛点)

### A.1 成因
- AI 出图本质是"概率采样",每次随机
- 文字描述无法完全锁死面部细节(脸型 / 眼睛形状 / 嘴唇厚度)
- 不同镜头 / 角度 / 表情,AI 可能"重新理解"角色

### A.2 解法梯队(从入门到高级)

#### 解法 1:固定 prompt + 参考图(入门)
- 每个角色一段 50-100 字的"角色 prompt",全集所有镜头都用同一段
- 每个角色出 3-5 张"定型图",每张作为角色参考喂给工具
- **工具支持**:即梦的"角色参考"、MJ 的 `--cref`、Vidu 的"角色一致性"

**实操**:
```
角色 prompt(陆战神):
亚洲男性,30 岁,短黑发,英气锋利眉,深邃眼眸,
方正下颌,薄唇,身高 185cm 体格强壮,左眼角有一道疤
```
+ 上传 3 张定型图 → 每个镜头都用这段 prompt 加这些参考图

效果:**60-70% 一致性**

#### 解法 2:同种子 + 渐进调整(进阶)
- SD 体系:固定 seed(种子值),只改"表情 / 动作 / 镜头"部分的 prompt
- 同 seed + 同基础 prompt = 高度相似输出

效果:**70-80% 一致性**

#### 解法 3:IP-Adapter / FaceID(高级,SD 体系)
- 给一张角色脸部参考图,IP-Adapter 把它"嵌入"到生成过程
- FaceID 专门保面部特征

效果:**80-90% 一致性**

#### 解法 4:LoRA 训练(专业,SD 体系)
- 用 20-50 张角色图,训练一个专属 LoRA 模型
- 之后用 `<lora:角色名:0.7>` 就能稳定召唤
- 训练成本:1-2 小时(本地) / 10-30 元(云端)

效果:**90-95% 一致性,行业最强**

### A.3 选哪个

| 你的工具栈 | 推荐解法 |
|---|---|
| 即梦 / 可灵 / MJ 用户 | 解法 1(固定 prompt + 参考图) |
| SD / ComfyUI 用户 | 解法 3(IP-Adapter)起步 |
| 高产 / 系列剧 / 长期 IP | 解法 4(LoRA 训练) |

### A.4 沉淀到材料库

每个角色一份档案存到 `材料库/人物/<角色名>.md`:
- 完整 prompt
- 5-10 张定型图(放本地,不入 git 大文件)
- 关键特征清单
- 容易翻车的细节
- 用过的解法 + 效果

## B · 难点 2:场景一致性

### B.1 成因
- 场景比人物更难锁:每个角度都不同
- 室内场景的家具摆放、室外场景的地标建筑容易飘

### B.2 解法

#### 解法 1:场景概念图 + 参考图垫底(入门)
- 每个主要场景画一张"建立镜头"作为参考图
- 其他镜头用此图作为"垫图" / "参考图"
- 加固定的场景 prompt 后缀

#### 解法 2:多角度场景集(进阶)
- 每个场景出"远 / 中 / 近 / 不同时间"等 5-10 张,组成场景库
- 出新镜头时选最接近角度的那张作为参考

#### 解法 3:3D 场景搭建(高级)
- 在 Blender / Unreal 搭粗模
- 渲染成 2D 图给 AI 当参考(垫图 / Depth ControlNet)
- 行业头部团队的做法

### B.3 沉淀到材料库

每个场景一份 `材料库/场景/<场景名>.md`:
- 场景 prompt
- 多角度参考图
- 关键道具清单(必须出现:窗户位置、桌椅、特殊物品)

## C · 难点 3:风格统一

### C.1 成因
- 不同 prompt / 工具 / 模型 / 种子 → 风格差异大
- 跨工具混用(MJ 出几张、即梦出几张)风格更乱

### C.2 解法

1. **画风后缀全集统一**:整部作品所有 prompt 都拼同一段 30-50 字的"画风后缀"
2. **同一工具到底**:不要混用多个出图工具
3. **同一模型 / Checkpoint**(SD):锁死一个,不要中途换
4. **后期统一调色**:剪映 / PR 加同一滤镜,把不同图的色调拉平

### C.3 画风后缀模板举例

```
玄幻仙侠:东方水墨风格,工笔重彩,细腻笔触,
高饱和度,云雾缭绕,仙气飘渺,8K 高清

都市战神:写实电影感,低饱和度,高对比度,
冷色调,暗部细节丰富,影视级打光,8K 高清

治愈日常:吉卜力风格,温暖柔光,
浅景深,高亮度,自然色调,水彩质感

国漫风:中式国漫风格,赛璐璐着色,
鲜艳饱和,扁平阴影,流畅线条,大气磅礴
```

### C.4 沉淀到材料库

存到 `材料库/`(可建一个 `画风/` 子目录):
- 每种画风一段后缀 prompt
- 该画风下的 3-5 张代表图

## D · 难点 4:镜头运动可控

### D.1 成因
- "图生视频"工具是黑盒,运镜描述常被忽视
- 复杂描述会让 AI 困惑,简单描述又显得呆板

### D.2 解法

#### 简单镜头优先
不要写"先推近再环绕再拉远",改成"镜头缓慢推近",效果稳定 10 倍。

#### 标准运镜词典
| 想要的效果 | 描述写法 |
|---|---|
| 推近(zoom in) | "camera slowly zooms in to the subject" / "镜头缓慢推近主角" |
| 拉远(zoom out) | "camera slowly zooms out, revealing the environment" |
| 左摇 | "camera pans left slowly" |
| 跟随 | "camera follows the subject moving forward" |
| 静止 | "static camera, subject moves naturally" |
| 升镜头 | "camera rises up gradually" |
| 环绕 | "camera orbits around the subject"(高难度,慎用) |

#### 工具选择
- **可灵**:可控性最强,接受复杂运镜
- **即梦**:中文描述友好,简单运镜最稳
- **Runway Gen-3**:运动质感最自然,但贵

### D.3 沉淀到材料库

存到 `材料库/`(后续可建 `运镜模板/` 子目录):
- 每种运镜一个示例(描述 + 关键帧 + 生成结果)
- 易翻车场景的避坑笔记

## E · 难点 5:手部畸形 / 物理穿模

### E.1 成因
- AI 模型对手指拓扑理解差(尤其老模型)
- 复杂动作 / 道具交互容易穿模
- 多角色同框时身体部位混乱

### E.2 解法

#### 解法 1:负面提示词(基础)
```
deformed hands, extra fingers, missing fingers, fused fingers,
bad anatomy, mutated, ugly hands, distorted hands, watermark
```
中文版:
```
畸形手, 多手指, 少手指, 融合手指, 解剖错误, 变形, 丑陋的手, 水印
```

#### 解法 2:避开高难度构图
- 不让 prompt 出现"双手特写"
- 不写"持剑挥砍"等复杂手部动作
- 复杂动作用"中景"以上景别(看不清手的细节)

#### 解法 3:ControlNet 控制手部(SD 体系)
- 用 OpenPose 给一个"标准手"姿势
- 用 Depth / Canny 锁住手的位置

#### 解法 4:后期局部重绘(SD inpaint / Photoshop AI)
- 出来的图手坏了,框选手部 → 局部重绘 → 修复

#### 解法 5:换工具
- MJ 的手比 SD 老模型好
- Flux 的手比 SD 1.5 好
- **现代工具(Flux / MJ V6+ / 即梦 Pro)手指已经基本不崩**

### E.3 实战经验
**这是 8 个难点里最容易解的**——升级工具就能解决 60%,加负面提示词解决另外 30%,只剩 10% 需要精修。

## F · 难点 6:多角色同框互动

### F.1 成因
- AI 默认"画一个人"
- 多人时面部混淆 / 服装混淆 / 动作错位
- 角色一致性问题被放大 2 倍 / 3 倍

### F.2 解法

#### 解法 1:控制人数 + 明确分工(基础)
- prompt 里明确说"two people":一人 X,另一人 Y
- 用"left side"、"right side"分位置
- 例:"two characters, on the left: 战神(prompt A), on the right: 反派(prompt B)"

#### 解法 2:分别出图 + 合成(进阶)
- 角色 1 单独出一张,角色 2 单独出一张
- 用 Photoshop / 剪映合成到一张图
- 再用图生视频让两人互动

#### 解法 3:Regional Prompter(高级,SD)
- 把画面分成左 / 右两个区域
- 各区域单独 prompt
- 极强可控性

#### 解法 4:用 ControlNet OpenPose(高级)
- 找一张"两人对话"的姿势参考
- 用 OpenPose 锁住姿势
- 再叠加各自的角色 LoRA

### F.3 实战建议
**新手最简单的做法**:
- **避免多角色同框**:用"正反打"(一个镜头拍 A、下一个镜头拍 B)来表现对话
- 必须同框时用**远景 / 全景**(看不清细节)
- 关键剧情(打斗 / 拥抱)用**特写**(只看部分肢体)

## G · 难点 7:长视频稳定性

### G.1 成因
- 图生视频默认 5 秒,5 秒后画面常崩
- 拼接多段时画面跳变

### G.2 解法

#### 解法 1:分段生成 + 拼接(主流)
- 不要追求一个镜头超过 5 秒
- 把"长镜头"拆成 2-3 段 5 秒视频,后期剪辑拼接

#### 解法 2:首尾帧法(进阶)
- 给 AI 起始帧 + 结束帧,让它生成中间过渡
- **工具**:可灵的"首尾帧"功能、Runway 的 First/Last Frame
- 拼接时只需保证"上段结束帧" = "下段起始帧"

#### 解法 3:静态镜头 + 后期添加运动
- 出一张大分辨率静态图
- 在剪映 / PR 加"位移 + 缩放"做出"运镜"效果
- **极稳**,但画面只能"假动",物体不能真动

### G.3 实战建议
- 每个镜头 ≤ 5 秒,极少数 ≤ 8 秒
- 真要 10 秒以上镜头,**拆成 2-3 段**或**用首尾帧**

## H · 难点 8:口型对齐(说话镜头)

### H.1 成因
- 图生视频里的角色"嘴形"很难和配音对上
- 关键帧角色"不张嘴",视频里就更不会张

### H.2 解法

#### 解法 1:避开特写说话镜头(最简单)
- 中景以上,看不太清嘴 → 用户脑补
- 用"背影 / 侧脸 / 转身"等不正面说话的镜头

#### 解法 2:专业对口型工具
- **D-ID**:输入图 + 配音音频 → 自动生成对口型视频
- **HeyGen**:支持中文,效果好,商用付费
- **Sadtalker**(开源):本地部署,免费
- **Live Portrait**(开源):效果惊艳,中文社区在迭代

#### 解法 3:剪辑层面遮蔽
- 说话时镜头切到"听者的表情"
- 听者不需要张嘴,自然规避

### H.3 实战建议
**新手**:用解法 1(避开特写说话)和解法 3(切镜头到听者)。
**进阶**:对**关键情绪台词**用 D-ID / HeyGen 做专门的对口型镜头(每集 2-5 个),其余用解法 1。
