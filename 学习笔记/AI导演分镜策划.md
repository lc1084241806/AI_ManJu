# AI导演分镜策划

> 会分镜的人，才能真正用AI拍电影。

---

## 一、什么是AI分镜策划

分镜回答三个问题：
1. **先让观众看到什么？**
2. **再让观众理解什么？**
3. **最后让观众感受到什么？**

分镜不是把画面拆碎，而是信息配置问题——把所有信息塞在一个镜头里，观众不知道该看什么。

---

## 二、景别组接

### 五种景别的功能

| 景别 | 作用 | 适合场景 |
|------|------|----------|
| 远景 | 交代世界是什么氛围 | 城市街头、海边、医院走廊等环境建立 |
| 全景 | 告诉观众人物在做什么、动作方向 | 走进空间、穿过人群、停下、转身、奔跑 |
| 中景 | 建立人物之间的关系 | 第一次相遇、人物与物品的关系 |
| 近景 | 传递人物内心情绪变化 | 心动、紧张、害怕、挣扎、情绪的克制 |
| 特写 | 放大关键细节，强化意义 | 眼神、笑容、手、物品、文字、牙齿 |

### 景别组接完整公式

```
第一镜（远景）→ 第二镜（全景）→ 第三镜（中景）→ 第四镜（近景）→ 第五镜（特写）
  交代环境          交代动作          建立关系          传递情绪          放大重点
```

> 适用于：开场 / 发现 / 关系建立类场景

### 完整示例：夏日海边集市

| 镜次 | 景别 | 画面内容 | 作用 |
|------|------|----------|------|
| 第一镜 | 远景 | 夏日海边集市，阳光明亮，男孩从远处向镜头走来 | 建立故事空间 |
| 第二镜 | 全景 | 男孩穿过集市，突然停下，看向远方 | 交代动作，制造悬念 |
| 第三镜 | 中景 | 花摊旁，女孩正在挑花，阳光洒在她的白裙和头发上 | 揭示男孩看见的人，建立关系 |
| 第四镜 | 近景 | 切回男孩的脸，他愣住，眼神亮了一下，嘴角想笑又停住 | 让观众感受到心动 |
| 第五镜 | 特写 | 切回女孩的脸，她慢慢抬起头，向男孩方向轻轻笑了一下 | 完成情绪回应，连接两人 |

**核心：** 同一个场景，拆开拍，观众才会被一步步带进故事，而不是一眼看完。

## 三、蒙太奇（镜头之间产生的意义）

蒙太奇核心原理：**镜头之间产生新的意义，观众会自动补全它们之间的关系。**

最简单的例子——同一个表情，后面接不同镜头，观众理解完全不同：

| 前镜头 | 后镜头 | 观众理解 |
|--------|--------|----------|
| 男人平静地笑 | 后面接孩子 | 他很慈祥 |
| 男人平静地笑 | 后面接一箱钱 | 他很贪婪 |
| 男人平静地笑 | 后面接倒下的人 | 他很危险 |

### 四种蒙太奇用法

#### 1. 时间蒙太奇（表现时间的流逝）

- **作用：** 通过道具、光线、环境变化，表现时间流逝
- **适合表达：** 等待、物品变化、光线变化、人物状态变化
- **常见方式：** 特写、时间过去、多景、环境、物品变化

**示例对比：表现一个人等了很久**
- 普通生成：坐在那等了一会
- 时间蒙太奇：手机特写时间一分一秒地跳动；桌上的咖啡慢慢变冷；窗外天色从亮变暗，身边的人来了又走

#### 2. 情绪蒙太奇（表现人物内心）

- **作用：** 用细节叠加，表现人物情绪
- **适合表达：** 紧张、恐惧、焦虑、愤怒、压迫感
- **常见方式：** 身体细节、环境音、物件变化

**示例对比：表现一个人很紧张**
- 普通生成：他说出来我们紧张
- 情绪蒙太奇：生成他握紧杯子的手；额头上的汗；越来越响的钟表声；门外慢慢靠近的脚步声

#### 3. 平行蒙太奇（表现两条线同时发生）

- **作用：** 两条线交替剪辑，制造紧张和悬念
- **适合表达：** 两人错过、追逐、比赛、对比、共同计时等
- **常见方式：** A线推进 → B线推进 → 交叉剪辑 → 共同收尾

**示例对比：表现两个人快要错过**
- 普通生成：只拍一个人奔跑
- 平行蒙太奇：女孩在人群中焦急寻找 → 男孩在另一边站台准备上车 → 女孩越走越远 → 男孩低头看了眼手表 → 女孩推开人群向前跑 → 列车门正在缓缓关闭

#### 4. 联想蒙太奇（改变对前镜头的理解）

- **作用：** 通过后续镜头，改变观众对前镜头的理解
- **适合表达：** 危险、秘密、黑化、背叛、罪恶感等
- **常见方式：** 反差、象征、细节暗示、因果联想

**示例：表现一个人有危险**
- 联想蒙太奇：他平静地笑了一下 → 桌上的刀反射出冷光 → 酒杯摔在地上碎成裂片 → 远处有人倒在阴影里 → 他正在擦掉衣袖上的血迹

## 四、AI分镜策划核心流程

```
1. 明确主题和情绪基调
        ↓
2. 拆解故事关键信息点
   把故事拆成核心心和想传达的情绪的几个重要节点
        ↓
3. 选择合适景别组接
   为每个节点选合适的景别
        ↓
4. 运用蒙太奇增强叙事
   联想蒙太奇组合使用（时间/情绪/平行/联想）
        ↓
5. 优化提示词细化每个镜头
   写清楚画面、情绪、光线等
        ↓
6. 串联镜头形成完整故事
   理清画面和逻辑，让故事流畅完整
```

---

## 五、核心价值

- 让观众一步步进入故事，而不是一次性接收所有信息
- 让画面有重点，有节奏，有情绪，有导演感
- 让AI生成的画面，不只是好看，而是有故事、有理解、有共鸣
- 提高AI视频的叙事质量，让作品更专业、更打动人

**一句话总结：** 会分镜的人，才能真正用AI拍电影。
