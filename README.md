## ⚙️ 流水线一瞥(10 步 / 16 agent)

```
①选题  →  ②小说(A1-A5)  →  ③剧本(B1-B3)  →  ④分镜(C1-C3)
        →  ⑤故事板(D1-D3)  →  ⑥图生视频(E1)  →  ⑦配音(F1)
        →  ⑧音乐音效  →  ⑨剪辑后期  →  ⑩发布运营
```

详见 [学习路线总纲.md §1](学习路线总纲.md)。

## 🤝 协作约定

- 大文件(`*.mp4 *.psd *.wav` 等)不入 git,见 [.gitignore](.gitignore)
- 改 agent 必须在 [材料库/agent/CHANGELOG.md](材料库/agent/CHANGELOG.md) 追加条目
- 新版本必须**完整包含**旧版本内容(详见 `E:\Work\claude\CLAUDE.md` §5.3)
- 命名规范见 [材料库/README.md](材料库/README.md) §使用规范
