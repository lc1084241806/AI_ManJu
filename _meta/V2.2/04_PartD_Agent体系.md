## D.1 核心理念

### Agent ≠ 项目规则

**CLAUDE.md** 是"我和 Claude 协作的工作目录规则"——管的是文件该放哪、任务该怎么开。
**Agent md** 是"喂给 LLM 创建智能体的 system prompt"——管的是 LLM 在某个生产环节该怎么干活。
两者目的不同，**不可混用**。

### 为什么把流水线拆成 agent，而不是写一段长 prompt 一气呵成

| 长 prompt 一气呵成 | 拆成 agent |
|---|---|
| 上下文窗口爆炸 | 每个 agent 只看自己该看的输入 |
| 一处错全盘崩 | 一处错只改一处 |
| 跨平台难复用 | 同一 agent 可跑 DeepSeek / Claude / GPT |
| 无法版本化 | 文件即版本，可入 git，可对比 diff |
| 难以并行 | 独立 agent 可同时跑（如 A5 三视图 + A6 剧本并行） |

### 拆 agent 的真正价值不在"每次都跑"，而在四件事

1. **复用**：一次配置长期用，10 部小说共用同一个 A6 剧本生成 agent。
2. **替换**：A2 小说效果不好就只换 A2，下游 A3/A6 不动。
3. **并行**：A5 出图 + A6 写剧本同时跑，省一半时间。
4. **隔离上下文**：A4 审查规则不会污染 A6 生成规则。

## D.2 Agent 分类：必跑 / 按需 / 并行

一部作品**不需要把 11 个 agent 全跑一遍**，实际执行约 6–8 个：

### 必跑（每部作品都要）

```
A1 大纲 → A2 正文 → A3 精化 → A6 剧本 → A7 精简
```

5 个，**串行**。

### 按需（看题材和需要）

| Agent | 什么时候调用 | 什么时候跳过 |
|---|---|---|
| **A4 小说审查** | 题材敏感（玄幻法宝、悬疑犯罪）/ 投平台前 | 题材安全（治愈、日常）可跳 |
| **A6 类型特化** | 强类型作品（玄幻、科幻、恐怖） | 通用题材用标准版即可 |
| **A8 剧本连贯审查** | 长剧（20 集以上）、改编多次后 | 单集短剧可跳 |

### 可并行（节省时间）

- **A5 三视图** 与 **A6 剧本生成** 可同时跑（一个出图、一个写剧本）。

## D.3 Agent 文档标准 Schema

每个 agent md 文件必须遵守以下结构：

```markdown
# Agent: <名称>

## Meta
- 版本：V1.0
- 日期：YYYY-MM-DD
- 适用平台：DeepSeek / Claude / GPT 通用
- 输入：<期待的输入形态，如"小说原文 5000-30000 字">
- 输出：<期待的输出形态，如"标准格式剧本">

## 角色定位
你是一个 ...

## 输入约定
{题材}: 玄幻 / 现代都市 / 古风穿越 / ...
{平台}: 抖音 / 视频号 / B 站
{集数}: 10 / 20 / 30

## 输出 Schema
（精确描述输出格式：字段、顺序、标点、长度上限）

## 规则
1. ...

## 正例
（一段输入 → 一段输出的完整对照样例）

## 反例
（错误写法示范 + 为什么错）

## 自检清单
- [ ] 是否所有对话保留？
- [ ] 是否符合时长控制？

## 禁止事项
- 不得 ...
```

**关键设计原则**

- **自包含**：单独打开就能用，不依赖外部文件。
- **变量明示**：所有可变项用 `{xxx}` 占位。
- **正反例必须有**：AI 看示例学得比看规则快。
- **自检清单**：让 agent 主动质检。
- **输出长度上限**：避免无限膨胀。

## D.5 Agent 实际使用方式

### 平台 1：DeepSeek

**方式 A · 网页版"智能体"（推荐）**

1. 登录 DeepSeek，进入"智能体"
2. "创建智能体" → 填名称（如 `漫剧-剧本生成-玄幻V1.0`）
3. **系统提示词槽位**：把对应 agent md 整段复制粘贴
4. 保存
5. 之后直接发输入

**方式 B · 普通对话（一次性）**

```
[粘贴 agent md 整段]
---
以上是系统指令，请严格遵守。回复"已就绪"后我会发输入。
```

---

### 平台 2：Claude

**方式 A · Claude.ai Projects（推荐）**
登录 → Create Project → Custom instructions 粘贴 agent md → 直接发输入。

**方式 B · 普通对话**：同 DeepSeek 方式 B。

**方式 C · Claude API（批量自动化）**

```python
import anthropic
client = anthropic.Anthropic(api_key="sk-ant-...")

with open("A6_剧本生成_玄幻特化_V1.0.md", encoding="utf-8") as f:
    system_prompt = f.read()
with open("我的小说.md", encoding="utf-8") as f:
    novel = f.read()

response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=16000,
    system=system_prompt,
    messages=[{"role": "user", "content": novel}]
)
print(response.content[0].text)
```

### 跑完整流水线的实操示范

| # | 对话窗口 | System Prompt | 输入 | 输出 |
|---|---|---|---|---|
| 1 | 窗口 1 | A1 大纲 | 题材 + 集数 + 主角设定 | 大纲 |
| 2 | 窗口 2 | A2 正文 | 上一步大纲 | 小说正文 |
| 3 | 窗口 3 | A3 精化 | 上一步小说 | 精化版小说 |
| 4 | 窗口 4 | A4 审查 *(可选)* | 上一步小说 | 审查 + 修订 |
| 5 | 窗口 5 | A6 剧本生成 | 精化版小说 | 剧本 |
| 6 | 窗口 6 | A7 精简 | 上一步剧本 | 精简剧本 |
| 7 | 窗口 7 | A8 连贯审查 *(可选)* | 上一步剧本 | 审查 + 修订 |
| 并行 | 窗口 X | A5 三视图 | 精化版小说 | 三视图 prompt 组 |

**关键纪律**

- 每个 agent 用独立对话窗口——避免上下文污染。
- 每一步产出立刻存文件——存到 `06_项目作品/<项目名>/` 对应子目录。
- 不满意直接回头改 agent md，重跑。

---

### 常见避坑

| ❌ 错误做法 | ✅ 正确做法 |
|---|---|
| 把所有 agent 揉进一个对话 | 每个 agent 独立窗口 / 独立 Project |
| 把 agent md 写进 CLAUDE.md | agent md 放 `02_提示词库/<阶段>/agents/` |
| 用"对话式"语气 | 用"指令式" system prompt |
| 留对话窗口当存档 | 关闭窗口就丢，必须存文件入 git |
| 占位符忘了替换 | 发输入前先替换或在 user message 里明示 |
