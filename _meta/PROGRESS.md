## 关键决策与上下文（供下次会话恢复）

### Agent 体系核心理念
- **CLAUDE.md ≠ agent system prompt**：CLAUDE.md 是"我和 Claude 协作的项目规则"；agent md 文件是"喂给 DeepSeek/Claude 的系统提示词"。两者目的不同，不要混淆。
- **Agent 文档位置**：建议放在 `02_提示词库/<阶段编号>/agents/<agent_名>.md`，由 V2.1 框架升级正式纳入。
- **拆 agent 的价值不在"每次都跑"，而在复用 / 替换 / 并行 / 隔离上下文。**

### Agent 实际工作流（一部作品一次）
- 必跑 5 个：A1 大纲 → A2 正文 → A3 精化 → A6 剧本 → A7 精简
- 按需 3 个：A4 审查 / A6 类型特化 / A8 连贯审查
- 可并行 1 个：A5 三视图（与 A6 同时跑）
- 总计 6–8 次对话，**不是 11 次全跑**

### Agent md 文件标准 Schema（V2.1 时正式定）
```
# Agent: <名称>
## Meta（版本/日期/适用平台/输入/输出）
## 角色定位
## 输入约定（变量占位符）
## 输出 Schema
## 规则
## 正例 / 反例
## 自检清单
## 禁止事项
```

### Agent 使用方式（DeepSeek / Claude）
- **DeepSeek**：网页版"智能体"创建 → 把 md 整段塞进系统提示词槽位 → 一次配置长期复用
- **Claude**：Projects（Pro 订阅）→ Custom instructions 粘贴 md → 同样复用
- **API**：脚本化批量跑流水线（system=md 内容，messages=用户输入）
