## B.0 总览

```
ManJu_Learn/
├── README.md
├── 01_学习笔记/
├── 02_提示词库/
├── 03_角色与世界观/
├── 04_风格参考/
├── 05_工具笔记/
├── 06_项目作品/
├── 07_资源链接/
├── 99_草稿区/
└── .gitignore
```

设计原则：

- **数字前缀** —— 按学习与生产管线顺序强制排序。
- **"学习"与"产出"分离** —— `01~05` 是知识库（可复用），`06` 是具体作品，`07/99` 是辅助。
- **"模板"与"案例"与"智能体"三层**（V2.1 起）—— `templates/` 是抽象骨架，`examples/` 是具体成功 prompt，`agents/` 是可复用的 LLM 系统提示词。
- **大文件不进 git** —— 工程文件、原始视频、PSD 走 `.gitignore` 或 Git LFS。
- **框架自身可演进** —— 目录结构本身也有版本号，扩张时升级 V1.x → V2.x（详见 B.14）。

## B.1 README.md

**这是什么**
仓库门户。包含：仓库目的、学习路线图、目录索引、常用入口链接。

**什么时候动它**

- 仓库初建时写一次。
- 每完成一个学习阶段、调整一次目录结构时更新。

## B.2 01_学习笔记/

**这是什么**
个人学习产出，第一手知识沉淀。不是别人的提示词（那是 `02_`），也不是项目复盘（那是 `06_<项目>/07_复盘.md`），是你脑子里整理出来的"我学到了什么"。

**子目录**

```
01_学习笔记/
├── 工作流总览.md
├── 未知与待探索.md
├── 基础概念/
├── 教程笔记/
└── 复盘日志/
```

**什么时候用**

- 看完一节课、读完一篇文章 → `教程笔记/`
- 实操练习的反思 → `复盘日志/YYYYMMDD_<主题>.md`
- 想清楚某流程的全貌 → `工作流总览.md`
- 听到陌生术语 → `未知与待探索.md`

## B.3 02_提示词库/

**这是什么**
仓库的核心资产。所有"可复用的"提示词都在这里，按生产管线阶段编号。

V2.1 起每个子目录是**三层结构**：`templates/` + `examples/` + **`agents/`**。

```
│   ├── templates/
│   ├── examples/
│   └── agents/                  ⬅️ V2.1 新增
├── 20_小说转剧本/
│   ├── templates/
│   ├── examples/
│   └── agents/                  ⬅️ V2.1 新增
├── 30_剧本转分镜/
│   └── agents/                  ⬅️ V2.1 新增
├── 40_人物图片/
│   ├── templates/
│   ├── examples/
│   ├── style_keywords.md
│   └── agents/                  ⬅️ V2.1 新增
├── 50_场景图片/
├── 60_视频生成/
│   ├── 运镜.md
│   ├── 转场.md
│   ├── 特效.md
│   └── agents/                  ⬅️ V2.1 新增
└── 70_配音配乐/
    └── agents/                  ⬅️ V2.1 新增
```

### B.3.1 templates / examples / agents 三者区别

| | templates/ | examples/ | agents/ |
|---|---|---|---|
| 内容 | 抽象骨架，带占位符 `{角色名}` | 具体一次成功的完整 prompt | 完整的 system prompt 文件，可直接喂给 LLM 创建智能体 |
| 目的 | 下次手动套用 | 启发灵感、对比效果 | 一次配置长期复用，跨平台、可版本化 |
| 文件名 | `人物全身正面_模板.md` | `20260520_少女白衣古风_即梦v3.md` | `A6_剧本生成_玄幻特化_V1.0.md` |
| 使用方式 | 复制 + 替换占位符 | 复制 + 改写 | DeepSeek 智能体 / Claude Project / API system 参数 |
| 详见 | 本节 | 本节 | [`./04_PartD_Agent体系.md`](./04_PartD_Agent体系.md) |

### B.3.2 各子目录详解（节选）

- `10_小说创作/`：`agents/` 下挂 A1（大纲）/ A2（正文）/ A3（精化）/ A4（审查）
- `20_小说转剧本/`：`agents/` 下挂 A6（剧本，标准版 + 类型特化）/ A7（精简）/ A8（连贯性审查）
- `30_剧本转分镜/`：`agents/` 下挂 A9（剧本→分镜）
- `40_人物图片/`：`agents/` 下挂 A5（角色 / 物品 / 场景三视图）
- `60_视频生成/`：`agents/` 下挂 A10（分镜→视频提示词）
- `70_配音配乐/`：`agents/` 下挂 A11（配音指令生成）

详细 agent 清单见 [`./04_PartD_Agent体系.md`](./04_PartD_Agent体系.md) §D.4。

## B.4 03_角色与世界观/

**这是什么**
**人物一致性**的核心资产库。每个角色一份"角色卡"，每次生成都附上固定 prompt 块。

```
03_角色与世界观/
├── characters/
│   └── <角色名>/
│       ├── character_card.md
│       ├── reference/
│       └── seed_prompts.md
├── worlds/
└── style_guide.md
```

**与 `02_提示词库/40_人物图片/` 的区别**

| | 03_角色与世界观/ | 02_提示词库/40_人物图片/ |
|---|---|---|
| 性质 | 具体角色的"身份证" | 通用的人物生成方法库 |
| 复用 | 跨集复用同一个角色 | 任何角色都可套用模板 |
| 例子 | "林小满"的固定外貌 prompt | "古风少女全身像"模板 |

## B.11 决策速查：这个东西放哪儿？

| 你手上的东西 | 放哪儿 |
|---|---|
| 别人的优秀人物 prompt（完整可复制） | `02_提示词库/40_人物图片/examples/` |
| 别人的爆款视频截图（拿不到 prompt） | `04_风格参考/优秀作品/` |
| 自己摸索出的、可复用的人物 prompt 骨架 | `02_提示词库/40_人物图片/templates/` |
| **打算配置成 DeepSeek / Claude 智能体的 system prompt** | `02_提示词库/<阶段>/agents/` |
| 你正在做的项目里"林小满"的固定外貌 | `03_角色与世界观/characters/林小满/` |
| 即梦 v3 新功能的使用心得 | `05_工具笔记/即梦.md` |
| 看课笔记 | `01_学习笔记/教程笔记/` |
| 实操完的复盘 | `01_学习笔记/复盘日志/` |
| 听说过但还没懂的概念 | `01_学习笔记/未知与待探索.md` |
| 项目企划与素材 | `06_项目作品/<项目名>/` |
| 一个值得收藏的博主主页 | `07_资源链接/社区与博主.md` |

## B.12 推荐使用节奏

1. **每天**：草稿区随手记 + 当天产出归位。
2. **每周**：清理 `99_草稿区/`，更新 `复盘日志/`，扫一遍 `未知与待探索.md`，挑 1~2 项深入。
3. **每月**：
   - 检查 `examples/` 里哪些已稳定到可以抽成 `templates/`。
   - **检查 `templates/` 里哪些可以升级为 `agents/`**（V2.1 起）。
   - 更新 README 学习路线图。
4. **每个项目结束**：必写 `06_项目作品/<项目>/07_复盘.md`。

## B.14 三级升级路径与框架版本化

| 阶段 | 出现频次 | 归档位置 |
|---|---|---|
| 偶尔出现一次 | 1 次 | `99_草稿区/` |
| 反复出现、独立主题 | 2~3 次 | `01_学习笔记/未知与待探索.md` |
| 已学懂、有 3 篇以上内容要存 | 稳定主题 | **升级目录框架版本**，新增子目录 |

**框架自身的版本化规则**

- 兼容性扩张 → V2.1、V2.2…
- 重大重构 → V2.0、V3.0…
- 旧版本作为历史快照保留在 `output/`，不覆盖。
- **新版本必须包含旧版本的全部内容**，再修改与新增（CLAUDE.md §5.3）。
- 多文件成组输出时，按版本目录组织（CLAUDE.md §5.5）。
