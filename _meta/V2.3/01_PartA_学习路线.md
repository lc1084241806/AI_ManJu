## A.1 用户原始流程 vs 完整流水线

用户最初梳理的 6 步流程：

1. 生成小说
2. 通过小说生成剧本
3. 确定小说中所有个体的详情描述（人物三视图、物品三视图、场景等）
4. 通过剧本生成分镜提示词（每个分镜需要生成图片？）
5. 根据分镜提示词（图）生成视频
6. 视频剪辑

**评估：骨架正确，但缺四块**——**前期定位、角色一致性的工程方法、音频、发布迭代**。

下文 A.2 给出补完后的完整流水线，⬅️ 标记的是原 6 步中**缺失**的步骤。

---

## A.2 完整生产流水线（11 步）

### 步骤 0 · 题材定位 ⬅️ 缺

**做什么**
选赛道（短剧 / 竖屏微剧 / 搞笑 / 恋爱 / 玄幻 / 悬疑 / 治愈 …）、确定平台（抖音 / 视频号 / B 站 / 小红书 / YouTube）、目标时长、画风（写实 / 二次元 / 3D / 水墨 / 厚涂 …）。

**为什么不能省**
平台决定画幅（竖屏 9:16 vs 横屏 16:9）、时长（30s vs 3min）、节奏强度；画风决定后面所有图像与视频模型选择。**没定位就开工，等于盲人摸象。**

**要学**
- 看 50–100 条目标赛道爆款，做结构拆解（钩子位置、反转节奏、台词密度、镜头长度）。
- 平台规则与算法偏好基础。

---

### 步骤 1 · 小说生成 ✅

**做什么**
用 LLM 生成故事原文（人设、世界观、章节）。

**要学**
- 长文本提示词工程。
- 世界观 / 人设 / 钩子 / 反转 设计方法。
- Claude / GPT 等 LLM 的长文写作技巧（分章、续写、避免重复）。

---

### 步骤 1.5 · 大纲与分集 ⬅️ 缺

**做什么**
把小说拆成"集"和"场"。每集明确：钩子、冲突、反转、台词高密度区。

**为什么不能省**
AI 直接把小说转剧本会丢节奏。**短剧靠的是节奏，不是文笔。** 中间必须有"大纲层"做节奏控制。

**要学**
- 短剧三幕结构。
- "7 秒一钩子"节奏模型（短视频通用规律）。
- 单集时长内的信息密度控制。

---

### 步骤 2 · 剧本生成 ✅

**做什么**
按大纲将小说改写为标准剧本格式：场号 / 景别 / 动作 / 台词 / 旁白。

**要学**
- 标准剧本格式（中文短剧通用模板）。
- 对白口语化（书面语 → 嘴里能说出来的话）。
- 信息密度控制（一句台词承担多少信息）。

---

### 步骤 3 · 设定集（人物 / 物品 / 场景）✅ 但要前置

**位置修正**
用户原本把它放第 3 步（剧本之后）。**应该和剧本并行甚至更早**——因为剧本里写"小明走进酒馆"时，你得先知道小明长啥样、酒馆长啥样，否则后面要回头返工。

**做什么**
- 主要角色三视图（正 / 侧 / 背）+ 表情包 + 服装方案。
- 关键物品三视图。
- 关键场景的环境设定图。

**要学的最关键一件事 ⬅️：角色一致性**

这是 AI 漫剧的**头号难题**——"同一个角色每集长得不一样"是新手最大的坑。手段（由易到难）：
- 角色三视图 + 参考图喂给图生图（最简单）。
- **IP-Adapter / Reference-Only**（ComfyUI / SD 生态）。
- **LoRA 训练**（专属角色 LoRA，效果最稳但要数据集和算力）。
- 商业工具内置的一致性功能：
  - 即梦"角色"功能
  - 可灵"人物形象"
  - Midjourney `--cref`（character reference）

**要学**
- 角色一致性的 4 种主流方案及优劣势。
- ControlNet（控制姿势 / 构图）。
- 三视图制作流程。

---

### 步骤 4 · 分镜设计 + 关键帧生成 ✅（你已经想到了，但要分两层）

**回答你的问题**：是的，**每个分镜都要先生成图（关键帧），再用图生成视频**。这是当前主流工作流。

这一步实际是两件事：

#### 4a · 分镜脚本（导演的活，AI 不会自动给）

**做什么**
为每一镜确定：景别（远 / 中 / 近 / 特写 / 大特写）、机位、运镜（推 / 拉 / 摇 / 移 / 跟 / 升降）、时长、转场。

**要学**
- 镜头语言基础（景别 / 构图 / 轴线 / 视线匹配）。
- 蒙太奇剪辑基本原理。
- 短剧典型分镜模板。

#### 4b · 关键帧出图

**做什么**
每个分镜出 1 张图（图生视频用）或 2 张（首帧 + 尾帧，做运动控制）。

**要学**
- 文生图工具及提示词：Midjourney / Stable Diffusion / Flux / 即梦 / 可灵图像。
- 首尾帧概念（首帧 → 尾帧 = 运动方向，AI 视频会"中间插帧"补完）。
- 每张关键帧必须套用步骤 3 的角色一致性方案。

---

### 步骤 5 · 图生视频 ✅

**做什么**
把关键帧喂给视频模型生成 5–10 秒短片段。

**要学**
- 工具选型与对比:可灵 / 即梦 / Runway / Sora / Vidu / Hailuo / Pika——每家强项不同（人物表演 / 运镜 / 物理 / 时长 / 价格）。
- 运镜提示词写法（"镜头缓慢推进" / "环绕角色" / "跟随移动"）。
- 时长限制（多数 5–10 秒），长镜头要拼接。
- 失败率高，**多刷几次选最佳**——**预算意识与刷次策略**。

---

### 步骤 5.5 · 音频制作 ⬅️ 严重缺失

**做什么**
配音、BGM、音效、口型同步。

**为什么不能省**
**短剧 70% 是听的。** 无声视频根本留不住人。即使画面 80 分，没有配音的 AI 漫剧基本播放量为零。

**要学**
- **TTS 配音**：剪映自带 / ElevenLabs / 魔音工坊 / CosyVoice / GPT-SoVITS。
- 多角色音色管理（每个角色固定一个音色 ID）。
- **对口型（Lip Sync）**：HeyGen / Sync.so / 即梦对口型 / LatentSync。
- **BGM 选曲**：情绪曲线匹配剧情；Suno / Udio 生成自定义 BGM。
- **音效**：脚步 / 关门 / 风声 / 转场音——免费库（freesound）和付费库。

---

### 步骤 5.6 · 字幕 ⬅️ 缺

**做什么**
为所有台词加字幕，必要时双语。

**要学**
- 剪映自动字幕（中文准确率最高）。
- 卡拉 OK 字幕 / 逐字动画字幕。
- 双语字幕（出海作品必需）。
- 字幕样式与画面构图的关系（不挡脸、不挡关键信息）。

---

### 步骤 6 · 视频剪辑 ✅

**做什么**
把视频片段、配音、BGM、音效、字幕拼成完整成片。

**要学**
- 剪映 / Premiere Pro / DaVinci Resolve 任选其一。
- **节奏剪辑**：卡点、卡 BGM、卡台词重音。
- **转场原则**：硬切优先，少用花哨转场（除非赛道需要）。
- **调色统一**：不同 AI 视频工具出的片段色调会飘，最后必须统一调色。
- 平台规格适配（导出参数、封面尺寸）。

---

### 步骤 7 · 发布与迭代 ⬅️ 缺

**做什么**
封面设计、标题钩子、发布时间、A/B 测试、数据回看 → 反哺步骤 0。

**为什么不能省**
**不发布 + 不复盘 = 永远进不了爆款。** 数据是唯一真实的反馈。

**要学**
- 抖音 / B 站 / 视频号 / 小红书 算法基础。
- 爆款封面与标题套路。
- 数据指标解读（完播率、互动率、关注转化率）。
- A/B 测试方法。

## A.3 学习优先级

如果刚起步，**按以下顺序攻克最高效**：

| 优先级 | 主题 | 理由 |
|---|---|---|
| ⭐⭐⭐⭐⭐ | **角色一致性** | 决定能不能做"剧"，而不是"片段集锦" |
| ⭐⭐⭐⭐⭐ | **镜头语言 + 分镜设计** | 决定能不能"讲故事"，而不是"PPT 拼接" |
| ⭐⭐⭐⭐⭐ | **音频 / 配音 / 对口型** | 决定能不能"留住观众" |
| ⭐⭐⭐⭐ | 节奏控制（大纲 + 剪辑） | 决定能不能"被刷下去" |
| ⭐⭐⭐⭐ | 题材定位 + 发布迭代 | 决定能不能"被推荐" |
| ⭐⭐⭐ | 文生图提示词工程 | 教程最多、最容易入门 |
| ⭐⭐⭐ | 图生视频工具 | 工具迭代快，了解原理即可，具体工具随选随学 |
| ⭐⭐ | 小说 / 剧本 LLM 写作 | LLM 已经很强，提示词调一调就行 |

**反直觉提醒**：很多新手把 80% 时间花在"提示词工程"上，但这是最容易的部分。**真正的瓶颈在角色一致性、镜头语言、音频。**
