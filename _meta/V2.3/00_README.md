## V2.2 → V2.3 变更摘要

**本次为"兼容性扩张"，V2.2 全部内容保留不动，仅新增。**

1. **新增 Part E 实操 SOP**（`05_PartE_实操SOP.md`）：把 Part A 的流水线 11 步从"学什么"层面下沉到"怎么做"层面；每步统一格式（前置 / 调用知识库 / 调用 Agent / 调用工具 / 操作动作 / 产出落点 / 质检要点）；粒度中等——比 Part A 详细，但不绑死任何具体软件版本与按钮路径。
2. **新增项目模板**（`../../06_项目作品/_template/`）：每开一部新作品时复制此模板即可，内置 11 步标准目录骨架 + `SOP_checklist.md`（Part E 浓缩成 checkbox 清单）。
3. **Part A/B/C/D 不变**：知识层（V2.2）和执行层（V2.3 Part E + 模板）解耦——Part E 引用 Part A 的步骤号但不重述"为什么"。

> **设计原则**：知识库（Part A-D）告诉你"是什么、为什么、有什么"；SOP（Part E）告诉你"先做什么、再做什么、做到什么程度算合格"；模板（`_template/`）告诉你"做出来的东西放哪里"。三层互不重复。
