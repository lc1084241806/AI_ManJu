# 我的作品

> 你做过的每一部 AI 漫剧,都装在这里。
> 一部作品一个子目录,内部按 11 步流水线组织。

---

## 命名规范

```
我的作品/<编号>_<作品名>/
```

例:
- `000_练手作/`(阶段 1 的端到端练手)
- `001_战神归来/`
- `002_重生之我是太子妃/`

**编号建议**:三位数,从 `000` 开始递增。这样目录排序就是时间顺序。

---

## 单部作品的标准结构

```
<编号>_<作品名>/
  00_企划.md           ← 题材 / 受众 / 平台 / 集长 / 卖点
  01_小说.md           ← 完整小说(A1-A4 产出)
  02_设定集.md         ← 调用了哪些角色 / 场景(A5 产出 + 引用材料库)
  03_剧本.md           ← 分场剧本(A6-A8 产出)
  04_分镜.md           ← 镜头清单(A9 产出)
  05_关键帧/           ← 出的图(.png,大文件不入 git)
    1_1.png
    1_2.png
    ...
  06_视频/             ← 图生视频成果(.mp4,不入 git)
    1_1.mp4
    1_2.mp4
    ...
  07_音频/             ← 配音 / BGM / 音效(.wav .mp3,不入 git)
    配音/
    bgm/
    音效/
  08_成片/             ← 最终视频(.mp4,不入 git)
    final.mp4
    final_竖版.mp4
  09_复盘.md           ← 做完后 24h 的数据复盘
```

## 大文件管理

`.gitignore` 已经配置:
- `*.mp4` `*.mov` `*.mkv` `*.mp3` `*.wav` `*.psd` 全部不入 git
- 这些文件**只在本地保留** + 自己备份(网盘 / 移动硬盘)

文本类(.md)入 git,可以追溯历史、跨设备同步。

---

## 与"材料库"的协作

```
材料库/(可复用资产)
  ↓ 引用
我的作品/<项目>/(具体作品)
  ↓ 反哺
材料库/(更新解法 / 添加新角色 / 修订 agent)
```

### 启动新作品时
1. 在 `00_企划.md` 里写明用到哪些角色 / 场景(从材料库引用)
2. 用 `材料库/agent/` 里的 agent 跑各步骤
3. 把产出存到本目录对应文件

### 完成新作品时
1. 把新创建的角色 / 场景沉淀回 `材料库/人物/` 或 `材料库/场景/`
2. 把改进后的 agent 版本更新到 `材料库/agent/`
3. 写 `09_复盘.md`,记录"沉淀到材料库的内容"

**作品越多,材料库越厚,后续作品越快。**
