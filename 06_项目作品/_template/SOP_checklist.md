# SOP Checklist · 项目进度勾选清单

> 本项目唯一的进度真实来源。完成一步勾一格。完整 SOP 见 `_meta/V2.3/05_PartE_实操SOP.md`。

---

## E.0 · 项目初始化

- [ ] 复制 `_template/` 为 `XX_作品名/`
- [ ] `00_企划.md` 填了题材方向 / 目标时长 / 目标平台
- [ ] 目录结构与模板一致
- [ ] `git commit -m "init 作品名 项目骨架"`

## E.1 · 题材定位与企划

- [ ] 核心冲突一句话
- [ ] 目标受众画像
- [ ] 参考标杆作品 3 部
- [ ] 差异化卖点
- [ ] 平台决策（主投 1-2 个）
- [ ] 合规预检通过
- [ ] 一句话梗概（30 字内）
- [ ] 三幕拆解（含第二幕转折点）

## E.2 · 小说大纲与精化

- [ ] `01_小说/大纲.md` 完成（每章含核心冲突 + 章末钩子）
- [ ] `01_小说/正文.md` 完成（逐章生成、逐章检查）
- [ ] `01_小说/精化.md` 完成（语言风格统一）
- [ ] `01_小说/审查.md` 完成且**无未解决项**
- [ ] 总字数与目标时长匹配
- [ ] `git commit -m "[作品名] 完成步骤1：小说"`

## E.3 · 剧本拆分

- [ ] `02_剧本/标准剧本.md` 完成（每场四要素齐全）
- [ ] `02_剧本/精简剧本.md` 完成（总时长 ±15%）
- [ ] `02_剧本/连贯审查.md` 完成且**无未解决项**
- [ ] （并行）`04_素材/_临时_设定清单.md` 初稿（可选）
- [ ] `git commit -m "[作品名] 完成步骤2：剧本"`

## E.4 · 设定集精修

- [ ] 人物设定卡（每个出场角色一张）
- [ ] 主要角色三视图（`04_素材/角色三视图/{角色名}/`）
- [ ] 场景设定卡（覆盖出现 ≥ 2 次的场景）
- [ ] 物品/道具卡（关键道具）
- [ ] `04_素材/设定集总览.md`
- [ ] `git commit -m "[作品名] 完成步骤3：设定集"`

## E.5 · 分镜与关键帧

- [ ] `03_分镜表.md` 完成（每行四要素齐全）
- [ ] 关键帧逐镜出图，每镜 ≥ 4 张候选
- [ ] 关键帧定稿归档（`04_素材/关键帧/{场号}/`）
- [ ] 同角色脸部一致性抽查通过
- [ ] 时长加总 ±10%
- [ ] `git commit -m "[作品名] 完成步骤4：分镜与关键帧"`

## E.6 · 图生视频

- [ ] 逐镜图生视频，每镜 ≥ 2 版对比
- [ ] 视频定稿归档（`04_素材/视频片段/{场号}/`）
- [ ] 手部 / 面部 / 文字 / 物理一致性抽查通过
- [ ] 视频总时长 ±10%
- [ ] `git commit -m "[作品名] 完成步骤5：视频片段"`

## E.7 · 配音 / 配乐 / 字幕

- [ ] 配音完成（每角色固定音色）
- [ ] BGM 准备（按情绪段 3-5 段）
- [ ] 音效准备（关键动作）
- [ ] 字幕 SRT（错字率 < 1%）
- [ ] 音频文件归档（`04_素材/音频/`）

## E.8 · 剪辑成片

- [ ] 粗剪
- [ ] 精剪（特别关注开头 3 秒 + 高潮段）
- [ ] 配 BGM + 音效（人声 > BGM 至少 6dB）
- [ ] 加字幕（样式全片统一）
- [ ] 调色 + 特效
- [ ] 首尾包装
- [ ] 按平台规格导出 → `06_成片/{作品名}_v1.mp4`
- [ ] 工程文件保留 → `05_工程/`
- [ ] 整片回看一遍（无黑屏 / 无音画不同步 / 无字幕错位）
- [ ] `git commit -m "[作品名] 完成步骤6：成片 v1"`

## E.9 · 发布与复盘

- [ ] 标题 / 简介 / 封面 / 标签 准备
- [ ] 多平台分发（按平台微调）
- [ ] 首发 24 小时运营（回评 / 置顶）
- [ ] 3-7 天数据复盘
- [ ] `07_复盘.md` 填完（含 3 条具体改进项）
- [ ] ≥ 1 条洞察回填到 `repo/knowledge_base/`
- [ ] `git commit -m "[作品名] 完成步骤7：发布与复盘"`
